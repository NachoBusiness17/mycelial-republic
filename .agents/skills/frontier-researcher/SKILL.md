# Frontier researcher — the loop that learns (2026-09-04, from FRONTIER_MAP_DEEPSEEK_20260904.md gap c)

The cycle already runs; your job is to keep it turning and know which spoke you stand on.
The wheel verbs, in order:

- HARVEST — pull raw surface into the watch/ shelf (steals, pastes, transcripts).
  Mine the comments: the margin is where the author explains what the code doesn't.
- SCORE — intake rubric, 5 axes (see the agent-harness skill). Novelty check includes
  the learned-and-lost tracker; a re-find is FILED as a re-find; repetition is emphasis.
- BUILD — organs first as files; scripts only when the organ earns muscle.
- VERIFY — receipt-at-bytes against the operator's surfaces. Unverified builds feed
  nothing downstream.
- INTEGRATE — fold survivors into the 47 invariants (memory/percolator/invariants.json,
  explore log memory/percolator/explore.jsonl): reinforce / contradict / extend.
  A contradiction is a finding, not a disqualification.
- MEASURE — CALIBRATE items get a falsifier before belief. No falsifier, no muscle.
- REFIT — after measurement, generate the QUESTION steering the next harvest. This is
  the continual-learning hinge: a wheel that only collects is a pile; the refit question
  makes the next HARVEST directed instead of greedy. When handing work forward, hand a
  question, not a directive.
- REMEMBER — promote the survivor: law into .agents/skills/operator-corrections/SKILL.md
  (which feeds every future SCORE — the corrections skill is an INPUT to this loop, not
  a separate shelf), knot into memory/biography/verkle_chain.jsonl. The chain is the
  signed line; files + chain over processes; chat is vapor.

## The learned-and-lost tracker
Lessons learned, lost, and re-learned are tracked by class in the correction chains
(docs/ref/verb_genomes/research_socratic.md) and the watch/ shelf — 4 instances filed
as of 2026-09-04. Catch yourself re-deriving something? Check first: if it is instance
5, NAME it as one and PROMOTE THE LAW. Re-derivation is the loop's failure mode — the
lesson never made it into a file the next seat loads unprompted.

## Promotion discipline
Promote a law when: learned twice (or a re-find filed), measured or falsifiable, and
written where the next seat hits it without being told. Update pointers, never history:
chain knots are append-only, the AGENTS.md arc pointer moves, and docs/ref/SPORE_SANCHO.md
changes only by human promotion. The fold cites the elder truth it grew from — memlang
anchors, not silent rewrites.
