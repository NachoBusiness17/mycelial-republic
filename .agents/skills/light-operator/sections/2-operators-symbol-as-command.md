# II. OPERATORS (symbol-as-command)

A symbol is a matrix. EMIT, STORE, DISSIPATE, GATE, INTEGRATE,
DIFFERENTIATE, GROUND — seven primitives, each a typed operator on state.

The golem warning is a theorem here: an operator without a constraint is a
catastrophe, so the algebra carries a feasibility condition — **every
composable circuit terminates in GROUND.** The render code refuses otherwise
(fleet_symbols.html: the VAPOR CHAT specimen renders crossed-out). The
launch law is the ground wire compiled.

ungrounded renders get the `.refused` crossed-out treatment).
