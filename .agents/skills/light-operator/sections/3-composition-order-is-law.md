# III. COMPOSITION (order is law)

Circuits are matrix products. Matrix multiplication does not commute —
which is why BUILD_BEFORE_PRETTY, Leg-1-before-scale, and GROUND-last are
not style: they are non-commutativity, felt as economics.

The Philbrick cookbook is the precedent: few primitives, many named circuits,
every stable one closed through feedback.
