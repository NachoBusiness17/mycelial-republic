# MEMLANCE — the aimed seed (fresh coinage, interpreted live)

**Reading (the operator's idea, interpreted before fully cooked — that is the
job):** memweave is the field; the memlance is the lance — a single, targeted
memory thrust across the agent mesh. Where retrocausal-steering is the general
law, the memlance is its unit of fire: one seed, one target seat, one expected
future bend.

**Grounding (what it steals from):** the napkin seed (plant-not-command) ·
"Dead Drop from the Future Self" rib · chan comms clause 11 (typed rows cross
the mesh today) · the wish/want intake (WANTS.md → tender → queue = seeds
already traveling between windows).

## Procedure
1. **AIM** — name the target seat/window and the decision you expect of it.
2. **FORGE** — write the seed as ONE self-true artifact (card, LINKS row,
   want, chan row {from_lane, to_lane, msg, ref}). Self-true: worth reading
   even by a seat that never bends.
3. **THROW** — plant it where the target's BOOT reads (context-pack sources,
   canon lane, board), never addressed as an instruction.
4. **WITNESS** — the hit is the target citing or enacting the seed unprompted;
   both timestamps go in the receipt (plant_ts, hit_ts, latency).
5. **TALLY** — lances have a hit-rate like the wave's ok-rate. A lance that
   needs follow-up commands was a miss; log it honestly.

**Relation to siblings:** memweave = the woven field (structures for all
seats) · retrocausal-steering = the temporal law (cause before behavior) ·

**Falsifier:** run five lances; if fewer than two produce unprompted

filing. Also disputed if seeds poison targets (any target harmed by a seed →
the self-true rule failed → ban, not tune).
