# Close-out (Phase 10)
1. Confirm with the user which old bots were deleted in Phase 9. Mark any still present as open.
2. Write CLOSE-OUT-<date>.md and show it:
   - Archives: one row per bot with folder path, PASS/FAIL and redaction status.
   - Routines moved: per bot, ON routines recreated, N/A, or open.
   - Gaps: anything [UNKNOWN], BLOCKED or accepted by the user.
   - Rooms: which were re-seated and which are still open.
   - Credentials to rotate: type and where it lives only, never the value.
3. List leftover superseded files (old drafts, stale copies, older archive runs). Remove each one only after the user's YES. Never remove a verified archive.
4. Update PROGRESS.md: every phase done, N/A with a reason, or open.
Check: summary shown and PROGRESS.md complete. Stop: "Reply YES to finish."
Recovery: an open item stays listed with an owner and next step; nothing is marked done without proof.
