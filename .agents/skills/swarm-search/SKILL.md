# SWARM SEARCH - the repeatable steal loop

Founded 2026-10-05 on the Amenti run (receipt watch/inbox/AMENTI_DIFF_RACTOR_20261005.md,
map memory/research_packs/20261005_agent_mesh_salon/DIFF_TARGETS.md). The loop is
substrate-agnostic: any external corpus (a paper, a competitor, a mythos, a person's
posted system) rides the same rails.

## The loop (7 stations)

1. EXTRACT invariants. What does the external system TEST everywhere? One system,
   many domains = one invariant applied repeatedly. Write it as a sentence.
   (Amenti example: presence/absence of a relational carrier, the binding agent.)
2. MAP to self. Table: their element x our organ x status PRESENT / PARTIAL / ABSENT.
   PRESENT cells cite the organ (file path). Honesty law: do not claim PRESENT
   without a test or a running organ.
3. DIFF. The non-PRESENT cells are candidate targets. Each target gets: the steal
   (what signal her/its insight adds beyond what we banked), a machine-checkable
   FALSIFIER, and a cost (free lanes / minutes). No falsifier = not a target, a vibe.
4. RACTOR the target list. Fire the saved ractor-engine workflow (gate-check first:
   python tools/workflow_gate.py check --script .zcode/workflows/ractor-engine.dwf.ts)
   with topic = the DIFF artifact path + the adjudication ask, slug dated. Killing
   a target is a finding. For lighter passes, salon_runner fire over the artifact
   is the same panel shape (blind shapes + fold).
5. HIT the cold vertices. Cold = the field has zero measurements and our free lanes
   + local models can produce one for $0. Run the falsifier as an instrument
   (probe script or salon grid), not as an opinion. Sensing stays free-tier;
   verification climbs only if the finding demands it.
6. BANK. Findings land as mesh blobs (propose -> adjudicate -> knot), laws land in
   the nearest rib/skill, the whole run lands as one watch/inbox receipt.
7. RE-DIFF. Next pass over the same external system starts from the updated map -
   the loop compounds because the map persists.

## Standing laws inside the loop

- Witness law: N seats from M model families = at most M witnesses; count
  cross-family agreement only; intra-family agreement is echo.
- No sacred cows: the operator's enthusiasm for a target is not evidence; the
  ractor's kill of a target IS a product.
- Cold-vertex discipline: prefer a measurement nobody has over an opinion
  everybody has; the cheapest instrument wins.
- The external system's truth-claims are not endorsed by mapping them; we steal
  STRUCTURE (invariants, tests, protocols), decline unmeasured claims politely,
  and say so in the receipt.
