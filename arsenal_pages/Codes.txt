This is the codes page! We are not associated with 
ROLVe
, so please do not ask for the addition of more codes.
As a side note, this page is not constantly updated: we are always asking for people to test the codes and make sure they aren't expired.
Promotional codes
 are given out by 
ROLVe
developers
 to give away free items, such as currency or 
locker
 items. They can be redeemed in the main menu by clicking on the gift button and entering in a code.

Trivia
The 
ROLVE
 code was unusable from March 31, 2020 to April 27, 2021.
Due to a glitch, 16 players were able to redeem the 
UnfairBias
 despite having 10 copies.
The 
GULL1BL3
 code was created to fool people about the Milo unusual being released from this code.
Users who redeemed the code were unbanned shortly after.
The 
MIGHTYBANDITES21
 code was originally 150 copies, however it was changed at the last minute.
The code originally going to give out the Delinquent skin with the Froggy unusual however Bandites' request was declined.
[
19
]
The 
BanditesPog
 code was originally made by Castlers only to give Bandites and JJ_Waike the Delinquent with no Brim skin, however the code never actually worked.
[
20
]
The 
do you remember
 code was released to celebrate the song, 
September
 by 
Earth, Wind & Fire
.
There is a 1/1000 chance of getting Herobrine Delinquent with a Enchantment unusual upon redeeming 
the 2021 spooky code
.
This is a reference to 
Minecraft
 as the Enchantment unusual is referring to the Echantment Table while Herobrine Delinquent is a direct reference to a 
Minecraft
 myth, Herobrine.
Only 65 players were able to get the Herobrine Delinquent skin with Echantment unusual variant.
xonaeday21
 was created to celebrate 
developer
 xonae's birthday.
On November 26, 2022, 
goodnight
 and 
(
ROBLOX
 user profile ID in reverse)
 codes were stealthily made inaccessible to the first two respective stages of 
Snowy Bridge
.
wake up
 was the original code for the teleportation to the part one of Snow Bridge.
dhmu
 is a testing variant of 
dhmubruh
, which gives a glitched yet invisible version of the GrindSet calling card and the name was changed to "Grindset" without any capitalization on "set".
The glitched variant was later established into a "duplicate" to GrindSet on January 19, 2022.
