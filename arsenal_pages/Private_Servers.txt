Private servers
 (formerly known as 
VIP servers
) are a feature that allows the player to create their own server for 100 Robux. Inside private servers, players are unable to earn EXP/B$ by playing rounds or contracts; however, it is still possible to get EXP/B$ through completing daily challenges.
The owner of a private server can access a menu of commands by pressing the 'L' keybind (or on a button at the top right if on mobile). Examples of such commands are setting the 
gamemode
 or 
map
 for the next round. The private server menu can be used in public servers by game administrators.

End Game
This command gives the server owner the ability to end the game whenever they want.
Kick A Player
This command gives the owner of the server the ability to kick a player from the server. When this happens, the chat will prompt a system saying "[Player] was banned from this session."
If the owner tries to kick themselves, the chat will say "no".
Configure Clips
This command allows the server to configure clips and collisions of a map. There are 4 settings allowed for adjustment.
Disable Collisions - Disabled the map's collisions, players can explore out of bounds areas in the map.
Enable Collisions - Enabled the map's collisions, blocking out of bounds areas.
Make Invisible - Configure the map's clips to be invisible.
Make Visible - Configure the map's clips to be visible, as they emits pink barriers around the map.
BigHead
This command increases the head of every player in the server to become big. The headshot hitbox also increases, meaning players are easy to be killed.
Example of BigHead.
Gravity
This command allows the server owner to adjust the gravity of the server. This gives players the ability to float higher or lower after a jump then fall slower or faster.
Default gravity:
 55.52 studs
Team Mode
This command allows the server owner to set the amount of 
teams
 in the map even if it's locked to 2 teams. There are 3 settings for the command.
2 Teams - Team Blue and Red are permitted.
4 Teams - Team Blue, Red, Yellow, Green are permitted.
Free for All - All players are permitted to no teams.
Time Scale
This command allows the server owner to adjust the time it takes to do objectives like weapon firerate, reload, player movement speed and pull out weapons moderately.
Default scale:
 1
Toggle Appearance Skin
This command allows the server owner to activate the Appearance 
skin
, which uses the player's 
Roblox
 avatar for their respective skin.

Low Gravity
This command decreases the gravity of the server, making the player movements more floaty. This command was replaced by a newer and current iteration that allows to adjust the gravity.
Spawn Cluckling
This command allows the server owner to spawn 
Cluckling

Egg Hunt 2019
 event. This command was removed on the same day it was added for unknown reasons.
