# BASECAMP — the living documents (one per program)

## THE LAW (mine-then-archive)

1. Every old file gets MINED before it gets carried: what does it hold that the
   best current version does not? The nuance moves into the basecamp file.
2. After mining, the original ARCHIVES (hash + date + location noted). It stops
   littering the working set. It is never deleted.
3. Duplication is emphasis: when the same idea arrives twice, the basecamp
   records BOTH arrivals — the repetition is signal.
4. Rediscovery becomes lookup: before starting anything new, search basecamp
   first. If the idea already lives here, extend the entry instead of
   re-deriving it.

## THE RULE FOR NEW WINDOWS

Before building anything: search basecamp. If the idea is here, EXTEND the
entry (append the nuance, note the date). Only create a new camp when a genuinely
new program appears. The basecamp is the anti-amnesia device.

## THE MUSEUM MODEL (self-steal, 2026-09-16 window close)

The estate is a museum with three rooms, and the charter is never-delete:

- **THE EXHIBIT HALL** — the basecamp: mined, curated, living documents. What
  every visitor (new window, new seat, Astra) is shown first.
- **THE WORKSHOP** — the current session's working set: drafts, probes, prompts,
  half-built things. Loud, messy, temporary. Artifacts graduate to the exhibit
  hall when mined; the rest gets swept to the vaults at window close.
- **THE VAULTS** — everything else, forever: the old versions, the event logs,
  the 2,155-file exhaust nights, the dead worldlines, the superseded drafts.
  Hashed, dated, never deleted. The vaults are the provenance — the museum can
  prove every exhibit's history because the basement keeps everything.

**The tour guide** is the basecamp README: it tells visitors what's on display,
where the vaults are, and the law (mine before carrying, duplication is
emphasis, rediscovery is lookup).

The never-delete principle is what makes the museum honest: every vault entry
is an admission that we once thought differently. The exhibit hall shows the
best of what survived.
