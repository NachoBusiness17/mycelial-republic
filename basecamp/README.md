# BASECAMP — the living documents (one per program)

## THE LAW (mine-then-archive)

1. Every old file gets MINED before it gets carried: what does it hold that the
   best current version does not? The nuance moves into the basecamp file.
2. After mining, the original ARCHIVES (hash + date + location noted). It stops
   littering the working set. It is never deleted.
3. Duplication is emphasis: when the same idea arrives twice, the basecamp
   records BOTH arrivals — the repetition is signal.
4. Rediscovery becomes lookup: before starting anything new, search basecamp
   first. If the idea already lives here, extend the entry instead of
   re-deriving it.

## THE RULE FOR NEW WINDOWS

Before building anything: search basecamp. If the idea is here, EXTEND the
entry (append the nuance, note the date). Only create a new camp when a genuinely
new program appears. The basecamp is the anti-amnesia device.
