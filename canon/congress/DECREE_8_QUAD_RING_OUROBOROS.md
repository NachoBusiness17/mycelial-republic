# THE STANDING CONGRESS OF THE SOVEREIGN ESTATE
## Plenary Decree 8: The Quad-Ring Ouroboros Mandate (2026-10-23)

Enacted by the Plenary Assembly of the Standing Congress to formalize the transition from tripartite inquiry loops to the **Quad-Ring Ouroboros Architecture** (Research -> Audit -> Inquire -> Build).

---

## 1. The Quad-Ring Operational Standard

A system that only researches, audits, and inquiries remains an incomplete mind without hands. The Plenary Assembly enacts the four-ring topological mandate:

```
[Ring 1: Work Engine]        --> Senses pending asks & banks empirical reports
        |
        v
[Ring 2: Verification Gate]  --> Socratic FOL audit & Quasilocal Boundary Gate (stamps DONE)
        |
        v
[Ring 3: Self-Feed Engine]   --> Mines stealable patterns & synthesizes depth+N inquiries
        |
        v
[Ring 4: Build Engine]       --> Pops self-improvement tasks & implements repository code
        |
        +----------------------> Closes the loop back into Ring 1
```

- **Ring 1 (Work / Sensing)**: Drains open queues, executes deep technical synthesis, and banks verified findings.
- **Ring 2 (Verify / Gate)**: Audits truth claims via First-Order Logic predicates and Bartnik quasilocal boundary energy invariance.
- **Ring 3 (Self-Feed / Metamorphosis)**: Extracts stealable design patterns and generates depth+$N$ testable successor hypotheses.
- **Ring 4 (Build / Ratchet)**: Translates open self-improvement tasks into repository commits, executes automated test suites, and enforces monotonic capability growth.

1. **The Ghost Diagnostic**: Background drift probes failed under HTTP 404 because port 8080 is bound to the **GSTD Node Dashboard v3.5.0** (`com.docker.backend`), not `llama-server`.

## 3. Constitutional Status of Sovereign Verification

Remote model endpoints are subject to transient latency, upstream billing suspensions, and transport disconnection. The Congress enacts:

- **Sovereign Verification Priority**: All verification routines must carry an autonomous local fallback (`tools/judge_v3_fol.py` + `tools/quasilocal_boundary_gate.py`).
- **Zero Stall Invariant**: An external API outage shall never stall queue drainage or self-feeding loops.
