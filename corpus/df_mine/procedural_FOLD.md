# procedural_FOLD — how DF assembles a never-repeating forgotten beast

There are no FB raws in `vanilla_procedural/objects` — the Steam version builds them at world gen in **Lua that emits token text**. `creatures.fb.default` (creatures.lua:154) is the chain:

SEED (`[FEATURE_BEAST] [ATTACK_TRIGGER:0:0:2]`, skills, LARGE_PREDATOR, is_evil) → SPHERES (`[SPHERE:CAVERNS]` + water + one evil sphere) → **PROFILE**: `get_random_creature_profile` weighted-picks 1 of 235 animal profiles (beetle w22 … bull w14 … blob w1000) → **FORM**: `body_base_fun[body_base]` returns the RCP_\* body-part list (17 bases; quadruped may sprout 6/8 legs) → **TWEAK 1** (`btc`): one of ~26 part mutations (wings/tail/shell/trunk/horns/mandibles) → **MATERIAL CLASS**: `c_class` → `random_creature_class` (MAMMAL/CHITIN_EXO/FLESHY/AVIAN/…) merges organs + tissue detail plan; **1-in-20 flip to UNIFORM** = whole body made of one material (ash, flame, glass, vomit, ANY_MINERAL from the world's own stones; DEATH sphere→ash, FIRE→flame) → **TWEAK 2** (`btc2`): skin/scales/feathers/skinless/eye-count → **ATTACK CLASS**: `attack_tweaks` — web / dust-vapor-gas breath / glob spit / secretion / poison blood / poison bite / sting / FIRE (fireball+jet) — each = CREATURE_EXTRACT_TEMPLATE + a syndrome of 1–5 randomized CE_ effects from a 17-effect pool → gaits via APPlY_CREATURE_VARIATION → DESCRIPTION assembled from the same flags ("Beware its deadly dust!") → PCG_LAYERING sprite stack. The were-curse reuses this with a per-world profile **blacklist** so forms never repeat.

## Fold notes for the Ossuary (procedural wisps)

1. **Wisp = sphere → form → attack → material, in that lock order.** DF gates every downstream roll on the sphere: DEATH grays the palette, dumps ash into the material pool, and reshapes the description. Pick the wisp's sphere first and derive form/material/color from it; never roll them independently.
2. **Make the attack class the identity, not decoration.** One guaranteed attack tweak per creature (DF's `strong_attack_tweak`) with a player-facing warning string ("Beware its webs!") — the tease IS the memory. Randomize only the syndrome internals (severity, organ, timing) so two dust-wisps still feel distinct.
3. **Enforce never-repeating with a blacklist + weight table**, like werebeasts: track drawn form-keys per world/session, redraw on collision, and give rare keys big weights (44 insects at 22 vs 3 generals at 1000). Combinatorics come from crossing independent axes (form x tweak x material x attack), not from one giant table.
