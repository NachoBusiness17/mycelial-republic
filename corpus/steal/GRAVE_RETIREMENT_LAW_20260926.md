## LAW

The handoff ledger must have a retirement path or it becomes a swamp. Retirement is receipt-only grave burial: classify every item with the canonical label set observed in the graves, never delete, deletions are operator-gated, the absorbing successor is verified on disk before it is cited, and the event is registered.

STILL-RELEVANT is not a burial; it is a re-brief pointer. One grave equals one receipt; detail lives in the receipt, never in the README.

"Never delete. Deletions are operator-gated. A grave that removed, moved, or rewrote the file is not a grave, it is a loss."

## STEAL

Retire any queue/handoff/ or watch/inbox/ item by filing a GALA_GRAVE_*.md receipt in watch/inbox/ that classifies it against DONE-ELSEWHERE, SUPERSEDED-BY, ABSORBED-BY, FOSSIL, or STILL-RELEVANT; pairs each claim with a command in a lane check log; verifies the successor exists on disk before citing ABSORBED-BY or SUPERSEDED-BY; and registers the event in the lane directory. Zero bytes deleted; deletions stay operator-gated. The README stays a map, not the ledger.

## FALSIFIER

The law fails if queue/handoff/ grows session over session with no new grave receipts; or a grave removes, moves, or rewrites a file; or an ABSORBED-BY or SUPERSEDED-BY cites a successor absent from disk; or the README grows to narrate a burial.
