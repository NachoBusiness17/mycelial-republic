THE RAW 1D MAP — d(θ), 256 texels wide

x-axis = angle θ (0°→360°) · brightness = first-hit distance · amber texels = rays that hit a caster. This strip IS the light: the 2D scene right of it is one dependent read per pixel. Row 2 = UNSEEN: slate = outside the aim (the eye sees only its aim) · amber = occluded (wall-blocked) · dim teal = actually seen.

THE ALGORITHM — three passes, five lines

  1. OCCLUSION — casters = any pixel alpha>0.75; bake the scene silhouette to a mask (per-pixel casters, no edge extraction).
  2. 1D MAP — cast N rays; d(θ) = min normalized distance to the first caster: the radial horizon. 2D shadow state → 256 numbers.
  3. RENDER — per pixel, polar (θ,r): lit = step(r, d(θ)). One lookup, constant cost.
  4. PENUMBRA — 9-tap gaussian over NEIGHBORING ANGLES, width × smoothstep(0,1,r): aliasing spent as gradient (artifact-into-feature).
  5. FALL OFF + ADD — radial smoothstep(1,0,r); lights composite additively. ~20 lights were fill-bound on a 2013 GPU.

THE ROOM THAT REMEMBERS — v2

ORGAN WALLS — the occluders are the fleet's real anatomy, read from room_state.json (same dir): chain = skeleton, memory/biography = memory, guards = immune, lanes = circulation, trajectory = nervous, mag/* = organs, the room itself, the board. Occlusion is structural: a dark wall still casts shadow — darkness ≠ absence.

LIT / DARK-SIDE — a wall is LIT when the seat's attention touched it in the last 200 trajectory steps (token hits in memory/trajectory/steps.jsonl, counted by mag/room_state.py); brightness tracks the hit count. Untouched walls render DARK-SIDE: dashed, dim, labeled.

THE HOOK ECONOMY (Ponytail) — pixels earn by fire-rate: JOINED = ≥3 fires/24h twice running (two consecutive trailing windows of the tape); ghost = candidate overlay, dashed-dim, promoted only by its own rate; PRUNE = 0 fires/72h — dark-side, geometry kept, glow stripped. Each wall paints its algebra-primitive glyph (stolen whole from fleet_symbols.html: chain=STORE, lanes=GATE, guards=DISSIPATE, room/organs/watch=INTEGRATE, boot_check=GROUND, board=EMIT, sensors=DIFFERENTIATE) and a 200-step fire histogram — the map shows the STREAM, never a snapshot. NO HASH → NO DRAW: fetched walls without a content_hash are skipped.

INVARIANTS — walls whose label+position persist across room_state versions render gold ◇invariant candidate: load-bearing, they cast the longest shadows. Seed marks chain, the room, boot_check (chain never moved since Aug; the room beats hourly; boot_check gates every window).

GAZE LAW (the louver) — only the sector the light aims is fully lit; everything else renders at 15%. You cannot flood the room with attention: the eye sees only its aim.
