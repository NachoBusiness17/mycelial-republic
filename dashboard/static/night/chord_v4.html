## THE VERIFIED CORE (2026-paper-grounded)
1. **INTERACTION TAX**: models reading each other's FULL solutions collapse toward one
   another within a round; independent proposals preserve the useful diversity
   (arXiv:2608.23541). MoA stays non-negative because proposers never read each other.
2. **MATCHED BUDGETS**: under equal thinking-token budgets, single-agent systems match or
   beat several multi-agent architectures on multi-hop reasoning (arXiv:2604.02460).
3. **JOB-CLASS ROUTING**: buy diversity only with a unique-information hypothesis per lane —
   provider vs evidence vs objective vs falsifier diversity are DIFFERENT treatments.
4. **AGREEMENT ≠ VERIFICATION**: three models repeating one unsupported claim is still one
   unsupported claim.

## THE TWO CONVERGENCES (the architectural insight)

  blended into one confident paragraph.
- Operational: eventually ONE decision, acknowledging uncertainty, with the competing
  claim carried as unresolved.
