## TOP PATTERNS BY SUBSYSTEM (cited from the wings)

### GATEWAY (the strongest shelf — adopt-grade)
- **Session hygiene compaction** (gw_run): compaction run against LIVE cached agents —
  compress context without killing the session. Our resident sessions need exactly this.
- **Drain control via marker files** (drain_control): no control channel into a running
  gateway — markers only. Confirms our file-channel law at their production grade.
- **Lifecycle guard** (cron/lifecycle_guard): agents are FORBIDDEN from scheduling crons that
  restart/stop/uninstall the gateway. Our covenant enforcement, their implementation.
- **Authz mixin**: RBAC wrapping every gateway method — permission checks as a mixin layer.
- **api_server_runs**: durable /v1/runs — start, SSE-stream, poll, RESOLVE APPROVALS, and
  **steer RUNNING agents** mid-flight with lifecycle cleanup. (The live-steering surface.)
- **OTLP telemetry with closed vocabularies** (relay_shared_metrics): enumerated states,
  sources, error classes, delivery outcomes; unknown degrades gracefully. Our board's data
  contract, their spec.

### STATE (the memory shelf)
- **State registry** (hermes_state_registry): SQLite SessionDB opens deduped per resolved
  path, refcounted per GENERATION; generations retire when the file's inode changes
  (snapshot restore swaps). Generation-scoped connections = our churn_state done right.
- **Context compressor**: after each turn, absorb the oldest un-summarized exchange into a
  rolling summary; atomic archive_and_compact; defrag threshold. (The resident-session
  rotation primitive — wired to agent_cache_pressure's byte bounds.)
- **Honcho client** (plugins/memory/honcho): memory ops routed through a deterministic
  server, logged as ONE APPEND-ONLY TAPE. (Our event.v1, their memory plugin.)
- **memory_manager**: single integration point delegating to registered providers, one
  external provider max, prefetch/sync/background split, context scrubbing.

### TOOLS / SKILLS (the injection-surface shelf)

- **toolsets.py**: named toolsets as composable lists with `includes` — capabilities as sets.
