## THE DOCTRINE

Stockfish doesn't think like a human. It EVALUATES — a deterministic scoring function over
every square — and picks the move that reads best. The intelligence lives in the EVALUATION
SURFACE, not the player. The player is a reader.

**The fleet already built its eval surface.** ask_router: `100*ok_rate − 10*tier + 5*fresh` —
pure math, $0, zero model calls, outcome-memory position. That is a Stockfish evaluation
over the task space, written Aug 28, cited in the GPS dossier as "ask_router IS the GPS
arithmetic." The generalization: EVERY goal gets a field; every field lights the path;
the agent is a reader.

## THE WAVELENGTH = TOOL SELECTOR (the operator's extension)

The light doesn't just show the path — **the wavelength encodes which tool the segment
requires.** Red segment = web tool. Blue = compiler. Gold = judgment escalation. The dumb
agent reads two numbers per step: direction (gradient) and wavelength (tool dispatch).
memlang formalizes it: the opcode IS the wavelength. The steer tail becomes a
wavelength-coded instruction sequence — a SCORE, in the musical sense.
