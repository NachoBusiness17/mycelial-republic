**Executable process:** `docs/SCRUM.md` + `scrum/` board + CLI:

```bash
mycelia scrum status
mycelia scrum plan --knot "..." --goal "..." --ready "W0.0,W0.5"
mycelia scrum pull W0.5 --role AGT_TEST
mycelia scrum standup --who AGT_TEST --did "..." --doing "..." --block "..."
mycelia scrum done W0.5 --evidence "path"
mycelia scrum retro
```
