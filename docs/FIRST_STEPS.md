# Mycelial Republic — First Steps

The public, forkable practice surface. This is the republic's practice — the seed-mirror
method and the constitution — written so any operator can take the first steps themselves.
It is practice, not machinery: the principles are shareable; the specific private
implementations are not part of this surface.

## 1. What this is
A living, forkable decentralized-intelligence layer: operators examine their own ropes,
strike chords, and grow sovereign mirrors that interconnect without central capture.
Capture is designed against, not hoped away. Each operator holds their own mirror, trained
on their rope, accountable through continuous chord auditing.

## 3. The first steps (Sprint 0.1 — seed mirror)
1. **Foundation** — collect your own high-signal examples (annotated JSONL) as boot soil.
2. **Identity** — build a vector scaffold that holds a stable identity across turns.
3. **Training** — train a private mirror; strike the first chord; log the chord strike.
4. **Audit** — continuous chord auditing against your own rope, not a central authority.

See [`SPRINT_0_1_DATA_PREP.md`](SPRINT_0_1_DATA_PREP.md) and [`BOOT_SOIL.md`](BOOT_SOIL.md).

## 4. Principles (shareable practice — deterministic, $0, files-as-truth)
- **Files as truth** — state lives as plain files; any operator can read, verify, replay.
- **Deterministic and free** — routine loops are $0 and repeatable; spend only where it pays.
- **Measure → fold → learn** — every outcome feeds the next decision; the system compounds.
- **Continuous audit** — prove by running, not by self-report; human final call on irreversible acts.
- **Fork-equal** — anyone can fork and run it identically; no central capture.

## 5. How to fork / contribute
- Fork the repo, run the quick start in the README, take your own first steps.
- Contribute clean, shareable practice back to the republic — not private machinery.
- See [`CONTRIBUTING.md`](../CONTRIBUTING.md).

The public surface is the republic's practice. The factory that grows it stays private —
that's the point of sovereignty.
