"RELIABLE CIRCUITS USING LESS RELIABLE RELAYS BY E. F. MOORE’ AND C. E. SHANNON’ ABSTRACT An investigation is made of relays whose reliability can be described in simple terms by means of probabilities. It is shown that by using a sufficiently large number of these relays in the proper manner, circuits can be built which are arbitrarily reliable, regardless of how unreliable the original relays are"
