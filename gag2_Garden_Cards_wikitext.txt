== Overview ==
'''Garden Cards''' is a reward feature that allows players to flip cards to reveal prizes. 

Each board contains five cards, with rewards becoming more valuable as the player progresses through higher tiers.

The feature uses a five-tier progression system and includes both free and paid rewards. Some revealed cards can be claimed immediately, while others require a {{Robux}} purchase before the reward is granted.

== Gameplay ==
When Garden Cards are opened, the player is presented with five face-down cards. If the current board allows a reveal, the player can select one of the available cards to flip it over.

== Rewards ==
Garden Cards can grant these items:
* {{Sheckle}}
* [[Pets]]
* [[Eggs]]
* [[Crops|Seeds]]
* [[Crops|Harvested fruits]]
* [[Crates]]
* [[Chests]]
* [[Seed Packs]]
* [[Cornucopia Quests|Cornucopias]]
* [[Gears]]
* [[Mechanics|Fence skins]]
* [[Props]]
* [[Gears|Rakes]]
* [[Gears|Crowbars]]
It can also support certain player upgrades, including additional equipped pet capacity and plot expansions.

== Tiers ==
Garden Cards has five reward tiers. Higher tiers are intended to feature stronger rewards.
