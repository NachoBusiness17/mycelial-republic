== Overview ==
The '''Invisibility Mushroom''' is an {{TierText|Legendary}} [[Gears|gear]] that was added to the game's release.

== Appearance ==
It looks the same like other gear mushrooms beside being partly transparent.

== Obtainment ==
The Invisibility Mushroom can be obtained from the [[Gear Shop]] for {{Sheckle|30,000}} or {{Robux|240}} with a '''4%''' chance of stocking.

== Usage ==
Eating it makes the player invisible for 30 seconds, Ideal for robberies, only your avatar is visible in a transparent white color; no one else can see the player.
