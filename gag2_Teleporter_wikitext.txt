== Overview ==
The '''Teleporter''' is a {{TierText|Legendary}} [[Gears|gear]] that was added to the game's release.

== Appearance ==
A grey box with a red button, the same model as the [[Pet Server Teleporters]].

== Obtainment ==
The Teleporter can be obtained from the [[Gear Shop]] for {{Sheckle|60,000}} or {{Robux|260}} with a '''3%''' chance of stocking. Currently, this item is no longer available in the gear shop.

== Usage ==
Teleports the player forward by a distance of 15 studs.
