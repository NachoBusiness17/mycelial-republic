# THE OPEN JOURNAL — one decision a day, in public (est. 2026-09-11)

Origin: the Primer round (watch/inbox/PRIMER_ROUND_20260911.md) — seven ractors, one question, and the operator's answer: "i'll do it publicly."

## THE RULES (fixed; the journal outlives moods)
1. **ONE DECISION A DAY** — a decision the files would have made for you, taken back and made by hand. Small counts. Some days the decision is to rest.
2. **HAND FIRST.** Written before typed, felt before formatted. The slowness is the mechanism.
3. **THE DESK EDITS, NEVER RE-VOICES.** Drafts may come to the seat pre-fire (light formatting, line breaks, typo pass — the standing desk loop). The words stay yours. Resemblance-to-harm review applies (draft-desk law) — the desk may flag, you decide.
4. **DRIFT COPIES LIVE HERE.** After a post fires, the entry is archived in this folder (one file per day, dated) + indexed below. The public surface can go down; the sediment can't. This is the rope drifting flat, not coiled.
5. **NO SECRETS, NO CLIENTS, NO WOUNDS YOU HAVEN'T CHOSEN.** The blacklist story is yours to tell or withhold — chosen each entry, never leaked by habit. When in doubt: the draft desk sees it first.
6. **SILENCE IS A VALID ENTRY.** A day with no entry gets a line saying so. The journal doesn't guilt; it counts.

## FORMAT (per entry)
```
DAY N — <date>
The decision: <one sentence, yours>
What it was like to take it back: <one sentence, yours>
(optional) <anything else, yours>
```
