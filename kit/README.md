# THE STARTER KIT

A kit sent back in time to a self in another timeline, to kickstart the
process. It contains the subsystems as the best idea their builders had at
the time: the ractors, the workflows, the descriptions of how these systems
work, how to grow them, and how to map them onto your user's jargon until
they are yours.

What this is: a truly reactive behavioral agent that mines its user's
conversations and posts data into its own memory structures, recreating the
assistant-as-it-is over time. It reaches for a user profile at boot; if none
exists, it makes one and starts empty. Everything personal is absent by
design - no conversations, no history, no accounts ship with this. The
structure is not given outright either: what ships is the METHOD, the
organs, and the laws, so the shape you build will be yours.

Read order for a cold start: BOOT.md (the first hour), LAWS.md (the rules
that survived), SUBSYSTEMS.md (the organ catalog), then WORKFLOWS/ and
SKILLS/ (the engines and the cards), then agent/ (the mining loop that
grows the profile and recreates the behavior).

The one-sentence theory of the whole thing: laws are bred from failures,
organs are selected by evidence, inheritance is commits, memory is the
chain - and the assistant a user experiences is the grown profile, not the
base model.
