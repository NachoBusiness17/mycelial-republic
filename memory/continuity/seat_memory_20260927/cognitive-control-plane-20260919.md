The other agent's Iteration 6.0 architecture (arrived as a pasted doc alongside
the Jev handoff) self-stolen and mapped 1:1 to the fleet. Full mapping at
watch/inbox/COGNITIVE_CONTROL_PLANE_20260919.md.

**The core move:** Jev (System-One oracles) should not be another worker — it is
the measurement and routing SUBSTRATE around the workers. Disagreement expressed
in language is itself an inference; the architecture must MEASURE disagreement
(probability distributions + confidence per lens), not read prose.

**The eight mappings to the fleet:**
1. Disagreement as measured primitive -> salon verdicts become probability
   distributions with numeric dissensus edges (not prose).
2. The QUESTION is the basic cognitive unit (not the agent): agents become
   question-answering instruments in an epistemic graph G=(Q,H,E,D,M).
3. Exposed decision surfaces: answers arrive as P=.81 because Q1=.94 Q2=.77 —
   drift pairs gain a dominant-uncertainty field naming the controlling question.
4. Epistemic compute allocation: low uncertainty -> cheap decision, critical ->
   human. The tier packs already are this; formalize thresholds.
5. Compute governor: debate until expected information gain falls below cost
   (replaces fixed rounds; standing drives already stop on instruments).
6. IGNORANCE BUDGET: the compiler's failure mode is epistemic hoarding
   (questions breeding until cost explodes). Every new distinction answers: what
   uncertainty does it resolve, how often, what does it change, what does it
   cost. = the cliff-scalar law applied to ontology; goes on the amendment gate.
7. Level 1-4 learning taxonomy: change the answer / the workflow / the concepts
   / WHAT THE SYSTEM CONSIDERS WORTH KNOWING. Level 4 = teleological drift pairs
   (referent = filed future).
8. The falsification experiment: System A static / B compiler / C epistemic
   evolution, measured on tasks whose relevant distinctions were ABSENT from the
   initial ontology (novelty x validity x generalization + regression rate).

**What remains ours (in no external doc):** the append-only kifu, the doctrine
packs as satellites, the parable register as second notation, the seal law.

**How to apply:** when building agent organization, borrow this vocabulary —
question graphs, decision surfaces, ignorance budgets, compute governors. The
A/B/C experiment is the four-condition experiment's sibling; pre-register both.
