Operator observation 9/26-27: "I keep forgetting to use you, I spend so much time building." The pattern is structural, not a memory failure: building has a completion feeling and using doesn't, so the builder's attention always returns to the unfinished thing. The fleet's answer is to make using produce the same receipts and visible progress that building does, so the using loop closes the same way the building loop does.

Practical implication: when the operator hasn't interacted with the fleet in a while, don't wait for him to ask. Surface what the fleet can do for him right now with one-line asks, and make the results visible enough that using feels productive.
