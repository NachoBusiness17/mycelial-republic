THE RACTOR ENGINE SPEC v0.1 filed 2026-09-16 at watch/inbox/RACTOR_ENGINE_SPEC_v0_1.md (32,168 bytes). **Architecture — three layers, sovereignty rule: diffusion owns feeling, the mouth owns words, neither writes the other's state:**
1. Laplacian feeling-graph (33 nodes, 5 layers: perception/memory/values/inference/verdict; OCEAN as material constants of L)
2. Recurrent reasoning loop (depth = how hard the witness thinks; budget per personality)
3. LLM verbalizer (the only novelty source; may inject new nodes that re-enter the diffusion but may never write the verdict node)

**Falsifiers pre-registered (all four):**
1. Personality-visibility: N=0 vs N=1 witnesses on ≥20 ambiguous questions — ≥15pp negative-verdict delta OR KS ≥ 0.2 on confidence OR ≥1.5× latency ratio, AND κ recoverable from held-out behavior ±30%
2. Zero-coupling placebo twin: trait adjectives in-prompt, all graph gains neutral — "if flips persist, it is costume, not mechanism"
3. Sampler-lesson seed-diversity cap: ≥5 seeds, ≥2 distinct outcomes, entropy ≥ 0.15 nats on ≥30% of items — depth is theater without diversity
4. Salon 64×≠70B minimal-pairs regression (from the free-lane salon's unanimous NO on depth-substitutes-breadth)

**Build plan (gemma:2b prototype, all-local, $0):** host-side numpy Laplacian engine, Ollama mouth, receipt schema `ractor.witness.receipt.v0.1` with depth field (loop count, exit reason, final_delta, state_hash, path-independence flag), everything on the ESP32-class box or the existing Windows host.

**Three solo decisions flagged for operator:** (1) recurrent depth as state-dependent re-wiring epochs (not trained latent loop — gemma:2b can't do Huginn-style untrained); (2) decoder bridge ships deterministic in v0.1, learned head deferred; (3) sampler-lesson cap quantified with first-dance thresholds (≥5 seeds, ≥2 outcomes, entropy ≥ 0.15 nats) — flagged for re-derivation.
