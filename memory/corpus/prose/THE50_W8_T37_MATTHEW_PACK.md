## 3. The thresholds, verbatim (so October cannot move them)

Fixed in the pre-registration before any run, reproduced here so this pack
carries them even if pages move later:

1. Warm-static approximately equals warm-append (mean SCS difference under
   0.05, two-sided t, p above 0.10): the event layer is cosmetic. Stop building
   event machinery; revert doctrine; file the null as confirmed.
2. Warm-deleting at or below warm-static: deletion is a net negative. Abandon
   the tombstone GC build; the chain stays the only memory.
3. Cold above both warm conditions: the shared prefix is a correlated blindspot
   generator. Escalate with full receipts; redesign from isolated-plus-broker.
4. Warm-append above warm-static above cold: the bet wins. Proceed to the GC
   boundary and the veto oracle.
5. Any other ordering: report verbatim, no post-hoc thresholding, amendment row
   only.

Folding-run gates, fixed in the receipt-credit spec: a single rollout must
produce all-credit receipts on base and trained models before any spend is
authorized or any comparison counts; trained accuracy below baseline on the
frozen slice means the fine-tune hurt and promotion halts; the single rollout
decides GO/NO-GO, never the thesis. The October verdict belongs to the
pre-registered battery, minimum 15 runs per condition or the result is filed as
a pilot, never as confirmation.
