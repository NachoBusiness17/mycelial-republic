# THE HAND-CARRY DOOR — operator-purchased PDFs land here

Buy the book (when we can afford it), drop the PDF in this folder, then:
    python mag/shelf_pdf.py <filename> <shelf> "<Title (Year) — Author>"

The organ shelves it into the right ractor corpus, extracts a text layer if pypdf is
installed, and records provenance: operator-purchased, dated. The clean chain of custody
is the whole point — the internet trained on stolen data; our shelf doesn't.
