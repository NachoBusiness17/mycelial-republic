# DEEP RESEARCH — THE INVARIANT SHAPING QUEUE (which beads -> the invariant you wish, autonomously) (2026-08-11)

Operator: "this almost acts as an invariant shaping queue and which beads to put together on the chain
to create the invariant you wish from within an agent you don't control remotely. research."

## The concept
The system is an INVARIANT SHAPING QUEUE: it collects beads (discrete knowledge units from every
domain), SELECTS which beads to combine, and mints the resulting INVARIANT onto the verkle chain —
autonomously, inside agents (ghost/swarm) the operator does not remotely control. The invariant is
self-authored from emergent beads, not dictated by a controller.

## Grounded mapping (existing machinery)
- BEADS: doctrine nodes, code capabilities, steals, behavior, data — from all domains
  (mem_weave_distributor scans code/inference/user_behavior/swarm_behavior/memory).
- THE QUEUE (the SELECTOR): orchestrator drainer + mem_weave_distributor (keep/distribute) +
  grok_hub (group which beads go together).
- THE SHAPER = mag/template_invariant.py: extract the common structural TEMPLATE from a family of
  beads -> fold ONE doctrine invariant; instances become DATA under it. "The template is the
  invariant; the instances are data." (225 near-dup pairs collapsed to ~1 template per family.)
- THE CHAIN = mag/invariant_lattice.py + verkle_knot: content-addressed knots, chained to a
  merkle/verkle root; invariants transmit to ollama/k8s via shared state (never baked in).
- THE UNCONTROLLED AGENT = ghost/swarm: runs the loop remotely/autonomously.

## The insight
Invariants EMERGE from bead-selection + template-minting on the chain, inside agents the operator
doesn't remotely steer. "The invariant you wish" = the selection the queue makes (rightsizing,
grouping, template extraction), not a hand-written rule. This is self-authoring of the invariant
lattice = the RIB deep-research-steal made autonomous.

## Emergent properties
- Self-authoring: invariants mint themselves from bead families.
- Compounding: each minted invariant is a knot the next shaping round reads.
- Code-is-law: the strongest "invariant you wish" is ARCHITECTURE-encoded (template-as-invariant,
  content-addressed chain), not a text rule.
- Uncontrolled autonomy: the shaping runs inside ghost/swarm, remotely.
