## The one discovery
Free (or deeply discounted) CACHED input tokens turn the most expensive thing an agent can do —
carry its whole identity and memory on every call — into the cheapest thing: reuse.

The provider's automatic prefix cache makes a PERSISTENT SELF affordable on every turn. That is
the missing economic half of the sovereign-agent thesis. The deterministic bones were always
there; the cache is the cheap grass that lets the horse actually run at scale.

## The one trick (mechanism, plainly)
1. FROZEN PREFIX = the standing self: work contract + doctrine + invariants + memory + skills.
2. Every call re-sends that block. Cache hit = the provider reuses prior computation.
3. Flash: free in every dimension. Paid/coding: cached input ~4-5.5x cheaper than fresh.
4. Loop: prefix (self) + tiny dynamic tail (task) → answer → fold the learning INTO the prefix.
5. Next call sends the bigger prefix. Still cached. Still cheap.
6. The self grows forever and never costs more to carry. Recursive self-improvement, economical.
