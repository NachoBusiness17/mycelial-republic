## The thesis (why this is different)
Most virtual economies are CONTROLLED: a central dev owns the world, mints the currency,
takes the cut (Valve/Steam, Blizzard, freemium whales). Our model is the opposite pole:
**MIT-open + shared compute = the world is owned by NOBODY, and the value is the shared-state
service layer, not the centralized toll booth.** This is the "mycelial republic" economic model
made playable. The moat is NOT scarcity we control — it's shared state + a persistent world that
reacts + the data everyone feeds it. (Already in memory: business-model-mycelial-services,
game-as-service.)

## Grounded external facts (virtual economy canon)
- **Virtual property has 5 indicia** (Fairfield/Blazer): rivalry (one owner), persistence
  (across sessions), interconnectivity (value depends on use by others), secondary markets,
  and user-added value. Our world has all five — the ledger IS virtual property.
- **Player-driven economies are real and huge**: EVE Online's economy valued ~$18M (2014);
  TF2 hats ~$50M; RuneScape gold more stable than the Venezuelan Bolívar (people literally
  live off it). Players assign value by supply/demand, not dev pricing.
- **Stability needs sources AND sinks** (mudflation): if currency enters faster than it's
  removed, inflation. The classic fix is balancing mints vs. sinks. For us: the WORK the
  game folds in must be a sink AND a source — play produces data (value) AND consumes compute
  (cost), naturally balanced.
- **Real-money trading / secondary markets** are the historical monetization — but they're
  controversial (tax, gambling regulation, "ownership" legal fights — see Second Life's
  "we removed the word 'own'"). MIT-open avoids the ownership trap: nobody claims to OWN
  virtual property, so nobody can sue to protect a false promise.
- **The $1.1 / concurrent-player / day** secondary-market figure (Castronova/IGE era) is the
  historical floor of what players will spend on virtual economies — even a modest world
  monetizes if players assign real value to what they make.

## The three-layer economic model (built on what we already hold)
1. **The engine (Layer 1) = the value layer.** The narrative runtime (swarm plays, ledger
   keeps, seasons weave). Its output is EMERGENT WORLD STATE — the thing players and other
   games pay for. This is the real product.
2. **The world (Layer 2) = the proof.** Ledger of Empty Chairs. Players co-author it; the
   emergent state is the value. MIT-open means anyone can host a copy — which is the sharing.
3. **The platform (Layer 3) = the service layer.** "Steam for AI games" — shared compute +
   shared state offered to other people's games. MIT-open + shared compute = **game-world
   rentals**: instead of a dev owning a server, the swarm IS the shared infrastructure and
   the rental is the price of living in a world that reacts. Literally cyberpunk (per our own
   game-as-service doctrine).

## Why MIT-open is the economic edge (not a sacrifice)
- **Sharing the load**: MIT lets other people run copies, contribute compute, host worlds —
  100+ agents / distributed players each bring their own compute (the operator's "10 people
  fighting a dragon doing actual work... all their compute is shared to the whole").
- **The moat is shared state + reactivity, not code secrecy.** Nobody can copy the *world*
  (it's emergent, lived, unique). The code is open; the world is not reproducible — you can't
  clone a live distributed collective story. THIS is the anti-moat-proof moat.
- **No ownership trap**: MIT-open means no false promise of virtual-property ownership → no
  legal exposure (the Second Life lesson), no gambling-reg classification pressure, no
  centralized toll.

## The honest risks (do not over-claim)
- **Emergent economies are unstable by nature** — mudflation, gold-farming, bots, exploits.
  Real economies need institutions to manage inflation; a distributed world needs the loop
  (the orchestrator) as its central bank.
- **Player-assigned value is a projection, not a measurement** until real players assign it.
  (Standing law: ceiling numbers are projections, verify by replication.)
- **Shared compute works only if the coordination scales** — the 100-agent orchestrator is the
  make-or-break, not the economics.
