The design's only hard evidence is the Deadzone steal — the market proof that the loop
works at scale (8,529 Very Positive). Everything about OUR game is Unproven by nature, and
the doc's own next steps already respect that (playtest the reprint loop BEFORE building
more rooms). The one over-claim to kill: "SOLVED BY DESIGN" — the reprint compounding is
a build + a test away from Supported. That is the falsification this audit found.
