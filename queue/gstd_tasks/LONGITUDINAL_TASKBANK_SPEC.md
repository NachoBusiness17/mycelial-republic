# LONGITUDINAL TASK-BANK SPEC - the drain's memory-measurable shape (v1, 2026-10-13)

Closes NEXT_SITTING item 2 (DUET grader co-evolution + arXiv:2610.07782's
structural null). Problem: the battery is a single-question benchmark with traces
reset between runs - by the paper's argument, the estate's memory tier is
UNTESTABLE in the current shape, and a frozen task bank saturates as cells
improve (the council becomes the old king's scales).

## Design

**1. Task rotation law (grader co-evolution).** The bank regenerates as
reputation climbs: when a cell's rolling STRUCTURE rate exceeds 0.9 over N=10
runs, that cell's next battery draws from a freshly generated task set (new
taskIds, new truths, generated by a proposer model and certified by the council
before use - proposers never grade their own tasks). Rotation resets the cell's
rolling window. This keeps STRUCTURE honest as cells improve.

**2. Longitudinal chains.** New task type: a CHAIN of k=5 tasks where task N+1's
context includes task N's trace (the answer, the receipt, the outcome). The chain
is one measurement unit. Chains test what single questions cannot: whether
carried memory helps.

**3. The memory-ablation arm (preregistered).** Each chain runs twice, order
randomized: ARM A (trace carried - the cell sees its own prior runs' receipts),
ARM B (traces reset - the cell sees each task cold). Preregistered expectation
BEFORE first run: if the mycelial memory tier is real, ARM A outperforms ARM B
on chain-final accuracy. If not, the estate's memory claim stays continuity-only
permanently, and this spec is the receipt of that concession.

**4. The falsifier.** Stated before launch: ARM A <= ARM B on >= 3 of 5 chains,
repeated across two independent sessions, falsifies the memory-accuracy claim.
Falsifier runs before any scaling. Abort condition: master TON below floor (the
greed law handles this), or any cell uncertifiable twice in a row.

**5. Cost.** Chains run on the existing five-model local battery - zero cash
cost, hours of local inference only.

## Launch order

Build chains after the next mainnet cycle (the settle path must be stable
first). The ablation arms are the estate's first honest measurement of its own
memory - the ouroboros finally weighing itself.

## v1.1 AMENDMENTS (from the outside seat's review, accepted 2026-10-13 morning)

The outside seat holds the spec to three bars; all three adopted:

1. **Longitudinal = fixed task bank re-run across WAVES, not a fresh benchmark
   per post.** The same k=5 chains are re-run across waves (W1, W2, W3...)
   with carried traces, measuring retention over TIME, not just within-chain
   dependence. Fresh generation serves the rotation law only.

2. **Memory-measurable = metrics that separate "remembered" from "re-derived":**
   - cost-to-answer delta (carried vs cold arms) - memory shows as cheaper or
     faster answers on previously-traced tasks;
   - receipt-reuse rate - the fraction of run N+1 outputs that cite run N
     receipts as inputs. If reuse is zero, nothing was remembered, whatever
     the accuracy says.
   The oracle stays: accuracy on chain-final tasks, both arms, same judge.

3. **The coverage receipt IS the drain's memory metric.** "The drain remembers"
   must be a measured quantity: checks-run / checks-checkable against the
   chain's own prior receipts. Otherwise it is exactly the unbacked quantity
   the lint exists to strike.
