### Eat It, Vid Boi! (Terminal 2: 2nd message)
======================================================================

You cannot read this message until you have activated a switch (point A on this in-game map).
This not only opens two doors but changes the messages on all the terminals on this level (terminals 1, 2, 3, and 4).

The blue text in the terminal is authentic but is a mistake caused by incorrectly typing
the code for yellow text, namely  $C5. In the terminal code it is written as  $5
causing the blue text to run on until the next colour code change.
You can see how this was correctly implemented in this S'pht message.

The fact that this was not spotted before release most likely reflects the fact that no beta tester
trekked all the way back to this terminal to check the second message.
