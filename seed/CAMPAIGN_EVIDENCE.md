# CAMPAIGN EVIDENCE DISCIPLINE

Append-only discovery campaigns stay affordable and trust-honest when three things are
pre-committed: the pass/fail bar, the replay budget, and an honest outcome vocabulary.
The evidence is allowed to half-destroy the ask's own premise.

## The scaffold, in order

| # | section | rule |
|---|---|---|
| 1 | **Certainty conditions (pre-registered)** | Write the pass/fail standard BEFORE the hunt — per claim, mechanically checkable ("all N rows anchored to a URL fetched THIS session returning HTTP 200, with ≥1 verbatim quote from fetched content"). Verdicts are scored against it, never against vibes. |
| 2 | **Sourced rows** | One row per source: URL, grade (primary/secondary), verbatim quote from the fetched bytes, date/edition read from the artifact. |
| 3 | **Replay header** | Each replay re-verifies only the TOP-N most load-bearing URLs, with exact commands + HTTP codes + byte counts logged. Everything else is marked `CARRIED, NOT RE-FETCHED` — honest carry-over, trust degrades gracefully instead of silently. Append next-session candidates. |
| 4 | **Per-claim verdicts** | Vocabulary: `WON` / `PARTIAL` / `WON-NEGATIVE` (asked for X, proved its absence) / `WON then REPAIRED` (broke, fixed, re-verified) / `HOLDS` with precision fixes. Failed fetches (403/404/bot-walls) are logged as results, not skipped. |
| 5 | **Independent lenses** | Every load-bearing claim needs per-lens confirmation ("6/6 LENSES INDEPENDENT") — convergence logged as validation receipt, with the failed/unverifiable premises named per lens. |
| 6 | **Honest nulls** | A section for what could NOT be verified: premises of the ask that failed, sources unreachable, checks proposed by nobody. Reported, not papered. |
| 7 | **Ranked implications** | What changes, ordered by cost of being wrong. |
| 8 | **Next dig targets** | The campaign grows; each replay names what it did NOT get to. |

## Why the small replay budget works

Re-verifying everything every session is unaffordable, so nothing gets re-verified and
trust silently rots. Fix: spend the budget where the verdict leans (2 URLs re-fetched
with byte counts in the case study), label the rest carried — the reader always knows
which claims are fresh bytes and which are memory.
