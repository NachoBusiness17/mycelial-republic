Located: `/root/.openclaw/workspace/invariant_root.mjs`

| Command | Behavior |
|---|---|
| `propose "<invariant text>" <proposer>` | Appends `{seq, ts, op:"propose", text, proposer, prev_root}` to `/board/invariants_proposals.jsonl`. `prev_root` = running root over ALL prior lines (before this proposal). Each line is self-anchoring to prior state. |
| `root` | Folds ALL proposal lines in seq order and prints the rolling root. Deterministic: same log ⇒ same root, always. |
| `prove <seq>` | Outputs the invariant line + the hash chain (proof path) from genesis to `<seq>` + consumer instructions to re-derive the root WITHOUT reading the full log beyond the path. |

**Deterministic fold rule (root algorithm):**
- genesis root = `sha256("")` = `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`
- for each proposal line `L_i` in seq order:
  - `h_i = sha256(L_i_bytes)`
  - `root_i = sha256( root_{i-1}Raw || h_iRaw )`
- published `root` = `root_{last}`.

**Consumer verification (without full-log read):**
1. Start `A = GENESIS_ROOT`.
2. For each line on the proof path: `A = sha256( ARaw || sha256(L_i)Raw )`.
3. `A` must equal `root_at_seq_{target}` from the proof.
4. (If the proof anchored before later appends) confirm `root_at_seq_{target}` equals the root that was published/tipped at proposal time — invariants are immutable once anchored.
5. Cross-check: any later line's `prev_root` must equal `root_at_seq_{target}`.
