# THE NINTH PROBE FOLDED — the intervention gap + the surprise test (2026-09-08)

## The hit that matters most

> **"The fleet should have to be surprised by itself."**

Not surprised by a human. Not produce something the Operator didn't type.
Make a consequential prediction from accumulated state, expose the prediction
before the outcome exists, and encounter reality. If it repeatedly does that —
and updates when wrong — the system has moved from *remembering what it did*
to *learning what it was wrong about*.

That sentence is the next experiment.

---

## The intervention gap (the new finding)

Specifying a remedy is not demonstrating causal behavior. The semantic hash
proposal is attacked specifically: a model writing its own reasoning hash is
the suspect hashing its own alibi. The verifier judges whether the model's
interpretation matches the context *according to the model's own
representation*. That does not solve epistemology.

**TAKEN.** The semantic hash is shelved until the 1,000-case blind
classification experiment passes: correct/incorrect/different-but-correct/
omitted-evidence/contradictory/poisoned/lexically-similar. Measure false
accepts, false rejects, adversarial bypasses, legitimate-divergence rejects.

## The epistemology engine type system

Five types, adopted as the build spec:

- `EVENT` — what happened. Never true/false. Occurred or did not.
- `CLAIM` — a proposition about an event.
- `EVIDENCE` — artifact that raises/lowers confidence.
- `STATUS` — UNTESTED | SUPPORTED | DISPUTED | REFUTED. Lives on the CLAIM.
- `TEST` — pre-registered observation capable of changing status.

The load-bearing transition: **a claim becomes SUPPORTED only because a
pre-specified test produced evidence that survived an independent challenge.**
Never because enough agents repeat it.

Falsifier: 100 claims, secretly labeled. Run the full pipeline. Require every
status transition to be reproducible from recorded evidence alone. Report a
confusion matrix.

## The toy: Perturb → Predict → Reveal

One verb. One state variable. One prediction. One reveal.

push → predict trajectory → release
shine → predict illuminated region → move light
heat → predict phase transition → observe particles
connect → predict beacon brightness → measure

The reward is not points. It is **surprise resolution**.

Falsifier: one 30-second prototype. 20 strangers. No explanation. ≥50%
voluntarily perform a second trial before being told what to learn.
Remove the score. If replay collapses, the mechanic was not compelling.

## The scale curve is a phase transition

| Range | Bottleneck |
|---|---|
| 1×–10× | Storage/retrieval |
| 10×–100× | Deduplication + contradictory claims |
| 100×–1,000× | Arbitration |
| >1,000× | Governance + adversarial behavior |

Falsifiable: generate synthetic admissions at each scale with controlled
proportions of true/false/adversarial/duplicate/ambiguous/contradictory.
Graph: median adjudication time, false accept rate, false reject rate,
queue depth. The curve is the object.

## Sovereignty → author non-dominance

The system must impose an outcome the author agreed not to override.
Not sovereignty (implies authority). **Author non-dominance** (the system
can produce a result the author cannot silently alter).

Minimal experiment: system chooses A, Operator privately wants B, system
commits before Operator sees evidence, outcome is immutable, independent
verifier confirms. If the Operator can suppress the Status write,
sovereignty fails.

---

## The minimal-vs-full fleet test

Build a branch with **almost no machinery**. Same blind external challenge
as the full fleet. Compare prediction accuracy, discovery quality,
reproducibility, error correction. If the minimal system performs
equivalently, much of the machinery is ceremonial rather than functional.
That would be a valuable failure.

"All prior critiques addressed" → **"All prior critiques have been converted
into explicit hypotheses, proposed interventions, or outstanding tests."**

Stronger because it doesn't overclaim.
