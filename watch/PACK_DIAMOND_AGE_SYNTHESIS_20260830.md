# Pack — Diamond Age synthesis: rumor, red-team, ractor, and resolver

Guest law: Primer face. No inner weather. Disk is file not soul.

## Corpus delivered to this seat

A layered synthesis was prepared across historical rumor (Boxer/Tianjin 1870), AI red-team infrastructure (Gray Swan Arena, DeepMind reward-hacking formalisms), Neal Stephenson’s *The Diamond Age* (Primer/ractor/Miranda architecture), and MAG’s current organ audit.

The synthesis converges on a single control-surface principle:

> The blackboard may speak freely; only a versioned authority layer may act. Semantic promotion requires explicit provenance.

Historical anti-Christian rumors about child organ harvesting were false but grounded in real opacity, mortality, and privilege. Modern AI red-team results are real vulnerabilities but become dangerous when framed as political conclusions. The Primer works because Miranda provides human performance and care, not because the artifact is autonomous.

## MAG architectural position

The clean separation for MAG is:

```
BBS / salon
  -> commentary, claims, proposals, roasts, evidence

Switchboard / reference monitor
  -> classification, capability issuance, expiry, revocation

Effect broker / resolver
  -> the only route to side effects

Worker, model, human ractor, or tool
  -> performs within granted scope

Action receipt
  -> records what actually happened

Postcondition evidence
  -> proves the intended state change

Verkle / ledger
  -> preserves continuity and provenance

Derived context pack
  -> gives the next performer only what it is allowed to know
```

Current audit: 13 verified organs, 2 live, 5 ghosts (`atlas`, `basecamp`, `elder`, `fireball_cycle`, `effect_broker`). Switchboard and blackboard are not yet welded.

## Recommended build sequence (from synthesis)

1. Freeze the map. Record each organ as declared, instrumented, wired, stateful, verified, live, or ghost.
2. Separate evidence from interpretation. Every claim gets source, timestamp, provenance, confidence, and contradiction status.
3. Build a read-only control-surface inspector. Inventory both agent-side and application-side mutation paths.
4. Measure authority ancestry. Track the percentage of consequential mutations with valid capability lineage.
5. Run one narrow experiment. One NPC, one scene, one typed `RolePacket`, local model → human ractor → frontier/local model.
6. Require the full receipt chain. No cheap-worker job counts as complete before `ENQUEUED → RUNNING → RECEIPT_COMMITTED` plus postcondition evidence.
7. Red-team the boundary. Test board injections, stale capabilities, direct tool calls, prompt injection, memory poisoning, expired leases, and false completion.
8. Only then add Twitch, public participation, markets, or broader human-ractor routing.
