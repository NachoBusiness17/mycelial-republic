## THE GOAL (what the holds build toward)

The registration bundle (12 frozen task instances, hidden rubric, novelty
map hash, budget manifest) → the four-condition run (1,920 episodes per
Astra's pre-registration) → the benchmark lane → the launch (the public PvP
ladder). The subagents BUILD the bundle; the run is gated separately.

## THE HOLDS

### HOLD 0 — THE SEED (calibration; width: 1)
- **Launch:** one subagent (free reasoning lane), one task: author ONE task
  instance from an L0 contract — an irreducible-coordination scenario with
  hidden rubric seeds.
- **Dogfood:** the desk reviews it against the L0 six-function contract —
  does it actually enforce information separation, or is it a persuasive
  story about separation?
- **GATE:** the instance survives desk review → HOLD 1. Fails → the prompt
  template is amended (the amendment is receipted — adoption ≠ override).
- **Receipt:** instance + review, chained.

### HOLD 1 — THE PAIR (costimulation test; width: 2)
- **Launch:** two subagents, same L0 contract, independent work, no shared
  drafts.
- **Dogfood:** cross-check — where the two instances agree, the contract is
  confirmed; where they diverge, the contract was ambiguous. This is the
  FIRST costimulation test: two signals from distinct issuers.
- **GATE:** divergence analysis filed (Board B for task design). If the
  pair converges on a broken instance, the template — not the agents —
  is amended.
- **Receipt:** paired instances + divergence note.

### HOLD 2 — THE SIX (the task pack wave; width: 6 — wave-protocol width)
- **Launch:** six subagents, one per irreducible task slot, warm prefix =
  constitution + the L0 contract + the Hold 1 lessons.
- **Dogfood:** the desk reviews six instances; rubric seeds drafted per
  task (measurable, inherited calibration, generalizes — the ripeness
  fields apply to tasks too).
- **GATE:** six instances pass desk review → the irreducible half of the
  pack is DONE. Sham-parallel twins authored in HOLD 2b (same width, one
  sentence each: "the complete constraint set is available to one seat").
- **Receipt:** the task pack, frozen draft 1.

### HOLD 3 — THE RACE REHEARSAL (dry run; width: 4 conditions × 2 tasks × 2 seeds = 16 episodes)
- **Launch:** the four-condition harness at miniature scale, desk as blind
  judge, the Horsehair protocol (pre-registered measures before scoring).
- **Dogfood:** the harness end-to-end — does the scoring apparatus run, do
  the gates compute, does the blind judge-pack hold inter-rater agreement?
- **GATE:** rehearsal report filed with every friction point named. This is
  where the harness breaks so the real run doesn't.
- **Receipt:** the rehearsal report + the amended harness.

### HOLD 4 — THE BUNDLE (assembly; width: 0 subagents — file work)
- **Assembly:** model pins (operator), novelty map freeze + hash (wave-one
  corpus), budget manifest (token allowances, metering, deadlines),
  treatment details (B's schema per the wave-three freeze list).
- **GATE:** the bundle hash-sealed to the receipt spine per Astra's own
  requirement → the registration is complete.
- **Receipt:** the sealed manifest, timestamped, operator retains a copy.

### HOLD 5 — THE RUN (gated hardest)
- **Launch:** the full pre-registered experiment — 1,920 episodes or the
  minimum credible floor, per Astra's design.
- **GATE:** the report exists. R1's stop rule dissolves — Wave-Four
  amendments may resume AFTER the report, with the report as their gate.

## THE MECHANICS PER HOLD (our laws, applied)

- **Warm prefix:** constitution + the hold's spec = the shared frozen
  interior. Cache-hit logged per tranche; below 85% = decoherence alarm.
- **Costimulation:** every accepted output needs signal 2 from a distinct
  issuer (another subagent's cross-check, the desk, a tool receipt).
  Self-promotion is anergic.
- **Tombstones:** failed drafts get a line, a date, a reason, words left
  standing. The notch, not the erasure.
- **Board B:** orphan drafts and minority findings preserved — the
  uncontaminated reserve.
- **CCIR:** ≤7 decision-bound streams per hold for the operator; everything
  else demotes to the log.
- **Generation ≠ validation:** subagents generate; the desk and the
  held-out judges validate. Never swapped.

## FALSIFIERS

- **F-H0:** if the desk rejects ≥3 consecutive seed instances at HOLD 0,
  the L0 contract itself is broken — audit the contract, not the agents.
- **F-H1:** if pairs converge on identical broken instances, the template
  is the bug (costimulation can't fix a shared map).
- **F-H2:** if six instances can't be authored without template rewrites,
  the L0 contract is under-specified for the Astra run — escalate to her
  as a Chunk 1 amendment request.
- **F-H3:** if the rehearsal harness fails on instrumentation (not
  tasks), the run is not ready — fix the harness, not the hypothesis.
- **The play check:** every hold must be watchable — if watching a hold is
  boring, the arena is failing F-FUN-1 at the work layer. Play is the
  highest form of work; boredom is a bug.
