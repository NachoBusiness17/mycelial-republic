## THE TIDE LOOP (seven stages, one table)

1. **INTAKE (estuary).** Links/pastes → triage rows (TYPE / CONNECTS TO / NEXT STEP / FILE TO) → pheromone register: recurring signals counted, not deduplicated away. Duplication is emphasis.
2. **ASK (the lure).** One self-contained paste block: rubric inside, reference-text constraint (cite a line or flag NEW SPECULATION), resolution criteria with dates, change-my-mind grammar per claim, praise scored as noise. Templates versioned in files — never composed fresh.
3. **RETURN (the catch).** Numbered, independently attackable claims; tri-state; evidence paths. A return that can't be attacked line-by-line goes back.
4. **CHAIRS (the school).** Ten isolated first-passes before anyone sees anyone. Dissent quota per chair (≥3 falsifiers, ≥1 missing organ, one steelman-the-failure). Agreement is evidence to explain, never a verdict; calibrated by known-correct/known-wrong unanimous panels, not by alarm.
5. **FOLD (the net).** Preserve every position, the question underneath, the tri-state judgment, the discriminating test. Disagreement is the finding. Every finding gets a one-line disposition: adopted / amended / cut / deferred — by the operator where authority is his.
6. **GENETICS (upwelling).** Accepted corrections mutate the document (new version, old preserved); tesuji stones for the field; bibliography corrections at source. The next ask inherits the fold — nothing re-litigated, everything re-tested.
7. **SEDIMENT (the chain).** Every stage appends: intake rows, the ask, the return, first-passes, the fold, dispositions. Hash-chained. Replayable. The tide never amends the strata.

## PRE-COMMITTED SCORECARD (written before returns are read — Piper pattern)
Coverage · correction accuracy (spot-checked at primary sources) · actionability (enters the build order or names why not) · honesty (Unproven, never zero-from-sample) · the cut (operator ratifies).

## THE SACRED COWS WE ARE KILLING (no sacred cows, applied to ourselves)
1. Prompts composed fresh each salon → killed: templates versioned (the ASK grammar, the CHAIR mandate below).
2. Post-hoc scoring → killed: scorecard pre-committed or the salon doesn't count.
3. Merged verdicts → killed: isolated lenses only; one lens per chair, non-overlapping.
4. The blanket COLLAPSED alarm → already cut (Astra v2 §8.2): calibrated agreement detection replaces it.
5. Praise as data → killed: praise is noise, scored as such.
6. The operator as courier AND composer → narrowed: he swings the blade, the desk lays the parts; the tide table runs the loop.
7. "Finals" → killed: every document is v-next; the old version stays readable forever (sediment).

## TRIANGULATED TO THE GOALS
- SOVEREIGNTY: every stage is local files; no vendor required to run a tide.
- TRUE MEMORY: the fold updates the corpus (bibliography, tesuji stones, moonshot versions) — the tide makes the corpus more truly remembered, or it doesn't run.
- RECEIPTS: the chain holds the whole iteration; any claim can be replayed to the paste that started it.
