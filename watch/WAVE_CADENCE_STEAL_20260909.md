## 1. THE MECHANISM AS IT RAN (Sept 7-8)

- **TRIGGER:** one operator message = one wave. A batch of ~6 (six URLs, six
  salon questions) dropped at once.
- **BURST:** ONE tool-call loop through a shared session — fetch all six,
  collect per-item. No per-item orchestration overhead.
- **TRIAGE (the 4-step loop, per item):**
  1. IDENTIFY what the input IS
  2. CONNECT it to the nearest existing organ/system
  3. Produce the NEXT EXECUTABLE STEP
  4. FILE it
  Output skeleton: `TYPE / CONNECTS TO / NEXT STEP / FILE TO` — every
  response a knowledge-graph node, never a chat message. "Findings queued as
  builds, concrete, with falsifiers."
- **HEARTBEAT (the part that made it feel alive):** between waves, a short
  call every **18-25 seconds**, one-line refrains: "the wave holds" /
  "quiet" / "standing by" / "the room remembers." Bounded idle, legalized.
- **VALIDITY:** probes run with ZERO shared context — convergence across
  independent probes IS the signal (nine probes, nine models, nine gaps →
  one convergent finding). Where they disagree, the collision is the
  finding. The manual salon "demands disagreement as admission price."
- **COURIER:** the operator hand-carries prompts into external models
  (Grok/DeepSeek/ChatGPT/Gemini/Astra) and returns responses; the fleet
  folds them in. Dogfood was one-by-one; the fix: batch all replies into
  ONE file, single digest.
- **REST:** launch bounded; after filing, the wave stands down. "The wave =
  the standing pattern that survives falsification."

**Numbers:** 6 per wave · 9 probes/models/gaps · ~60 links · ~15 external
models · $0 · heartbeat 18-25s · 46+ grounding posts verified.
