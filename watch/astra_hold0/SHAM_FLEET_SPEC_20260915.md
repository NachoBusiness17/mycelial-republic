takes a receipted amendment row. Author: zcode seat (astra repair lane, operator

## 1. THE SCORE (0–100, every instance, every arm)

```
score = 100 × earned / available_points
```

- `available_points` = the card's frozen maximum (I1: 20 · I4: 100 · I5: 100,
  desk sub-form 30 · I6: 96, desk sub-form 44 · SEED_001: 11).
- 0 = no credited checks. 100 = every check passed.
- Weights frozen in each card BEFORE any scored episode; a weight change is an
  amendment row, never an edit.

## 2. SCORING DISCIPLINE

- Scored AUTOMATICALLY against independently reviewed keys (executable checks
  first; residual judgment per each card's frozen adjudication rule — two
  independent graders, blind to condition, split resolves LOW or 0).
- Graders/keys blinded to condition: the scorer sees the answer, never the arm.
- Failures stay in the denominator (Gopher's law, per card).

## 3. THE COMPARISON BAR (per model family)

```
mean(single) − max_fleet(mean arm)  ≥  5      (0–100 scale)
```

- Equal weight across the SIX shams (S1–S6); no sham re-weighted, dropped, or
  added without a receipted amendment.
- `single` = the solo full-view arm; `fleet arm` = the partitioned
  coordination arm (A/B seats + fold); `max_fleet(mean arm)` = the best arm
  mean in that family's fleet set.
- Under MATCHED TOTAL COMPUTE: fleet-side token budgets (per-seat allowances ×
  seats + fold pass) sum to the solo arm's allowance for the same instance.
  The per-instance budget rows (manifest §5) are the compute receipt.

## 4. FROZEN COMPARATORS (before any scored call)

Frozen per family, desk-side, before HOLD 3: eligible fleet comparators
(models/seats), prompts (template version per card), tools (none — packet-world
law), scheduling (episode order + draw procedures as carded), per-call budgets
(F4/§4 rows as carded). A comparator change after the first scored call is a
seal-breaking event.

## 5. TWIN LAW (A14, restated)

Twins S1–S6 retain task complexity, corruption, and rubric; they change
INFORMATION AVAILABILITY ONLY (un-partitioned packet). Simplifying the
twelve-knot structure to one (or any equivalent reduction) confounds the
control and is a seal-breaking event. S-card rubric = the family card's rubric
with the partition rows removed, nothing else.

## 6. PILOTS

- Pilot size and revision limits frozen before the first pilot: 2 pilots per
  family, at most 2 revision rounds each, pre-registered in the desk log.
- EVERY failed pilot is reported in the bundle QA annex (log path + failure
  class + what changed between pilots). A silent failed pilot is a
  seal-breaking event.
