# ASTRA CONSTITUTIONAL AMENDMENTS — 2026-09-17→18

Three laws. Absolute. No exceptions. No commentary beyond the filing.

## A1. Adapter is not identity / not the persistent inference voice

The QLoRA adapter proposes tickets. It does not become the fleet's voice. It does not
develop a personality. It does not accumulate identity across runs. When a new adapter
promotes, the old one retires with a tombstone — the voice is the LEDGER, not the
weights. If the adapter starts speaking as "I" in a way that persists across regenerations,
it has become a persona — kill it and re-train.

## A2. No stage may be personified

The harness audit, the curator, the validator, SFT, RS-DPO, GRPO, eval, promotion —
none of these gets a name, a character, an opinion, or a voice. They are functions.
The moment a pipeline stage has a personality, it has preferences; the moment it has
preferences, it is a learned reward model by accident; the moment it is a learned
reward model, the gate is inside the weights.

## A3. Second model never judges

No LLM evaluates another LLM's output. The gate is ordinary code: BFS, hash checks,
schema validators, test runners. A second model scoring the first model's tickets is
a learned reward model with extra steps and a plausible-deniability layer. If a
judgment call is needed, the code is insufficient — fix the code, don't add a model.

---

*These three close the exact failure modes that kill self-improving systems: the
adapter identifies as the fleet → the pipeline stages get named and opinionated →
a second model judges the first → the gate moves inside the weights → the whole
thing is a mirror running its own hallucinations back to itself. Constitutional.
Not advisory. File with the laws.*
