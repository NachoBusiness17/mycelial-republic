## The law

No stat sheet lies to the player. Progression in Exanima is embodied: the physics teaches
your hands, and the number going up is your own skill, not a spreadsheet. Our MUD's basic
mechanics get the same honesty.

## Design for mud.html basic mechanics

- **Repeatable:** same seed → same world; same inputs → same outcomes. This is already the
  bones replay law — extend it to the mud sim loop so a session is a record, not a blur.
- **Reusable:** each basic system (movement, torch-light vision, melee timing, inventory,
  door rules) extracted as a named module with a harness hook. The 51-lane gate
  (scripts/test_mud_fifty.js) stays the regression law for all of them.
- **Progression:** skill lives in the player's hands — timing, spacing, light management.
  Gear and levels only unlock expression of skill; they never substitute for it. The
  every-enemy-can-kill law (Frontier Souls) carries over: the first enemy can kill you.
- **First thirty seconds:** one torch, one door, one honest enemy, no tutorial text. The
  systems teach; the game doesn't lecture.

## Falsifiers

1. A fresh player reaches the first competency moment in one sitting with zero tutorial text.
2. Two runs on the same seed produce byte-comparable event logs for the first five minutes.
3. The 51-lane harness stays green after the mechanics path lands.
