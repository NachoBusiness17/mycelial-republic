## LAW-064 — OBSERVATION GATE (premise-span subject-match)

**The law:** a citation supports a claim only if the cited text carries the claim's
SUBJECT, not merely its existence. Perturbation P4's gap: a true-but-unsupported claim
passed the gate because the cited file EXISTS. Existence is not support.

Instrument (extends `mag/cite_gate.py`, backup
`mag/cite_gate.py.bak-gatekeep-20260907`): when a claim line has a
because/so/therefore/thus/hence structure OR a numeric claim, the gate extracts the
claim's KEY TERMS (numbers + distinctive subject words, stoplist-filtered,
citation-shaped tokens masked so the pointer can never be its own subject) and checks
the cited file's text CONTAINS them — case-insensitive, streamed 64KB chunks, 1MB read
cap. Verdict tiers:

| Tier | Class | Status |
|---|---|---|
| exists + subject present (>=2 of >=4 key terms, else >=1) | `LOCAL-VERIFIED` + SUBJECT-MATCH | supported (full) |
| exists + subject absent | `EXISTS-UNRELATED` — NEW CLASS | **unproven** |
| absent/empty | `LOCAL-MISSING` | unproven |

`EXISTS-UNRELATED` is the P4 kill: the file is real but does not carry the claim's
premise, so the claim demotes BEFORE rightsizing. cite_rate still counts only
`LOCAL-VERIFIED` — an unrelated-exists citation now drags the rate down instead of
riding it up.

**Falsifier (rotation self-test, 4 cases, `python -m mag.cite_gate selftest`)** —
fixtures built under `state/cite_gate_selftest/`, removed after, originals untouched:
- A verified+subject-match -> LOCAL-VERIFIED/SUBJECT-MATCH — PASS
- B unrelated-but-existing -> EXISTS-UNRELATED, status unproven — PASS
- C missing path -> LOCAL-MISSING — PASS
- D numeric claim with subject, NO connective (numeric trigger only) -> LOCAL-VERIFIED/SUBJECT-MATCH — PASS

RESULT: **4/4 PASS.** Residual (tri-state): SUPPORTED — deterministic containment
cannot verify MEANING, only subject presence; a file that mentions the right words for
the wrong reason still passes. That is the next gate's problem (LAW-CAND-066's
criterion citation is the companion half). UNPROVEN — behavior on >1MB cited files
beyond the cap: terms in the uncapped tail read as absent (documented, capped-by-design).
