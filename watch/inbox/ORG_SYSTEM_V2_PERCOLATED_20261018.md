## V2 shape: nine compiled invariants mapped to organ changes

1. **Attestation-shaped boundary rows (G-A, G-C).** Handoff and bridge rows adopt
   the in-toto subject shape: subject digest + predicate (what produced it) +
   producer. Our V1 hash+receipt grows the predicate field; verification reads the
   row, not the claim. Sources: SLSA blog, in-toto release predicate, NIST.
2. **Docs-drift gates like tests (G-A).** The claim patrol's WARN-first flip path
   gains an external norm anchor: docs linting that blocks merges on drift is
   mainstream practice (GitLab "docs as tests", Fiberplane drift CI). Strengthens
   the operator flip call with a two-green-weeks + industry-shape argument.
3. **Supersede pointers on canon rows (G-B).** ADR status lifecycle
   (proposed/accepted/superseded-by-link) lands as fields on canon_beacon entries
   and state doc frontmatter: canon-supersedes already designed (g02); V2 adds the
   reverse pointer so a fork in the crown resolves by link, not by mtime argument.
   This is our amend-never-rewrite law independently reinvented four times.
4. **Term-numbered crown elections (G-B).** Direct Raft steal: canon_beacon.json
   gains a monotonic term; a doc claiming crown with a lower term than the beacon
   is ignored without re-election. Direct GHOST steal: two authored competitors
   resolve by weighted rule (fresher law-ack > older), never by argument.
5. **Generation closures with atomic switch (G-E).** Each genome fold is already
   sha-manifested; V2 names the closure: fold = immutable generation, beacon
   written before exit, failed checks never rewrite (canon_boot already behaves
   this way - the NixOS shape confirmed, not new code).
6. **The managed-state boundary, written down (G-E).** mag_genome.v1 gains the
   honesty row: genomes carry claims and distillates; live state (containers,
   queues, chains) is OUTSIDE the rollback guarantee. NixOS's own caveat, stolen
   before we learn it the hard way.
7. **Owner+purpose+removal-route at birth (G-D).** consumer_gate v2 (i08's
   resolver half) requires the declared Consumer to RESOLVE on disk; the Consumer
   Law text grows the ADR-flag shape: every organ registers owner+purpose, audit
   cadence, and where its removal PR routes. Seven current organs need backfill.
8. **Burn-rate escalation (G-F).** Redboard/patrols adopt SRE alerting: fire on
   consumer-visible symptoms only, dedup by fingerprint (have), inhibit while a
   cure is in flight (new), escalate by streak burn rate: WARN at first breach,
   loud at 2x bar. Attention thinning becomes arithmetic, not taste.
9. **Reachability-gated retirement (G-G).** Retiring an organ or lane requires
   the reachability check: name the entry points that reach it; zero reachers =
   lawful cow burial into the demotion register; any reacher = reroute first.
   First candidates: forge and harvest lanes (g12, zero-yield 14+ days).
