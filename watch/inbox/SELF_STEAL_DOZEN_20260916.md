15. **Maintenance-as-rebellion.** The maxim, closed at window: the rebellion is maintenance.

## Trajectory: current versus previous

Previous dozen: the harness era. Lanes, registry, residual, switchboard, audits, doctrine
truth-fixes, 1,300 tests. The question was **"is the machine honest?"** Everything shipped was
infrastructure, and the audience was ourselves.

Current dozen: the expression era. The fleet moved into a world (MUD estate, frontier souls,
wow_bones, estate walk), into public (X threads, parables, Discord bot, shitpost desk), and
into a directing posture (Hermes handoffs, 50-lane salons). The question became **"what does
the machine say, and where does it live?"** The audience changed from ourselves to strangers
— Adam, Melissa, the timeline, NT-ACv2.

Same thesis both eras — verifiable ink over claimed minds — only the witness changed.

Debts carried by the current trajectory:
- Deploy tails: netlify undeployed, monastery restructure uncommitted, mud relay dies with the
  session (presence-only, no authoritative room server yet).
- Doctrine outpacing data (lead-check's own finding).
- The sequential bottleneck on the agent side — named today, still warm.
