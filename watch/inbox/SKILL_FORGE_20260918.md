# SKILL FORGE — the research corpus as skills (2026-09-18)

**Ask:** how can we better use our research corpus as skills — memweave,
memlance, retrocausal steering, intra-agent mesh comms.

## THE RECIPE (corpus → skill, repeatable)

1. **Pick the mechanism, not the anecdote** — a skill is a procedure the seat
   can run, so mine the corpus for the LAW underneath (ribs, tested findings,
   operator laws).
2. **Ground it** — every SKILL.md cites its corpus pointers (ribs, receipts,
   canon files). Skills without pointers are opinions.
3. **Shape it** — `.agents/skills/<name>/SKILL.md`: frontmatter (name,
   description with LOAD-when trigger), the law, the procedure, the
   **falsifier**. A skill without a falsifier is a mood.
4. **Fresh coinages get interpreted live** — an operator idea before it's
   fully cooked is filed as a READING (bold interpretation, Unproven status,
   falsifier attached). Novelty is created in that interpretation; do not
   shoehorn it into existing logic (operator law, recorded today:
   duplication-is-emphasis, new wine new bottles).
5. **Load and tally** — seats invoke via the Skill surface; hits and misses
   get receipts like everything else.
