# THE SUMMIT — Game Design Document (mountain climb, 2026-09-24)

## The Verdict

The estate does not have a fun problem — it has a focus problem wearing a fun problem's clothes. Six lanes agree on the facts: mechanics are proven stealable (gray-box games become fun with zero rule changes — Juice It or Lose It, The Art of Screenshake); music-as-gameplay has exactly one shipped proof it can carry a whole game (Crypt of the NecroDancer); 'functional but not fun' is the documented pre-juice state, not a dead end. I re-verified the load-bearing estate facts myself this session: swarm.html:27-29 contains the 'DISCO SCIENCE engine... 122bpm' header and SPB=60/122/2; swarm.html:59 already increments a musicStep per 8th note; swarm.html:106 already pulses visuals on the beat during play; and a grep census across 7 game files (commands: grep -c -i 'oscillator|AudioContext|playSound|.play(' / 'shake' / 'particle' / 'localStorage') shows swarm is the ONLY game with audio markers (4), while soul_frontier has juice primitives (shake=21, particle=29) but zero audio and zero save. THE SUMMIT DECISION: ONE flagship — swarm — rebuilt so the 122bpm beat IS the ruleset (not the soundtrack), scored by a Groove Chain, juiced with the fixed Jonasson/Nijman checklist, run-looped DOORS-style (death-to-retry under 5 seconds), and gated by exactly one acceptance test: a non-operator completes a run and volunteers 'one more.' Soul Frontier merges (soul_frontier + frontier_souls + toy) and parks at P2 with Adam's design bible intact — it loses the flagship because survivors-likes is a named, saturated subgenre (Death Must Die, Halls of Torment) contested by staffed studios, while swarm's rhythm-action hybrid is uncontested and starts from the only code in the estate that already makes sound. Nothing new starts until the stranger test passes once. The summit is not 35 games that work; it is one game people choose.

## The Core Loop

Pick a line and ride it ON the beat. The procedural 122bpm disco track is the game's clock, not its soundtrack: every hazard spawns on a beat pattern, every trick only scores when landed on-beat, and consecutive on-beat actions chain a Groove multiplier while any off-beat action resets it (NecroDancer's core rule — you CAN move off-beat, it just costs you everything). Each ~20-60 second segment ends in a reward ceremony with bounded variance (outcome 1/3/5, never nothing — VS chest range under Kao's variance cap) plus one visible build choice after EVERY segment (Brotato's after-every-wave shop). The tension engine is the survivors push-pull transposed to rhythm: score pickups land off your safe line, so the on-beat line that keeps you alive diverges from the line that pays — collecting becomes a deliberate risk decision every bar (Vampire Survivors' documented mid-run dynamic). Death takes under 5 seconds to retry (DOORS) and always banks: score doubles as persistent currency buying permanent, visible power, so the death screen answers 'I'm closer,' never 'I wasted an hour' (Hades God-Mode / VS Power Ups pattern). The same verbs repeat every run, but each ~5-minute run recontextualizes them across four named stages — sparse opening, density-overtakes-skill gem tension, a breakpoint where a maxed trick-chain plus its paired item evolves into a run-defining form (VS evolution), and endgame optimization (the Lost Attic core-gameplay SPIRAL). The loop sentence: 'I died two bars before the drop — one more.'

## What Makes It Fun

1. Beat-as-ruleset tension — NecroDancer: every beat is a turn, enemies each move on their own rhythm, off-beat play forfeits the multiplier (crypt-of-the-necrodancer.fandom.com/wiki/Groove_Chain). In swarm the 122bpm track stops being soundtrack and becomes the spawn/obstacle/scoring clock — the hook no competitor can clone without cloning the whole identity.
2. Groove Chain escalation — NecroDancer: consecutive on-beat actions multiply payouts, one break resets it. The multiplier's climb is felt, not read: the shared hit sample's pitch rises per chain step (Juice It or Lose It) inside the disco track, so the audio itself is the score display.
3. Redundant-feedback juice — Vlambeer's Art of Screenshake: the same action confirmed through flash + shake + knockback + sound + particles makes identical rules feel transformed ('the player perceives the action changed the world'). Applied to the verbs used hundreds of times per run first (Woods/Swink priority rule).
4. Hit-stop weight — Smash Bros hitlag (Sakurai; ssbwiki.com/Hitlag): freezing both parties frames-scaled to impact is a visual certificate that the hit CONNECTED. Gives placeholder shapes weight art cannot.
5. Risk/reward collection tension — VS's documented mid-run dynamic (Lost Attic): density overtakes the player, so the surviving line and the paying line diverge — leaving safety to collect becomes a conscious decision every bar. This is the moment a mechanical game becomes a game.
6. Bounded variable-ratio rewards — Kao 2012 (MIT CSAIL): players prefer variable over fixed at the same mean, but NOT at extreme range; VS chests pay 1/3/5. Occasional big, never nothing — a bad roll must never read as wasted time.
7. The spiral, not the loop — same verbs, four emotionally distinct stages (Lost Attic on VS): static loops are the DOCUMENTED reason clones feel samey (20MTD and Spirit Hunters named as the failures).
8. Death always banks — Hades God Mode (+2%/death to 80%, access-ability.uk) and VS gold→Power Ups: every failure converts to visible progress, making 'one more run' rational rather than compulsive.
9. Instant-retry run loop — DOORS: death to next attempt in under 5 seconds, one input; short runs that feel substantial; procedural variation so no two runs match.
10. The veteran mountain — DOORS Modifiers unlock only after first full clear; 20MTD's Darkness ladder 0-15 makes difficulty itself the meta progression, so run #50 has somewhere to climb.
11. Audio-first telegraphs — DOORS Rush: rumble→screech→flicker, cues that work when the player isn't looking, guaranteed counterplay in every encounter, rare fake-outs for tension. In a music game this is native: the track's fills announce the wave a bar ahead.
12. The reward ceremony — VS's chest: over-the-top animation + catchy jingle with 1/3/5 outcomes (Galante credits the slot-chest jingle inheritance in the Android Police interview). The sound of a reward is as designed as the reward.
13. First-60-seconds onboarding — Mario 1-1: moving within 1 second, zero text, taught by forced encounter; VS delivers its first level-up in ~15-30s; the 'you only get 9 seconds' retention thesis (playerdriven.io). Time-to-first-reward is an instrumented acceptance gate, not a hope.
14. Input forgiveness — Celeste: coyote-time-class tolerance and one-new-idea-at-a-time presentation, proven in a 4-day PICO-8 prototype before production. Off-beat input in swarm always WORKS; it only costs the multiplier (NecroDancer's exact mercy).
15. Decision cadence — Brotato: first wave 20 seconds, a build decision after EVERY wave. A fresh choice every 20-60 seconds is the tightest pacing in the genre and the cheapest retention fix available.

## The Design Doc

### 0. Flagship mandate & acceptance gates

swarm is the ONLY active build target; everything else archived (see whatToCut). Two gates, both mandatory. GATE A (instrumented, any time): stopwatch from page load — time-to-first-input <1s, time-to-first-score <10s, time-to-first-reward-ceremony <30s (VS delivers first level-up in ~15-30s; Player Driven's '9 seconds' thesis). GATE B (the only 'done'): one non-operator, observed SILENTLY, completes a full run and volunteers to play again. The estate's prior 'playtest matrix' (2.2s automated input-pump per game, GAMES_SITE_PLAYTEST_20260921.md) is renamed honestly to liveness-CI — it is not a playtest and gates nothing. Web metrics to instrument: restart-within-5s-of-death rate, median runs per session (the 'one more run' counter IS the KPI), 1-day return rate (reference bar: Roblox D1 20%=good, 30%=great).

### 1. Beat Clock — music as ruleset

Keep SPB=60/122/2 (swarm.html:29). Promote the existing musicStep counter (swarm.html:59) to THE game clock: all hazard spawning, obstacle patterns, scoring windows and reward timing quantize to the 8th-note grid. Each hazard class owns its own beat-pattern (NecroDancer: 'enemies each move on their own rhythmic pattern') — e.g., drifters spawn every 4 beats, sweeper arms fire on the 2 and the 4, walls close on bar boundaries. STRUCTURE THE MUSIC in bars/sections so the engine can forecast: a one-bar musical fill/riser precedes every dense hazard wave — audio-first telegraphy (DOORS Rush pattern: the cue works when the player is not looking at the screen). FAIRNESS INVARIANT (the estate's own Round-3 discipline, which caught the mathematically undodgeable rock wall): no pattern ships without arithmetic proof it is dodgeable at 122bpm given the player's max speed.

### 2. Player verbs & game feel

Three verbs, introduced one at a time in isolation (Celeste rule): MOVE (ridable within 1 second of load, zero text — Mario 1-1), TRICK (landed on-beat; taught by a geometry-forced moment, not a tutorial card), and at most one dodge/phase with commitment windows stolen from Enter the Gungeon's roll spec: fixed duration, invulnerability FIRST HALF ONLY, vulnerable recovery — never whole-animation i-frames, or the verb becomes a spam button. Input forgiveness from Celeste's prototype-proven kit: coyote time on ledges, landing-window tolerance (the estate already grafted OlliOlli-class landing windows into arrakis Round 5 — reuse the discipline here). Off-beat inputs always WORK mechanically; they only reset the Groove (NecroDancer's exact mercy: failure costs the multiplier, not control).

### 3. Groove Chain & scoring

Consecutive on-beat tricks/kills build a Groove Chain that multiplies score and pickup value (NecroDancer: Groove Chain multiplies coin drops; off-beat resets chain and forfeits bonuses — here, resets multiplier and drops one chain tier, never zeroing control). The existing killMult decay (Round-5 graft) becomes Groove decay. AUDIO IS THE CHAIN'S UI: one shared hit sample, playbackRate +~0.1 per chain step (Juice It or Lose It's rising-pitch combo), mixed INTO the procedural disco so the player hears their streak climbing inside the track. Score display tweens, never snaps.

### 4. Juice pass (fixed order, runs BEFORE any new mechanic)

Per Jonasson/Nijman — rules never change, perception does. Order matters (cheapest-biggest-delta first): (1) SOUND on every verb — the census shows swarm is the only game with any audio; every trick, land, pickup, graze, death gets a synthesized voice from the existing WebAudio engine; (2) 1-frame white flash on every hit/land; (3) screenshake with VARIETY — distinct magnitude/angle per event size (Nijman's trick is consequence); (4) particles 'more than you think you need' — dust on land, sparks on grind, bursts on kill; (5) tween EVERYTHING — pickups home to the counter, counters pop-scale, nothing teleports; (6) hit-stop 1-6 frames scaled to impact, both parties frozen, bigger hits freeze longer (Sakurai hitlag). BUDGET RULE (Brad Woods/Swink): juice the verb used hundreds of times per run (ride/trick/collect) before any rare event.

### 5. Run structure — the spiral

Runs of 3-5 minutes (DOORS short-but-substantial; 20MTD ships a 10-min Quickplay for a reason). Four NAMED stages, each emotionally distinct (Lost Attic): STAGE 1 'Warm-up' (~0-1 min): sparse hazards, one verb, first ceremony by 30s. STAGE 2 'The Diverge' (~1-3 min): hazard density overtakes comfortable collection — safe line and paying line separate; the player must consciously leave the groove line to grab value (VS's risk/reward collection tension, documented as THE moment survivors games become games). STAGE 3 'The Drop' (~3-4 min): breakpoint — a maxed trick chain plus its paired item evolves into a run-defining transformed state (VS evolution: max one weapon + hold paired item → transformed form), the run's emotional midpoint. STAGE 4 'Ride-out' (~4-5 min): optimization and score-chasing against the overrun clock. Segment cadence per Brotato: first segment 20s, +5s per segment to a cap, a choice after EVERY segment.

### 6. Rewards, economy & ceremony

DUAL-PURPOSE CURRENCY (Brotato): score units count simultaneously as run ranking and persistent meta currency — every kill visibly advances two meters. End-of-segment CEREMONY (VS chest per Galante's slot-jingle inheritance): screen dim, escalating jingle, particle fountain — the ONE authored audio asset to produce first, and the highest-leverage single asset in the game. Outcome variance bounded 1/3/5 (VS chest range; Kao 2012: variable beats fixed at same mean but NOT at extreme range — a 1/50 spread reads as unfair). NOTHING WASTED (Brotato): uncollected pickups bag into the next wave's drops, never deleted. Death screen states exactly what banked this run (Hades).

### 7. Death, retry & meta

Death → restart in ONE input, under 5 seconds (DOORS). Persistent board (VS gold→Power Ups): banked currency buys permanent upgrades, each with a visible effect on the next run; a persistent 'you are X% stronger than run 1' marker (Hades God-Mode pattern generalized: the +2%-per-death assist is the optional variant, cap 80%). MODIFIER BOARD unlocks only after the first full clear (DOORS Modifiers: risk knobs that pay bonus currency) — beating the game unlocks a customizable harder second game. NUMBERED DIFFICULTY LADDER 0-9+ (20MTD Darkness 0-15: each tier unlocked by clearing the last) so run #50 has a mountain. Later, post-stranger-test: offline accrual — modifier knobs charge and chain bonuses mature while away (Grow a Garden: 'come back and see what happened' is the highest-leverage return mechanic in the research).

### 8. Telegraphs & fairness

Two-channel rule (souls lane): musical/ambient cue FIRST (works when not looking — DOORS Rush: rumble→screech→flicker), visual marker second, and hazard spawn points LOCK at telegraph time — never track the player after commit, or the telegraph is meaningless. Guaranteed out in every encounter where a hazard can spawn (DOORS: rooms with Rush always have at least one hiding spot). Exactly ONE no-windup ambusher class, reserved for late stages (DMD's Ghost: melee attack that triggers instantly, with no windup — designed pressure, used once). Occasional fake-out fills for tension (Rush's audio that stops short); fake-outs punish premature reaction, not presence.

### 9. Set-pieces & the overrun ender

One set-piece entity per milestone (a worm/void boss arriving ON the musical drop). While it is alive, regular hazard spawns PAUSE and resume on its death (DMD's boss-pauses-the-horde rule — the single rule that converts a horde into a duel without touching any other system). The ender: if a run outlives the final song, an overrun entity spawns with power scaled to the player's current Groove/score level, immune to slows, one-touch kill (VS Reaper: HP × player-level-at-spawn, CC/debuff immune, knockback negation). Optional secret: killable at extreme builds, unlocking a reward (VS Red Death). Set-piece entities never despawn when fled from — teleport back on-screen (VS boss behavior).

### 10. Onboarding (first 60 seconds)

Zero text before first input. Moving within 1 second (Mario 1-1: the first screen contains nothing but the character). First trick taught by a forced-encounter geometry moment on a safe hazard, not a card (Mario's mushroom placement: a forward-moving player cannot avoid learning it). One new idea at a time, each in isolation before any combination (Celeste Ch.1). First reward ceremony inside 30 seconds (VS cadence). Character variety is POSTPONED until after the stranger test — minute one holds exactly one idea: ride on the beat.

### 11. Audio & content

The procedural 122bpm disco engine stays — no rights, already shipping, and it is the differentiator no clone can lift without cloning the whole identity. Extend it: (a) structure songs in bars/sections so the beat clock can forecast drops (system 1); (b) the reward jingle is the one authored asset (system 6); (c) combo sample with rate ramping (system 3). Visual identity stays placeholder UNTIL the stranger test passes — VS shipped with a purchased Castlevania-style pack and coherence beat originality (PC Gamer), but art spend before the test is waste; one coherent CC0 pack replaces the fillRect look the day after Gate B passes. NecroDancer/Titan Souls prove the genre's drama is pattern-not-paint.

### 12. Platform posture & (deferred) monetization

Web canvas single-file stays until Gate B passes. No engine work — 'Write Games, Not Engines' (gamedev.net; measured: mag/ holds 1,005 top-level .py files, 32 game_*.py totaling 14,120 lines). IF a platform port ever happens, the architecture lane's verified stack applies as-is: Rojo+Wally, plain ModuleScript services (Knit is ARCHIVED Jul 2024 — its own author's guidance is plain modules plus a thin remote wrapper), Matter ECS only for the entity-heavy port, client-side VFX / server-side state, MicroProfiler on mobile. MONETIZATION: none until retention is proven repeatedly — every cited success monetized an already-fun game (The Mimic added its first pass only after Chapter 2; Brookhaven runs on engagement payouts alone). When it exists: cosmetics/revives/convenience only (DOORS revives, The Mimic's 30 R$ lantern), cosmetic-only passes (Arsenal), free content forever, status-bearing support (PLS DONATE). Honest note: a standalone web game has no engagement-payout analogue — retention is literally the only currency.

Every cited success (DOORS, Adopt Me, The Mimic, Grow a Garden, VS itself) monetized a game that was already retentive; The Mimic added its first pass only after Chapter 2 proved an audience. No fee structure rescues an unplayed game — and a standalone web prototype has zero revenue paths before retention anyway.
13. Design-level cuts inside the flagship: zero tutorial text or menus before first input (Mario 1-1); no second system in minute one (Celeste isolation rule); no unbounded reward variance (Kao's cap — 1/3/5, never 1/50); more than one no-windup ambusher enemy (DMD uses exactly one); whole-animation invincibility on any dodge (Gungeon: i-frames first half only); and, when Soul Frontier revives, stamina-as-punisher and dual action economies (souls lane: stamina is a rhythm device; pick charges OR a bar, never both).
