# THE SAME BOOK EXPERIMENT (2026-10-20)

Operator order: "make them all read the same book. Us riddled to our core
invariants. And then give them license to create, explore and find new ones
unbeknownst to them, so we can truly discover things that persist or exist
independently."

The experiment that the 600-models cosmology, the percolator, the geometric
probe, and the anti-consensus law have all been pointing at. This file is its
constitution.

## The design (four phases, each with a falsifier)

- **PHASE 0 - BAKE.** Write THE BOOK: our core invariants riddle-encoded in a
  parable (riddler-face law: teach the structure, never state the law). The
  answer key lives ONLY in this repo. STATUS: v0 exists - see the mining
  result below. 5/10 law episodes clearly present (no seat is load-bearing,
  the map/floor, deletion-is-theft staging, the ledger-before-flood frame,
  presence-is-not-authority), completion queued (H247_BOOK_COMPLETION).
- **PHASE 1 - READ.** The identical tokens to every lane: openrouter roster
  (hermes_burn), stealth idle lanes, local shelf (ollama), Beam, deepseek
  batch. Same book, same order - controlled input. Every reading banks a
  governor row (the non-handwave contract).
- **PHASE 2 - SOCRATIC MAP.** A fixed question battery per model: restate the
  rules the travelers lived by; apply them to NEW cases the book never shows;
  derive the law behind a scene. Graded DETERMINISTICALLY against the answer
  key (this repo's ten laws) - extraction score per model. This is the
  evaluation instrument he asked for: comprehension of baked structure, not
  vibes.
- **PHASE 3 - EXPLORE.** The open license: each model, blind to the others and
  to the existing bank, is chartered to propose the invariant that governs a
  domain - "you are the first to look here." Stealth idle lanes are the
  explore fleet; the window costs nothing.
- **PHASE 4 - RECUR COMPILE.** Candidates are hashed. Recurrence across >=3
  models with no shared context = independently-existing candidate (recurrence
  under reality is character) -> percolator -> memory/percolator/invariants.json
  with provenance same_book. Unique-to-one = model character (NOVEL class).
  The percolator's own recurrence and count laws are the compiler.

## Falsifiers (attached before the run, per the descent law)

- **F-sb1 (the control):** if Phase-2 extraction scores against THE BOOK do
  not separate from a paraphrase-control story with NO laws baked, the book
  carries no signal and Phase 0 is redrawn.
- **F-sb2 (recall vs creation):** if Phase-4 recurring candidates cluster only
  on the ten baked laws, the fleet is recalling, not discovering - the explore
  phase is redesigned (wider domains, no book priming in that arm).
- **F-sb3 (the consensus trap):** any candidate that only recurs after the
  models' outputs are visible to each other is struck - the independence
  requirement is the experiment's spine.

## The KV-cache answer, made honest

API lanes expose no literal KV cache. What they DO expose: Beam's endpoint
returns `reasoning_content` natively - the internal trace of a free 501B model,
at cost 0 (verified 2026-10-20). Phase 0's book was literally MINED out of that
tap: Beam drafted the parable inside its reasoning channel (numbered-word
blocks), the token cap cut the clean emission, and the reassembly script
pulled 428 words of finished prose out of the internals
(`canon/same_book/BOOK_V0_mined.md`; full trace: `BOOK_V0.beam_reasoning.md`).
True attention-level internals stay reserved for local models (ollama) - a
stretch arm, not a promise.

## Infrastructure

- Reading/exploration rounds ride the governor's carriers; every dispatch is a
  banked row; conservation applies (dispatched == banked).
- Beam free week (10-20..10-27) is the judgment-class reader and writer.
- The book joins canon/ - riddled, not decipherable; the answer key stays in
  the repo (the key file is this receipt's ten-law list, operator-only).

## What the experiment must never do

Never tell a model it was tested on the book. Never show one model another's
exploration. Never compile a candidate on a single witness. The moment any of
those three breaks, the words "exists independently" stop meaning anything.
