# TIMELINE INTEL - research batch (2026-10-22)

## 1. HeirCommit: selection is not learning

Eval question vetting before model updates cuts harmful updates by 68-83%.
Connects to the falsifier index and the congress's eval-gate design.

## 2. RL360: open-source RL infrastructure

8,192 concurrent sandboxes, 150 steps in 7 days, ~1.3M rollouts.
Long-horizon agentic RL where crash = wrong answer. Connects to the
fleet's material-rate distinction (crash vs wrong answer, the water
governor already separates these).

## 3. Floating metal-hybrid lattice metamaterial

Titanium matrix with polyurethane foam injected into struts, skeletal
density under 1.0 g/cm3, buoyant in seawater. Connects to the phone mesh
hardware (buoyant nodes) and the dwarf-ai UPS pattern (graceful shutdown).

## 4. GLiDE v1.2: #1 decision model

71.5 score, 82ms latency on RTX PRO 6000, 1.9% calibration error, open
weights. Connects to the same-book calibration experiments (1.9%
calibration error is a number worth comparing to the battery's
fabrication rates).

## 5. MemoryTax: the bitter lesson of agent memory

Stronger models improve at memory generation; memory frameworks still
help when a model can search raw history itself. Mem0 beat full context
only with GPT-4o-mini. Claude Opus 5.5 + Pi coding agent searching raw
history scored 99% at under half the cost of full context. THE direct
answer to the estate's memory architecture question: strong models with
raw history search beat memory frameworks, but weak models still need
designed memory. The implication: build the search tools, not the memory
framework, and upgrade the model when the budget allows.
