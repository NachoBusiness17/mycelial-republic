Annealing works because high T lets the system cross barriers (a width-24 lane can attempt anything) while the quench crystallizes what the melt found. The product of the 09-26 melt is 402 landed lanes (computed below); the quench's job is deciding which crystals are load-bearing.

## 6. The Maxwell demon: a three-gate sorter built from organs that already exist

Thermodynamic constraint first (Sagawa and Ueda 2008, generalized second law with feedback): a demon can extract at most kT times the mutual information it acquires, and its memory erasure (Bennett 1982) costs the same kT ln 2 per bit. So the demon only pays for itself where disorder is high: percolator yield 4.3% says measurement is cheap relative to what it saves; SPOT_PATROL's 0 warns in 108 rows says patrolling the already-sorted ledger is a demon feeding on its own exhaust. Design, three gates at existing seams:

- Gate 1, PRE-SORT (dispatcher, before burn). Compute each brief's expected payoff before opening the door: reject briefs whose slug or content canonicalizes against an already-landed receipt (extend the mag/link_library canonical_sha256 duplicate check, already wired into the free-resource-scout filing path per the B2-06 LEDGER row, from URLs to briefs); require a named artifact path and a falsifier line at dispatch (the receipt shape already demands both at landing); compute the B2-167 highest+1 renumber under a lock file at dispatch time, which kills the concurrent-board race that produced 4 errata rows and 2 permanently lost lines. This is the demon sorting molecules at the partition.
- Gate 2, MID-SORT (dissipation valve, during burn). Make the invisible visible: land the B2-443 owed --dwf-run mode in tools/provider_error_tally.py (attribute by sess_dwf-<runid> prefix, per-actor terminal cuts), and give the dispatcher a live dissipation signal: model.network.failed clusters inside a rolling window trip the hold law mechanically instead of by operator prose. EMPTY-class output (zero content bytes at done_reason=length) counts as dissipated work, retried once with think:false, never silently skipped, exactly the scripts/tide_gemma.py contract.
- Gate 3, POST-SORT (LANDED RULE demon). Close the verdict vocabulary: writer-side enum {LANDED, PARTIAL, ERRATUM, OWED, SNS, VOID}, free text rejected at write time; landed stays disk-derived, never self-report (already law, BURN_WAVE_STATE.json:1067); and repoint substance sampling at the unsorted stream: the form_over_substance detector already computes receipt_completeness >= 0.90 against build_quality <= 0.50 in mag/lane_runner.py:365 with cluster_step pure at :432 and the run_lane hook at :904, so the organ exists, it is simply wired downstream of the sort instead of upstream.

Demon self-maintenance (the erasure budget): the demon's own memory must be pruned or it becomes the next entropy source.
