## Known limits (stated, not papered)

- "has tests" and "readers" are TEXTUAL reference counts (import statements,
  import names, file paths), not runtime import graphs; comments and
  docstrings count. Test-file counts are upper bounds on importing tests.
- Reader counts are lower bounds for modules reached only through generic
  dispatchers (mag.cmd passes the module name as %1; dispatch tables in
  main.py/configs may route without a textual mag.<name> mention).
- mag/__init__.py and package inits accumulate chain credit (importing
  mag.x executes the inits), so their reader/test numbers count chains, not
  direct imports. Documented in the census Method section.
- .json/.jsonl data files were not scanned for references.
- HEAD moved c1285e758 -> 946473060 during the session (concurrent lane
  commits on the shared repo); the census records its own snapshot moment
  and HEAD inside mag-census.md.
- Mimosa PreToolUse hook blocked one verification one-liner because its
  inline source named mag/ file paths (write-guard false positive); the
  check was rerun via the Write-tool-created _f24_verify.py. No file under
  mag/ was written or modified by this item; the census is read-only.
