## Method

Instrument `_f29_silent_pass_scan.py` (banked, same directory; Python
3.11.15 venv interpreter): os.walk over the whole working tree, pruning
.git, __pycache__, and any directory holding pyvenv.cfg (that caught .venv:
23,249 third-party .py files excluded as dependencies, not repo code);
ast.parse per file (utf-8, errors replaced; a leading UTF-8 BOM is
stripped first because BOM-prefixed files are legal Python; that fix
recovered 167 files from the parse-failure bucket, 220 down to 53); a
context-tracking NodeVisitor flags every ExceptHandler whose body is only
Pass statements. A pass-only body cannot log, re-raise, or handle, so
"without logging" holds by construction; comments after `pass` do not
change the shape. Each hit records file, line, exception type exactly as
written (via ast.get_source_segment), category, single-line vs multi-line
form, enclosing def/class chain, and the try body's first source line. Git
tracked/untracked per file via `git ls-files -z -- *.py` (subprocess
spawned with creationflags CREATE_NO_WINDOW on win32 per repo law; no other
subprocess exists in the instrument).
