## 0. The pipeline in one line

`main.py context-pack` (attended surface) and 6 in-process call sites call `mag.context_pack.build_context_pack()` (mag/context_pack.py:571) which reads ~40 files/globs plus 3 live HTTP probes and returns a dict ("schema": "mag_context_pack.v1"), then `format_context_pack_text()` (mag/context_pack.py:993) renders that dict to text under a per-mode char budget using a 5-stage shed ladder; the CLI writes `memory/context_pack_latest.md` + `memory/context_pack_latest.json` (main.py:3503-3509), prints the text, then appends a census-liveness line (main.py:3520-3524). Overflow sheds are receipted as JSONL rows in `watch/inbox/PACK_OFFLOAD.jsonl` (mag/context_pack.py:34-49).
