## 1. Theory: the IB objective restated for agent-to-agent messages

- Tishby, Pereira and Bialek, "The information bottleneck method" (arXiv:physics/0004057, fetched this session; submitted April 2000): create a compact code for a signal X that maximally preserves the information X carries about a relevant signal Y; the framework generalizes rate-distortion theory with the distortion measure arising from the joint statistics of (X, Y), and the optimal coding rules solve via self-consistent equations that generalize the Blahut-Arimoto algorithm. Translated to agents: sender state plays X, the receiver's next decision (or task reward) plays Y, and the message M is the bottleneck variable. "Optimal compression for inter-agent messages" is exactly min I(M; sender state) subject to preserving I(M; decision-relevant content).
- Alemi, Fischer, Dillon and Murphy, "Deep Variational Information Bottleneck" (arXiv:1612.00410, fetched; ICLR 2017): the neural-stochastic version - compress input X into a stochastic representation Z that retains what is relevant for predicting Y, with a variational lower bound trained by the reparameterization trick; the abstract also claims better robustness to adversarial attack. This is the recipe an agent's message encoder actually implements in the papers below.
- The paper that states the agent-communication IB objective explicitly: Wang, He, Yu, Qiu, An and Rabinovich, "Learning Efficient Multi-agent Communication: An Information Bottleneck Approach" (arXiv:1911.06992, ICML 2020; full text read via ar5iv this session). Their method IMAC maximizes J'(theta_i) = E[Q_i(h_1..h_n, a_1..a_n)] - beta * I(H_i; M_i), equivalently maximize expected task return subject to I(H_i; M_i) <= I_c, where H_i is agent i's protocol inputs (observation o_i plus the scheduling message c_i) and M_i is its outgoing message; since p(m_i) is intractable they lower-bound with a Gaussian variational prior z(m_i), giving a KL-divergence penalty the network can train on. They justify bandwidth -> entropy with H(m) <= (2B log2 K)/n + d log2(delta) for a channel of bandwidth B, then bound entropy via the max-entropy Gaussian argument. This is the cleanest published statement that an inter-agent message budget is a mutual-information budget.

## 2. The MARL channel-compression line (2016-2026)

- Foerster, Assael, de Freitas, Whitney, "Learning to Communicate with Deep Multi-Agent Reinforcement Learning" (arXiv:1605.06676, NeurIPS 2016, ~2,985 citations per search): RIAL treats messages as discrete actions from a bounded alphabet (one-hot vector, 256 symbols in their experiments), i.e. a hard capacity constraint; DIAL passes messages through a noisy, discretized channel during training so gradients flow while the protocol stays effective when the channel is discretized at test time. Verified on the arXiv abstract page and via the NeurIPS 2016 proceedings hit in search.
- Sukhbaatar, Szlam, Fergus, "Learning Multiagent Communication with Backpropagation" (arXiv:1605.07736, NeurIPS 2016, ~1,803 citations per search): CommNet, continuous averaged real-valued broadcasts - the unconstrained-channel contrast case. Note the attribution: DIAL is Foerster's paper, CommNet is Sukhbaatar's; the ling lane's raw output flipped these repeatedly (sensing artifact, corrected here from the fetched arXiv pages).
- Das et al., "TarMAC: Targeted Multi-Agent Communication" (arXiv:1810.11187, ICML 2019, ~815 citations per search): learns both what to send and whom to send it to via signature-based attention (each message carries a routing signature plus content). Targeting is routing-side compression: it cuts who receives bits, not how many bits exist.
- IMAC's measured tradeoffs (ar5iv full text, Tables 1-2): predator-prey best row 32.32 (+/- 4.26) vs TarMAC 25.13, SchedNet 24.74, GACML 21.52, MADDPG w/ com 28.63; under a bandwidth stress test at |Sigma|=1 IMAC scores 51.24 vs 18.01 for MADDPG_e1 trained with the same budget - i.e. IB-trained protocols degrade less when bandwidth tightens; on StarCraft II 3m/8m, QMIX+IMAC eventually beats QMIX with unlimited communication. This is the bits-vs-reward curve the field was missing in 2016.
- 2025-2026 frontier [search-surfaced only, snippets not fetched]: "Heterogeneous Information-Bottleneck Coordination Graphs for Multi-Agent Reinforcement Learning" (arXiv:2605.17393, Duan 2026); "Robust Multi-Agent Reinforcement Learning by Mutual Information" (Li et al., TNNLS 2025, NTU-hosted PDF: policy from a minimum-sufficient-information-of-observations view); a NeurIPS 2025 poster connecting communication-constrained priors to Pac-Bayes information bottleneck theory. IB has moved from the message channel into the coordination-graph structure and the policy itself.

## 3. LLM-era inter-agent message compression (2023-2026)

- Jiang, Wu, Lin, Yang, Qiu, "LLMLingua: Compressing Prompts for Accelerated Inference of Large Language Models" (arXiv:2310.05736, EMNLP 2023, fetched): up to 20x compression with little performance loss, evaluated on GSM8K, BBH, ShareGPT, Arxiv-March23. The abstract page I fetched states the 20x compression figure but no latency multiplier; the commonly quoted "6x speedup" was not on that page, so it is OWED here. Note LLMLingua compresses prompts, not demonstrated inter-agent messages; its use as an agent-chat-history compressor is downstream community practice [search-surfaced: CrewAI-tooling writeups claim ~64% token cost savings; unverified].
- LongLLMLingua (ACL 2024 long paper, aclanthology 2024.acl-long.91; arXiv:2310.06839; verified by search this session): query-aware coarse-to-fine compression, up to 64.2% prompt compression with up to 28.5% performance improvement on LongBench and up to 4x inference speedup. Cautionary note for the free-lane law: two free-lane id claims in this area were wrong - the stealth lane gave arXiv:2402.14539 for LongLLMLingua, which is actually an unrelated spatio-temporal epidemiology paper (fetched and confirmed), and its MaAS id 2502.04133 is a tiling paper (fetched and confirmed). Titles and headline numbers were right; ids were not.
- LLMLingua-2: OWED - id and measured numbers not verified this session (stealth lane claimed arXiv:2402.05755, ACL Findings 2024, distillation-based extractive compression; not fetched, not banked as fact).
- Zhuge, Wang, Kirsch, Faccio, Khizbullin, Schmidhuber, "GPTSwarm: Language Agents as Optimizable Graphs" (arXiv:2402.16823, ICML 2024, fetched): agents as computational graphs whose nodes query LLMs and whose edges are information flow; optimizers do node optimization (prompts) and edge optimization (connectivity), recursively combinable into inter-agent hierarchies. The fetched abstract carries no numbers; the stealth lane's "10.7% accuracy / 17.7% token cost" figures are UNVERIFIED and dropped.
- Zhang et al., "AFlow: Automating Agentic Workflow Generation" (arXiv:2410.10762, fetched; arXiv page lists no venue): Monte-Carlo-expansion search over workflow executions yields 5.7% average improvement over state-of-the-art baselines across six benchmarks, and lets smaller models outperform GPT-4o on specific tasks at 4.55% of its inference cost. This is message-content shaping by search rather than by bottleneck.
- Zhang, Niu, Fang, Wang, Bai, Wang, "Multi-agent Architecture Search via Agentic Supernet" (arXiv:2502.04180, fetched; search says ICML 2025, arXiv page lists no venue): samples query-adaptive agent topologies from a supernet; uses only 6-45% of the inference costs of existing handcrafted or automated multi-agent systems while surpassing them by 0.54-11.82% across six benchmarks. Topology-level compression: the optimal message set is query-dependent.
- Other leads [search-surfaced only]: Q-KVComm (adaptive KV-cache compression for multi-agent communication), a prompt-compression-as-attack-surface paper (arXiv:2510.22963), the Awesome-Agent-Context-Compression catalog repo. None fetched.

## 4. Synthesis: what "optimal" means per generation

- Symbolic/MARL era: capacity is alphabet size; the IB restates capacity as a mutual-information Lagrangian (IMAC's beta * I(H; M)), and the measured quantity is reward per bit. The 2016-2020 arc went continuous-unconstrained (CommNet) -> discrete-capped (RIAL) -> noisy-differentiable-bottleneck (DIAL) -> targeted (TarMAC) -> IB-optimal (IMAC).
- LLM era: the message medium is natural language, so compression splits into three levers with measured returns on different axes: content compression (LLMLingua family: 20x, 64.2%), content shaping by search (AFlow: 4.55% of GPT-4o cost), and topology compression (MaAS: 6-45% cost, +0.54-11.82% performance). Nobody fetched this session measures bits-per-message against task reward in LLM swarms the way IMAC did for MARL; that gap is the research opening this ask points at.
- Bridge to this estate (first-hand, greps run this session): the fleet already operates a bounded-pointer message protocol. AGENTS.md:20: "preserve hashes and bounded pointers" in the shared artifact boundary; AGENTS.md:58: escalations travel with "brief attached, not full chat"; AGENTS.md:28: "Pay the context tax once" (encode once, reuse the compressed form); AGENTS.md:87: context-pack is a "min-token pack".
