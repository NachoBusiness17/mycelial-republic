# w4-27: Recipes as Types. The Estate Already Is a Type System

**Ask:** deep research, recipes as types. The estate's laws are natural language; design the type-theoretic compilation in which each law becomes a type constraint and each violation a type error, and name the category theory underneath. **Method:** every claim below is grounded in sources read this ask (tools/census_drift_patrol.py, tools/violation_ratchet.py, tools/workflow_gate.py, tools/config_seal.py, tools/thought_quantizer.py, tools/freshness_check.py, githooks/pre-push, mag/context_pack.py, memory/corpus/quantized_thought/*) plus two live runs (a janitor pack render and targeted greps, quoted inline). Prior-receipt numbers are marked as prior and were not re-measured. Banked at watch/inbox/burn_reset_20260927/flash50/w4-27.md with an identical copy at w4-types.md (the ask names both paths).

## 1. Thesis

The compile the item asks for does not need to be invented. It needs to be noticed, named, and then tightened. The estate's natural language laws have already been compiled into types, three times, in three materials: as grammar refinements over prose claims (census_drift_patrol.py:117-119), as fingerprint-set membership with named, signed exceptions (violation_ratchet.py:84-85, 247, 280-301), and as regex predicates over workflow scripts (workflow_gate.py:45-80). What the estate lacks is not the compilation but its metatheory: no single artifact says what these fragments have in common, which laws structurally resist compilation, and where the compile predictably loses information. That is what this card supplies, with the defects it predicts verified live.

## 2. The correspondence, fragment by fragment

### 2.1 The three-valued verdict is a type-theoretic discovery

Every checker in the estate independently converged on the same return type: 0 pass, 1 violation, 2 cannot verify (violation_ratchet.py:28, config_seal.py:15, census_drift_patrol.py:30-32, workflow_gate.py exit 2 on failed checks at 319-321). Type theory names the three: 0 means the term inhabits the type (the push satisfies the law), 1 means a negative judgment (the term provably fails), 2 means elaboration failure (the checker itself cannot produce any judgment). The estate's own B2-277 law "blind differs from stale" (githooks/pre-push:76-96, evidence file .git/census_blind_last_push.txt at lines 93-95) is exactly the distinction between a refutation and a failed elaboration, and it was paid for: the census exit class was split only after the operator saw that a gate which cannot see is more dangerous than a gate that says no. Most industrial linters collapse 1 and 2 into one red X. This estate rediscovered the trichotomy under fire, then hardened the channel after the B2-338 case bug where an uppercase OK head took the WARN arm on every green push and trained operators to dismiss the channel (census_drift_patrol.py:321-325). A type system that cannot distinguish "false" from "the checker crashed" will be muted by its own users; the estate learned this empirically.

### 2.2 Grammar refinements over natural language

The purest NL-to-type compilation in the estate is CENSUS_CLAIM_RE (census_drift_patrol.py:117-119): the law "the test census claim must be current and byte-backed" is compiled into a refinement of the string type, `(\d[\d,]*) tests [collected] / (\d[\d,]*) files \((\d{4}-\d{2}-\d{2}) census`, and parse_carrier (148-170) returns None, fail-closed, for any bullet that fails the shape, mapped upstream to exit 2 "need the claim shape" (303-309). The history in the comment block is a lesson in why laws must be types: the retired regexes took the first date and first "N tests" match anywhere on the bullet, so prose numbers ahead of the claim silently became the parse (B2-245, 84-92). The type is also owned as a spec: the ownership law at 97-116 declares the grammar is this regex plus this comment block, fixtures are frozen and never auto-synced to the live carrier, and the measured gap (B2-274 experiment, 111-116) is that rewording the AGENTS.md bullet to any other grammar leaves self-test and pytest green while the live patrol fail-closes. Two surfaces cannot see a live-carrier reword; only the typed grammar can. This is the argument for the whole program: prose laws drift silently because nothing fails when the words move.

### 2.3 Evidence-carrying exceptions and blame transfer

violation_ratchet.py compiles the law "old debt is registered, only new debt fails" (docstring 4-8) into a set-membership type: a violation is the record (rule, file, detail), fingerprinted as sha256(rule NUL file NUL detail), first 16 hex (84-85), deliberately line-free so unrelated edits do not churn the register (19-22). cmd_check (237-277) partitions hits into registered and NEW by fingerprint membership (247). The exception mechanism is not a suppression flag; it is an evidence-carrying existential: baseline-update stamps accepted date, by, note, and for file-too-long the frozen accepted_lines (280-301, 292-296), and the B2-273 growth law turns post-acceptance growth into a printed GROWTH ledger line, non-blocking but never silent (262-272, 71-80). Exceptions also rot: an accepted entry with an expires date counts as a violation once the date passes (70-72, 228-234, printed at 258-259). In blame-calculus terms (Wadler and Findler's gradual typing), baseline-update is blame transfer: the violation remains in the world, but the judgment "this is debt" is re-signed to a named acceptor. config_seal.py has the same signature for config bytes: verify fails on any modified, missing, or unsealed file (50-73), and update is a NAMED ACT with --by and --note required (8-9, 76-91). "Never loosen the hook" (AGENTS.md build discipline) is the refusal to erase casts, which is precisely the soundness core of gradual typing, enforced both socially and mechanically.

### 2.4 Time-indexed and metric refinements

Three laws carry a time index: the census goes STALE past 7 days with growth since the census day (census_drift_patrol.py:78, 250-288), boot docs go STALE past STALE_DAYS = 7 while the repo has a heartbeat within 2 days (freshness_check.py:8-11, 53), and accepted ratchet debt expires by date. The deep check is more interesting: collect_patrol (census_drift_patrol.py:196-216) compares the carrier's collected claim against the byte truth of a live `pytest --collect-only -q`, failing when the delta is COLLECT_DRIFT_TOLERANCE = 20 or more in either direction (125, 199-216). That is a genuinely dependent constraint: the truth of the claim depends on a value computed at check time, relaxed from propositional equality to membership in a ball of radius 20. The comment gives the reason in type-theoretic terms without using the words: intra-day landing noise of a live estate is tolerated below the bar (122-125). You cannot re-run the world to equality, so the estate verifies up to a metric. A future compile should make the TTL and the tolerance explicit fields of the law record rather than constants scattered per tool (see section 4).

### 2.5 The workflow gate: syntactic approximation of semantic types

The recipes are the fleet's verbs (steal, self-steal, probe, fold, verify, dispatch, sign, wash); the workflow gate is their type signature. A well-formed recipe must fan out per item (G1), pass earlier outputs into later asks (G2), carry reviewer verdicts back into revisions (G3), salvage incrementally via report() (G4), publish a deliverable (G5), land a dated receipt in watch/inbox (G6), and carry the no-fabrication and em-dash laws inside its asks (G7) (workflow_gate.py:13-31, 45-80). The checks are regexes over script text, and two of them have already hit the wall of syntactic decidability, each solved by the same type-theoretic move, manifest typing. G6's dated-stamp requirement (86-94) and G3's judge-independence marker (96-114) are soft rows: present-but-undated or present-but-undeclared makes the row not-ok with a reason while leaving the verdict and exit contract untouched (117-144). The G3 comment states the impossibility plainly: independence "is a FIRING contract, not a script line"; the dwf facade gives subagents the session model, so the gate demands a declaration, `judge-model: provider/model`, and checks the declaration (96-114). You cannot statically decide a property of the runtime firing from the source text, so you require an explicit type annotation and check the annotation. That is exactly the move of manifest typing, rediscovered in a bash-adjacent gate script.

Every check also registers a row in memory/workflows/REGISTRY.jsonl (307-317), and scenario mode validates one card per gate, each card citing a real FAIL row that shows its gate failing, with expected verdict, failed set, warn set, and exit code asserted in {0,1,2} (24-31, 165-208, 203-204). The type system eats its own dogfood: gate changes must re-prove themselves against observed failures.

## 3. The compiler that exists, and its four verified loss classes

The natural language front end is tools/thought_quantizer.py, self-described as "the standing compiler for the tiered instruction packs" (line 2). Pipeline: memory/percolator/invariants.json (live read this ask: dict with 366 invariants plus false_positives) through two-pass classification (docstring 12-19; classify() 57-79 with IMPERATIVE_RE, TELEMETRY_RE, LAW_SHAPE_RE at 39-50) into quantized packs at memory/corpus/quantized_thought/. Live compile_report.json read this ask: v0.3, in=331, refused_telemetry=2, refused_fragments=9, dedupes=13, kept=307, error_quoting_laws_kept=37, packs frontier 24 / flash 12 / local 12. The consumer seam is mag/context_pack.py:343 _quantized_laws, riding the boot pack right after the L0b objective (1063-1080).

Four loss classes, each verified this ask:

**(L1) Non-denoting terms in the environment.** The v0.3 amendment keeps error-quoting laws when imperative-shaped (37 kept per the report). The price is visible in the live flash pack: of its 12 rows, three are shell error fragments, verbatim `No such file or directory: 'Get-ChildItem'`, `'type'`, and `'powershell'` (ids de7eaa711459, d536890f0abc, ae3af609ff99 in instructions_flash.jsonl), and two more are telemetry-prefixed (`pro-21b9e9bea9 -> ok (Verify with git diff...`). The classify() logic explains it: TELEMETRY_RE refusal only fires when shape is statement or law-statement (77-78), so an error message wearing an imperative shape passes. A non-denoting law is not a false law; it is a syntax error in the type environment. A janitor seat cannot detect it and simply obeys a message that was never a norm. The compile needs a front-end check the quantizer half-has: an imperative-shaped string must still be a norm, not an event log line.

**(L2) Erasure by budget.** Live check run this ask, command and result: `.venv/Scripts/python.exe -c "from mag.context_pack import build_context_pack, format_context_pack_text; pack = build_context_pack(mode='janitor'); text = format_context_pack_text(pack, mode='janitor'); print(len(text), bool(pack.get('quantized_laws')), len(pack.get('quantized_laws') or ''))"` rendered 1196 chars with pack['quantized_laws'] present at 902 chars, and the rendered text ends `...(pack clipped)` before the laws section. The janitor tier's budget is max_chars 1200 (context_pack.py:52-57); the laws ride in policy after a ~2.2k objective (1063-1080); the hard clip truncates them out. So the law environment is fully computed and then erased in the render for the tier least able to check anything itself. Meanwhile the static checker at pre-push runs with the full environment (every ratchet rule, the census grammar, the seal). This is Siek-Taha gradual typing as a lived condition: static full, dynamic partial, with the unchecked boundary landing on the least privileged tier. The estate's own comment says the laws are directives that "must survive the clip" (1070-1074); the live render proves they do not survive it at janitor budget. The design consequence is section 4's budget_tier field: a law that cannot fit a tier's budget should be a compile-time error ("environment does not fit budget for tier janitor"), not a silent runtime erasure.

**(L3) Two inconsistent decay relations on one resource.** Producer bar: thought_quantizer.py:200 check(max_age_hours=24.0), the fossil arm demands a recompile past 24 h. Consumer bar: the render seam's own docstring says packs older than 7 days render as a one-line debt pointer (context_pack.py:343-353, age math at 373). Boot-doc bar: STALE_DAYS = 7 with HEARTBEAT_DAYS = 2 (freshness_check.py:8-11, 53). The same artifact, a compiled law, is stale at 24 h for its compiler and fresh up to 7 d for its readers. In refinement-type terms, "Fresh Law" is a TTL-indexed type and the estate has three TTLs in scope for one family with no subsumption relation stated between them. The live report timestamp (2026-09-28T16:19Z) means the pack is currently fresh, but the conflict is structural, not a snapshot accident.

**(L4) The environment is bigger than the runtime and unequally distributed.** 307 laws are kept by the compiler but the packs carry 24/12/12 (60 total); the prior s2-23 receipt computed that 283 of 307 compiled laws (92.2 percent) live in no pack. Not re-measured this ask, cited as prior. The type-theoretic name: dead definitions. They are compiled, kept in the report's kept set, and linked from nothing. A linker pass (every kept law must be reachable from at least one tier pack or be explicitly marked archived) would turn this from a census finding into an impossibility.

## 4. The category theory underneath

**Curry-Howard with receipts as proof terms.** Laws are propositions; artifacts and recipes are programs; gates are the checking derivations; receipts are the proof objects. The estate stores proofs durably: REGISTRY.jsonl rows on every gate check (workflow_gate.py:307-317), INDEX register/autoseal events (prior s2-23 census: register 4091, autoseal 1147, invalidate 135, amend 17), accepted ratchet claims with by/note dates. The reading that fits is not proof irrelevance but proof relevance: which proof you hold matters, because the audit trail is the value. Amend-not-rewrite (workflow_gate.py:320, and the harness amend contract) is intensional identity of proofs: the run id and digest (295) name the derivation, and rewriting would break the identity chain even if the proposition stayed true.

**Heyting, not Boolean: excluded middle fails off the scanned scope.** Each ratchet rule is a predicate defining a subobject of the object of estate files; the rule set SCANNER_RULES (violation_ratchet.py:51-61) is the family; the pre-push hook is the product of the characteristic maps over mag/ and tools/ (DEFAULT_ROOTS, line 43). But a subobject only exists over the scanned subcategory. For a file outside it, the law's truth value is not False, it is undefined. The estate encodes this intuitionistically and was burned into doing so: the B2-95 law (docstring 8-17, scanner_domain 64-68, prune 309-324) keeps any accepted claim the scanner cannot re-derive, because in August a routine prune reaped all 25 mimosa claims registered over watch/inbox/, a tree the scanner never scans. Their fingerprints had no re-derivation morphism, so "not derivable" was wrongly coerced to "not true". A classical checker treats not-provable as false; the estate now refuses the coercion by construction. That is Heyting semantics discovered empirically, and it generalizes: the B2-274 gap where a live-carrier reword leaves both frozen surfaces green shows the same failure one level up, at the grammar's own domain boundary. The compile should treat scanner domain as part of the law's type: a law is a pair (predicate, domain), and "complies" is only decidable inside the domain.

**Blame calculus over an enforcement lattice.** The enforcement points are boundary casts, ordered by when they can fire: pre-write hook (the s2-23 observation that a python-created twin bypassed the Write hook with zero events shows the boundary's edge), pre-submit (workflow_gate before CreateWorkflow), pre-push (ratchet, seal, census, freshness; githooks/pre-push:9-96), boot (pack load), daily patrol (schtasks deep check). The blame theorem's demand, that every dynamic failure be attributable to the boundary that cast it, is implemented concretely: NEW lines carry fingerprint plus file:line (violation_ratchet.py:255-257), GROWTH and EXPIRED name their acceptances (258-272), census blindness lands evidence on disk (pre-push:93-95), scenario cards must cite the FAIL row that witnessed the failure (workflow_gate.py:180-191). Blame with a paper trail is the estate's native idiom; the type-theoretic reading just says the trail is not bureaucracy, it is the witness term.

**The checker cannot check itself, so it meters itself.** Prior receipt arch-05: the ratchet's recursion census scanned 1220 files against 1227 actual, with 8 except-pass invisible in 2 missed test files. Not re-run this ask. The structural point stands on the live code: a scanner that must terminate cannot decide its own full extension, so coverage of the checker is a coinductive property, observed by censuses and never proven. The estate's response is the honest one a compiler should copy: price the doubt instead of claiming the theorem. The denominator law (name instrument, moment, and delta before comparing counts, AGENTS.md B2-216 bullet), the frozen self-test vectors with their ownership law (census_drift_patrol.py:97-116), the opt-in deep check with its named instrument gap (53-64), and the ratchet printing its own scope every run (`scope=N files (all)`, violation_ratchet.py:250) are all the same move: every judgment carries its own domain and moment, because the domain is not internally decidable.

## 5. What a real compile would force

Sketch, not proposal drift: one law record type, Law = {claim: Refinement (machine grammar, census-claim style), check: EnforcementPoint in {pre_write, pre_submit, pre_push, boot, patrol}, blame: Loc, ttl: Duration, tolerance: Metric, budget_tier: Tier to Presence}. The four verified defect classes become compile errors instead of lived erosion: (1) an imperative-shaped string that is not a norm is rejected at the front end (kills L1's shell fragments); (2) an environment exceeding a tier's budget is a static error naming the tier (kills L2's silent janitor erasure); (3) two TTLs on one resource fail subsumption at compile (kills L3); (4) a kept law unreachable from any tier pack is a linker error (kills L4). And one return type, Verdict = OK | Violated(evidence) | CannotVerify(evidence), which three tools already implement as exit classes and scenario mode already asserts as {0,1,2} (workflow_gate.py:203-204); the compile just stops re-litigating it per tool. The recipes keep their G1-G7 signature; the compile's contribution is that a recipe which cannot state which laws bind it, at which boundary, with what tolerance, is not runnable.
