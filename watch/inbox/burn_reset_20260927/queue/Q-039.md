## Deployment pairing (NOT landed; operator or a follow-up pass)

Auth on the host is only half of the door. For a public deployment someone must:

1. Set `NPC_GATEWAY_SECRET` (env or `.env`) on the host process, and point `Config.Gateway.url` (`roblox/src/shared/Config.luau:52`) at the host's reachable IP (today it is `http://127.0.0.1:8771/npc`, which only works from same-machine Studio).
2. Add the secret to `Config.Gateway` and send the `Authorization: Bearer` header in `roblox/src/server/NpcGateway.luau:44` (today only `Content-Type`).
3. Design note on (2): `Config` lives in ReplicatedStorage (`NpcGateway.luau:10`), so a secret stored there is readable by game clients; for a truly public host consider ServerStorage or a host-side secret store. The wrinkle is flagged here, not decided.
