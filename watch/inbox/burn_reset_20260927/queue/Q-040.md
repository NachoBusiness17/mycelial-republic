## Fixes landed

1. **Client** (`roblox/src/client/init.client.luau`, the only input-owning script):
   - `ContextActionService` service added; `ABILITIES` entries gain `fire` = the server registry name (`AbilitySlots.luau:20-23`), so keyboard and touch send byte-identical strings from one table.
   - Touch block gated on `UserInputService.TouchEnabled`, so the verified desktop path is untouched: CAS buttons (keycodes deliberately NOT bound, no double-fire of the keyboard path) for Sprint (hold: Begin/End -> `movement:FireServer("sprint", on)`, Cancel treated as release), Dash (Begin -> `dash`), and the four slots (`Ability_Fire/Thumper/Redirect/Count` -> `ability:FireServer(ab.fire)`), each with `createTouchButton = true` + `SetPosition` thumb-reach constants.
   - Cooldown chip -> button overlay: bounded poll (100 x 0.1s) of `ContextActionService:GetButton(actionName)` because the button does not exist until the engine builds the touch GUI; on success the chip re-parents into the button (transparency 1, fromScale size); on timeout the chip stays the free-floating legend (no unbounded wait, no crash).
   - Double jump for mobile: `tryAirJump()` extracted verbatim from the old Space branch; keyboard Space keeps the InputBegan entry, and `UserInputService.JumpRequest` (what the mobile jump button raises) feeds the same guard. Guard is idempotent across both entries because `airJumps` increments synchronously before a second caller checks it, so a desktop press raising both events still sends at most one `airjump`.
   - Keyboard ability branches collapsed to a lookup over `ABILITIES` (same four keycodes, same four fire strings the Q-037 pass verified end-to-end).
2. **Spec doc** (`roblox/docs/CLONED_MECHANICS.md:89`): 70->80 -> 70->82 reconciliation, attributed (see verdict row 1).
3. **README** (`roblox/README.md` Known gaps): new Q-040 bullet naming dual-path input, the chip overlay, the JumpRequest double jump, the per-player FOV verification, and the owed touch playtest.
4. **Build artifact** (`roblox/the_mountain.rbxlx`): rebuilt so the committed place is not stale (b2-108 law). Note: a sibling lane (Q-041) landed `src/client/LeaderstatsHud.client.luau` mid-pass, so this rebuild embeds their on-disk script too; their lane owns that file's commit.
