## What the ask asked

"Leaderstats page for the Mountain: build the Roblox-standard visible scorecard showing VM, Rebirths, Invariants, Summit count. Wire to existing leaderstats data."

## Existing leaderstats data (found, not invented)

The server already owns the scorecard data: `roblox/src/server/init.server.luau:200-263`
attaches a `leaderstats` Folder to every Player (PlayerAdded at :264, existing players
at :265-267) with four IntValues:

| leaderstats child | Server writer line | Feeds from |
|---|---|---|
| `Virtue Marks` (VM) | init.server.luau:204-206 | `VirtueMarks` attribute (change-signal bound :231-232, :255) |
| `Rebirths` | init.server.luau:207-209 | `Rebirths` attribute (:234-235, :256) |
| `Invariants` | init.server.luau:210-212 | `Invariants` attribute (:237-238, :257) |
| `Summits` | init.server.luau:213-215 | count of `Summit_` prefixed attributes (:240-248, :258-262) |

Grep confirmed no client reader of `leaderstats` existed before this item: the only
prior hits were the server block itself and a MudBasecamp comment referencing the
retired server poll (`MudBasecamp.luau:359`). The on-screen page did not exist.

## What landed

1. **New client page** `roblox/src/client/LeaderstatsHud.client.luau` (new file, --!strict):
   - Own `ScreenGui` "LeaderstatsHud", `ResetOnSpawn = false`, DisplayOrder 10, parented
     to `PlayerGui` - the estate HUD pattern (init.client.luau AbilityChips, CathedralMapHud).
   - Panel pinned top-right (`AnchorPoint (1,0)`, `UDim2.new(1, -8, 0, 36)`): 36px clears
     the Roblox top bar (same offset the cathedral panel uses to clear the sphere chip),
     and the right column was the one free wall (cathedral panel holds the left, chips
     bottom-right, chat log bottom-left).
   - Four rows: VM, Rebirths, Invariants, Summits - name left (Garamond), value right
     (Code font), PANEL/INK palette matching the tree's other HUDs.
   - Wiring is read-only, single source of truth: `player:WaitForChild("leaderstats")`,
     then per row `stats:WaitForChild(<child name>) :: IntValue`; paints `.Value` once at
     bind, then rides each IntValue's `Changed` signal. No polling (the t56 law that cured
     the server's leaderstats poll applies client-side too). Before replication each row
     reads "..." - an honest blank, never a fabricated 0.
   - Respawn-safe: the folder lives on the Player, not the Character, and ResetOnSpawn is
     false, so no re-bind path is needed.
2. **Doc** `roblox/README.md`: one bullet in the mesh-layer list naming the page, its
   file, the four stats, and the read-only/single-truth contract (M-key player list stays
   the Roblox-standard view).
3. **Build artifacts** `roblox/the_mountain.rbxlx` + `roblox/sourcemap.json`: regenerated
   by the gate so the committed place is not stale (b2-108 law).
