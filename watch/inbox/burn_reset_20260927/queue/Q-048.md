## 1. The two shapes being composed

**Shape A, the ghost's memory states.** `ghost_memlance.index()` is the source
of truth: real files on disk, one state each, with a deterministic grounding
verdict (UNVERIFIED_MARKERS dominate, `mag/ghost_memlance.py:109-112`) and a
relevance score that is tag/title overlap plus a +3.0 verified bonus
(lines 247-259). The anti-hallucination contract is the module's core: select()
returns only real bytes with provenance, never memory-of-memory (docstring
lines 17-23). Measured scale: 4,237 states, 11.2% verified, biography
dominating at 4,000 (the `_MAX_FILES = 4000` cap at line 81).

**Shape B, the quantizer packs.** `thought_quantizer` compiles a raw
invariant stream into tiered packs: dedupe by 60-char signature, refuse
fragments (<25 chars) and pure telemetry, weight = recency x shape (raw counts
are provenance only), tier the output frontier / flash / local, write a
compile report, and arm a staleness check. `context_pack._quantized_laws`
proves the read side: the pack rides the boot context, and a stale fold
renders as a visible debt line instead of law (context_pack.py:361-363).

The ask: give Shape A the Shape B treatment, without breaking A's
anti-hallucination core.

## 2. The lattice (geometry)

A quantized lattice over memory states. One cell per (kind, seam, recency
bucket). Axes:

1. **kind**: the nine existing kinds from INDEX_ROOTS (ghost_memlance.py:70-80).
   No new taxonomy; the fold must not invent categories the index does not
   already carry.
2. **seam**: the theme cluster. The vocabulary is the wave's seam tokens, the
   same one `select_wave` already borrows from `mag.osculating.geometry()`
   (ghost_memlance.py:315-324). A state joins a seam cell when its title/kind
   tokens overlap the seam vocabulary; states with no seam overlap fall into
   their kind's "flat" cell. The seam axis is deliberately additive and
   reranking-only, the same law the wave already obeys: it reranks what is
   grounded, it never manufactures membership.
3. **recency bucket**: the four thought_quantizer bands (2d / 7d / 14d / 30d,
   tools/thought_quantizer.py:82-96) plus a fifth "cold" band, so the lattice
   has a resolution axis like auto_quantize's L0..L5 ladder (hot = raw and
   fine-grained, cold = coarse cells).

A cell is the quantized unit: the memory-state sibling of state_quantizer's
quantum summary knot. Reading one cell stands in for reading its N member
states, the same N:1 compression state_quantizer states in its docstring
(lines 15-19).

## 3. The fold operators (deterministic, $0)

Per fold pass over `ghost_memlance.index(refresh=True)`:

1. **GATE (hard, first).** A state enters a cell's law layer only if
   `verified` is true by the existing marker verdict. UNVERIFIED_MARKERS keep
   their dominance (ghost_memlance.py:62-67, 109-112). Unverified states land
   in the cell's derived layer, flagged, never promoted. With 88.8% of the
   index unverified today (measured above), this layering is the load-bearing
   wall, not decoration.
2. **DEDUPE.** Merge states sharing a 60-char signature
   (tools/thought_quantizer.py:103-107 precedent); member paths accumulate;
   counts stay provenance and never become weight (the thought_quantizer law
   at lines 19-20).
3. **WEIGHT.** Cell weight = recency band score x grounding shape x the
   existing relevance signal, generalized from `_score` (tag hit 1.0, title
   hit 2.0, verified +3.0, ghost_memlance.py:247-259). No new scoring
   vocabulary; the fold reuses the selector's own arithmetic so a cell never
   ranks above its own best member.
4. **AGGREGATE per cell.** dominant tags (top 5), ts range, verified_fraction,
   member path list (bounded pointers, never full text), and a drift scalar:
   cosine distance between the earliest and latest member's tag-vector over
   the seam basis. The drift arithmetic is state_quantizer's
   (mag/state_quantizer.py:206-216) applied to tag vectors instead of theme
   vectors.
5. **TIER at read time.** The pack tiers are renderings, not storage:
   frontier = member excerpts; flash = first-line imperatives capped at 220
   chars (to_flash precedent, thought_quantizer.py:110-113); local = 10-word
   laws (to_local, lines 116-118). Tier rendering sees ONLY the verified
   layer of a cell.
6. **ANCHOR.** Every cell row carries {cell_id, fold_id, sources [paths],
   fold_ts}. `trace_state` (ghost_memlance.py:345) is already the tool that
   walks a cell row back to real bytes; the anchor exists so that walk always
   terminates on disk.

## 4. Artifacts and surfaces

- Fold log: `memory/ghost/memlattice/fold.jsonl` (one row per cell per fold),
  sibling of state_quantizer's summary_knots.jsonl
  (mag/state_quantizer.py:49-50).
- Fold report: `memory/ghost/memlattice/fold_report.json` with the census
  shape thought_quantizer already established (in / kept / refused / dedupes /
  cells / per-kind / input roots) plus one new field the chain-side fold
  lacks: **source_nonempty**, a hard count of states actually read. See the
  caution in section 7 for why this field is non-negotiable.
- Staleness: a check mode at the 24h bar (thought_quantizer.py:200-217
  precedent) plus the read-side 7-day debt pointer (context_pack.py:361-363
  precedent). The fold is deterministic and $0, so the honest design is fold
  on demand when the report is stale, never a silent stale read.
- Retrieval, two stage: stage 1 scores CELLS (dozens, not 4,237) by goal-token
  overlap with dominant tags, weighted by recency band and verified_fraction;
  the wave bias applies additively at stage 1 only. Stage 2 runs the existing
  `select()` restricted to winning cells' member paths. The wave keeps its
  standing law (reranks what is grounded, ghost_memlance.py:303-342); the
  lattice only changes where candidates come from, never how they are judged.
- Injection: a one-line-per-top-cell lattice digest could ride the same seam
  `_quantized_laws` uses (context_pack.py:328, injected at 902, rendered at
  1058-1061), with the same visible-staleness law. This is optional phase 2;
  the retrieval two-stage is the phase 1 payoff.

## 5. Expected payoff, from the measured numbers

The dominant cost is the biography wall: 4,000 verkle-knot states (capped at
`_MAX_FILES`, ghost_memlance.py:81) are scored on every `select()` call. First
fold win: kind=biography collapses into cells by month bucket, so stage 1
scans dozens of cells while stage 2 stays exact. Second win: the 11.2%
verified fraction becomes a first-class lattice property (verified_fraction
per cell), so "show me only grounded memory" becomes a cell filter instead of
a post-hoc sort.

## 6. Laws carried through (the no-drift list)

1. Never fabricate: a cell with no member paths is refused; excerpts are real
   bytes only (ghost_memlance.py:17-23 contract).
2. Unverified never promoted: marker dominance is inherited, not re-decided.
3. Telemetry refused; error-quoting laws kept when imperative-shaped (the
   v0.3 heal, thought_quantizer.py:12-20, 149-151).
4. Counts are provenance, never weight (thought_quantizer.py:19-20).
5. Soft decay, nothing deleted: the raw index stays append-only; cold cells
   stop ranking but their members remain on disk (memory_consolidate.py
   principle, lines 19-26).
6. Bounded pointers: cells carry paths and capped excerpts, never full text.
7. The wave reranks, it never selects-in (ghost_memlance.py:303-342).

## 7. Verified caution the design inherits

`mag/state_quantizer.py:48` sets VERKLE_CHAIN to the placeholder string
`memory/biography/# CHAIN_QUERY_MIGRATION_NEEDED: replace with chain.tail()
or chain.by_type()`. I ran `ls` on that path this ask: it does not exist.
`_read_jsonl` returns [] on a missing file (state_quantizer.py:61-63), so the
chain-side fold runs on an empty source and would still write a "fresh"
summary. The lattice fold must fail loudly on the same condition: the
source_nonempty field in section 4, and a fold over zero states is exit-error,
never a published empty lattice. This is the single most transferable lesson
from the existing quantizer to this design.
