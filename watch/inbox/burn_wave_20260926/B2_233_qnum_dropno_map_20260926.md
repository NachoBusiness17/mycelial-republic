## Work done

Built the map as a min-cost sequence alignment, not a row-index assumption: (1) classified qdrops rows (trip_q / caption_id / unmarked) from name+trip signatures and caption-ledger ids; (2) mined unique content pairs from triage readings via TEXT-prefix containment and media-token lookup, filtered for anchor-order admissibility and uniqueness; (3) ran per-anchor-interval dynamic programming (states row x q_num; transitions include-as-Q, skip-as-interloper, mark-missing; costs: unmarked-include 1, caption-skip 1, trip_q-skip 2, plain missing 3, evidence-conflicting moves 8; anchors hard); (4) parent-pointer reconstruction, merged intervals, wrote the meta+map jsonl; (5) re-verified everything from the landed file bytes in a second process. Two of my own earlier attempts are disclosed as falsified en route: tripcode-rank-only (16/16 anchors MISSED, 262 rows short) and content-matching-only (34-42 pairs, cannot cover the corpus) - the alignment is what the anchors actually force. The 196 alignment_unmarked rows are the honest weak class: identified by minimal-cost fit, flagged per row so any consumer can demand stronger evidence for exactly those. Temp scripts stayed in temp; the landed artifact is the jsonl + this receipt.
