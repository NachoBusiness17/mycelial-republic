## Work done

Spec first: the hook comment block states the trigger arms, the cost, the stdin contract (one ref line per pushed ref: local_ref local_sha remote_ref remote_sha), the WARN-ONLY choice and the flip convention before any code. Implementation: two fixed pathspecs; CAPTION_CHANGED folds three sources into one flag: git diff --quiet HEAD over the pair (covers staged and unstaged), git ls-files --others --exclude-standard over the pair (untracked), and per pushed ref git diff --quiet remote_sha local_sha over the pair. Stdin is consumed exactly once, guarded by [ -t 0 ] so a manual tty run reads empty (the blocks above it never read stdin); ref lines are split into 4-word groups so multi-ref pushes process every group; branch deletions and unborn remotes (all-zero shas) are skipped as no-range. WARN-ONLY first landing per t40 precedent, with the sibling-tree rationale recorded in the comment: B2-242/243/244 showed concurrent lanes share this one checkout, so an enforcing gate could block an unrelated sibling push on a sibling's half-done generator; TODO-FLIP-TO-ENFORCE notes the operator flip. The brief's alternative arm (a scheduled verify landing its output in watch/inbox) was not taken: the hook fires in the exact window the falsifier names at 0.4s cost, and the scheduled beat is filed as self-feed B2-269 instead. The receipt is registered through the append-only watch/inbox/index_events.jsonl log, not a whole-file INDEX.json rewrite (touch law, B2-221 whole-file-rewrite precedent). No tests/ fixture: the three prior caption receipts each found zero tests referencing the module, and the gate itself is the hook. scripts/ sits outside the mag/+tools/ ratchet scope; ratchet PASS on the changed set at lane start and at lane end.
