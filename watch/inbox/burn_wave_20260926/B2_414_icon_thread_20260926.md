# B2-414 receipt: drop() ignores its icon argument (2026-09-26, lane SW-03)

## Verdict

LANDED, companion-.lnk route per the spec. The dead ico_line ('start "" /D "%CD%" /B >nul 2>&1', a no-placeholder line that launched nothing and never referenced the icon path) is removed from drop()'s .cmd body; the spec paragraph is filed in the module docstring first (a plain .cmd cannot carry an icon; the icon belongs on a .lnk via drop_shortcut's IconLocation); and when an icon file exists drop() now lays a companion <name>.lnk pointing at the .cmd with IconLocation set, recording companion_lnk/companion_status on the .cmd ledger row. auto() still passes mag_agent.ico, so every known-action drop carries a real icon on the .lnk instead of a dead line in the .cmd. 5/5 tests pass, including both brief falsifiers (a .cmd whose bytes reference no .ico path; the auto("secret") path no longer emits the dead line).
