# B2-59 receipt: MIPROv2 full-text dig (arXiv 2406.11695) 2026-09-26

## Verdict

The prompt-law v2 amendments hold: neither stolen nor vacuous. The paper names it MIPRO; "MIPROv2" appears 0 times in the arXiv text (only in DSPy code). It ships zero protected-section or anchor features: candidates mutate free-form instructions and demos jointly, the seed survives only as candidate arm 0 plus one unpaired baseline trial, adoption is best-of-N argmax with no regression guard. Kill condition F1 ("a shipped optimizer that natively locks a user-fact block, or hard-anchors candidates to p0") is not triggered. New finding: dspy ships ReAnchor (@experimental) in the same tree, natively implementing amendment D's adopt-else-restore gate over decision parameters with a 5-fold check; name it beside TARA; its fold check is a steal candidate for amendment D.

## Evidence

- Joint mutation space, abstract (live bytes): "we factorize our problem into optimizing the free-form instructions and few-shot demonstrations of every module". Code: mipro_optimizer_v2.py:766-777, `trial.suggest_categorical(f"{i}_predictor_instruction", ...)` plus `f"{i}_predictor_demos"` per predictor.
- Loop shape, paper F.5: "MIPRO proposes a complete set of T instructions per module ... and bootstraps a complete set of K task demonstrations per module ... all upfront"; "We use the sampling rule from the Tree Structured Parzen Estimator"; "All latent variables in the Bayesian Model are initialized with a uniform prior". Code: step 1 bootstrap demos, step 2 GroundedProposer instruction candidates, step 3 `optuna.samplers.TPESampler(seed=seed, multivariate=True)`, minibatch evals with periodic full evals, argmax return.
- No protection: protect/anchor/lock/verbatim/preserve/immutable/frozen return zero hits across the 107,626-char paper text. Lesson 3: "our instruction optimizer even helps correct mistakes in the seed prompt" (the seed is rewritten, not anchored). Appendix H shows seed "P1: context, question -> answer" wholly rewritten by trial 10.
- Seed handling, code: `instruction_candidates[i][0] = get_signature(pred).instructions`; "Add default run as a baseline in optuna (TODO: figure out how to weight this by # of samples evaluated on)"; adoption is `if not minibatch and score > best_score`, and amendment D already rules the shape out: the guard "is not a best-of-N selector".
- ReAnchor, reanchor.py:24-26: "It keeps each fitted configuration only when it beats the original behavior and passes a fold check; otherwise it restores the original configuration, including absent field entries." calibrate.py:22: "A setting stays unless a candidate scores strictly better and the gain holds across folds." FOLDS = 5. Scope is decision thresholds, cuts, weights in predictor fields, not prompt text, so F1 stands.
