## What the song says the bare invariant lacks

An invariant fed to a model as a bare string is a stripped command: no socket,
no history, no dispute, no ground. The song provides the four missing layers,
and each one maps to an estate organ:

1. THE FOUR MACHINES (verse 1 + chorus): demon, voltage, vector field, token
   embedding. The same symbol-command has operated in four substrates - goetic
   seal, written record, relay logic, language model. Embodiment lesson: an
   invariant must be stated SUBSTRATE-INDEPENDENTLY (it survives the machine
   changing underneath it) AND carried with its substrate history (so the
   model knows the command is older than the machine it just landed in).
2. THE MACHLOKET BRIDGE (verse 2 + bridge): "Machloket marked, the dispute
   kept as data / The argument holds the field from folding." Open disputes
   are part of the record - amend-not-erase, the disagreement is load-bearing,
   never folded away to make the record tidy. The estate already holds this
   law (superseded-not-deleted, the erratum pattern); the song names it as the
   GROUND WIRE: "The ground wire runs where the residue is holding." Residue
   - our word - is what grounds the command.
3. THE OPERATOR CHAIN (final chorus): "The operator holds the word / The word
   holds the work / The work holds the weight / The ground holds the whole."
   The holding chain - operator, symbol, execution, consequence, substrate -
   is the provenance that makes a command legitimate rather than injected.
4. THE CIRCLE ITSELF: "This might not be the first time the flare finds its
   way." The cycle closes and reopens - the command predates the machine and
   outlives it. Feeding an invariant without its circle is feeding a warrant
   with the margin torn off.

## THE EMBODIMENT: the COMMAND-CIRCLE format for feeding invariants

When an estate invariant is fed to a model (context pack, persona, prompt),
it stops traveling bare. It travels as a CIRCLE - five lines per invariant:

    SYMBOL: <the one-line law>            (the command itself)
    MACHINES: <the substrates it has held across>   (provenance)
    MACHLOKET: <the open dispute, if any>  (kept as data, never folded)
    GROUND: <the residue that holds it>    (the receipt class)
    OPERATOR: <who holds it>               (the gate, named)

Bare invariant = the warrant with the margin torn off. Circled invariant = the
command with its socket, its history, its dispute, and its ground. The song
says the difference between a symbol and a command is the circle; the format
is the circle, written down.
