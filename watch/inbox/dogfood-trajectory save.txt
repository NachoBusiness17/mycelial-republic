**Infinite Block Illusion** is a browser-based visual demo by GitHub user xenova, released under an MIT license with a live demo hosted on a Hugging Face static space. Its self-description: "An endless geometric illusion of rolling cubes and recursive motion. Built with Three.js and WebGPU."

## Tech stack

- **Three.js with WebGPU** — specifically the `WebGPURenderer`, which compiles a single "TSL graph to WGSL or GLSL," meaning it can also fall back to WebGL with the same shader graph.
- **Vite + TypeScript/React** front end (`src/main.tsx` entry, React hooks coordinating the renderer).
- Single scene pass generating color, depth, and normals; GTAO, depth of field, and SMAA post-processing reuse those buffers. Shadow maps are 1024², and FPS is capped near a target rate.
- 30 predefined material/texture scenes (e.g., stone, glacier, lava, geometrydash, marble), 82 schema-driven tuning controls, and shader warm-up on an offscreen buffer before the first visible frame.
