# Fleet research lens — portable model packet

Start with **model-handoff.md**. The main synthesis is **research-brief.md**. Then read **[orphans-and-connections.md](orphans-and-connections.md)** for underconnected ideas and candidate combinations.

The corpus records the best ideas available at the time. Evidence status and exploratory value are separate; this packet preserves both.

| Artifact | Purpose |
|---|---|
| source-catalog.md / source-map.json | All 37 input files, roles, hashes and coverage |
| evidence-excerpts.md / .json | Selected line-addressed source passages, clearly marked as data |
| claims.json |36 scoped tri-state claims with confidence and change criteria |
| relations.json | Typed source/claim/research/test links; “informs” is not “proves” |
| research-program.md / experiments.json |15 discriminating proposed studies |
| glossary.json | Translation from local vocabulary to operational meaning |
| external-references.json | Prior and new research, with inspection limits |
| citation-candidates.json |123 discovered reference URLs; unverified by extraction |
| session-export-structure.json | Structural count of the 325-message export |
| prior/ | Retained earlier brief, audit evidence and draft protocols |
| orphans-and-connections.md / orphans.json / connections.json | 12 candidate orphan motifs and 10 testable connections, with attribution and novelty limits |
| discovery-excerpts.md / .json | Additional source passages for the discovery map |
| orphan-coverage.json | Source-graph coverage, explicitly distinct from idea completeness |
| manifest.json / validation.json | Package hashes and structural checks |

**Scope:** source-and-claim mapping with selected close reading, not exhaustive adjudication of every transcript line. No live fleet mutation, external messaging or publication was performed. Original transcripts are not wholesale bundled; their origin paths/hashes and selected excerpts are supplied. A receiving model needs the relevant original if a claim depends on an omitted passage. No artifact in this package grants execution authority.
