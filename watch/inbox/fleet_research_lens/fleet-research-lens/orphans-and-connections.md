# Orphans and candidate connections

Version 1.1 · 2026-09-16 · Generative supplement to the mapped research brief

The operator describes this corpus as **“the best ideas we have had at the time.”** Read it as a dated research notebook: evolving mechanisms, metaphors, doubts, experiments and aspirations. A hypothesis need not be proven to deserve preservation. An earlier mistake may still contain a useful question. An audit should prevent unsupported promotion, not erase the search that generated the idea.

This supplement adds the generative half of the map: what deserves another look, what lacks a useful connection, and what could be tested by combining separate strands. **Supported / Disputed / Unproven describe evidence; they do not rank an idea’s creative worth.** Research lifecycle (seed, open lead, test candidate, dormant, superseded) is a separate field. A proposal can be Unproven and worth testing; a measured result can be Supported but irrelevant to the next decision.

“Orphan” here means an underconnected motif, an unbuilt bridge, an unresolved measurement or a parked branch. It does not mean the operator forgot it, that nobody developed it, or that it is absent from the live system. All 37 source files already have a substantive claim link, even after excluding the inventory claim. That graph result does not establish complete idea coverage. The twelve candidates below arose from a second targeted reading; the list is not exhaustive.

“Novel connection” means newly surfaced or made more concrete in this dossier. Several are recovered from the corpus itself. Each entry credits its precursors and names what this review adds. **No first-in-literature claim is made.** The external map supplies research context already inspected; it does not establish novelty or validate the combinations. No new literature-wide novelty search was conducted for this supplement.

## A useful first reading

Start with **O01 → N01** for the recoverable-representation contract, **O10 → N06** for correction across derived products, and **O12 → N09** for testing what this map hides. These are proposed first investigations because their smallest tests can use existing text and disposable fixtures; this ordering is an editorial judgment, not a measured ranking.

Keep **O06 → N08** as an explicit physical-computing branch and **O05 → N07** as a preservation-and-dissent branch. Neither needs to be forced into the current orchestrator to justify keeping it.

The most useful organizing connection is **N02**: an idea can be stored, explored, questioned and returned to without being granted evidential standing or authority to act.

### O01 — The EXACT / QUANTIZED / DERIVABLE ladder

**Status: Unproven; confidence: medium.** This is a scoped gap judgment. Attribution of the precursor to the cited notes is Supported.

**What is already there:** S22 distinguishes storing an exact object, retaining an approximation, and retaining a recipe that can reconstruct it. It also explicitly withholds support for the cited GVA mechanism.

**The open bridge:** The first dossier mapped cache policies but did not give this three-way action space its own research object. A valid reconstruction contract is still needed for each object type.

**Why keep it:** The useful question is what can be regenerated cheaply and verifiably. That question survives failure of the claimed KV mechanism or its citation.

**Small next move:** Start with an object that is actually reproducible, such as a parser index from immutable source bytes. Record recipe, inputs, versions, reconstruction cost and the equivalence check. Do not assume a value tensor determines its discarded key tensor.

**Evidence that would change the judgment:** An existing evaluated implementation closes this mapping gap; or reconstruction loses required information or costs more than keeping the object.

**Source passages:** `S22:99-105`, `S22:123-138` in [discovery-excerpts.md](discovery-excerpts.md). **Existing map:** C13, C16, C25; X03, X09.

### O02 — Dormancy without declaring an idea dead

**Status: Unproven; confidence: medium.** This is a scoped gap judgment. Attribution of the precursor to the cited notes is Supported.

**What is already there:** The notes contain adaptive TTL proposals, a preservation metaphor, cold storage, expiration, retraction and resurrection conditions.

**The open bridge:** A cache eviction, an expired observation, a rejected claim and a promising unused idea need different reasons and return conditions. These distinctions were compressed into separate memory and retraction sections.

### N01 — Make every cheaper representation carry a recovery contract

**Status: Unproven; confidence: medium. Novelty: Unproven.** Extension of an explicit source connection.

**Connection:** Join the fidelity ladder, archived spans and receipt compiler. A transformation records parent content IDs, recipe/version, permitted loss, expected recovery procedure and the check that establishes task-appropriate equivalence.

**What this synthesis adds:** The source already joins DERIVE to verification. This synthesis makes that interface reusable across parser indices, summaries and caches while retaining distinct equivalence rules for each.

**Why it could matter:** Memory savings become accountable transformations. A failed or unavailable reconstruction can be surfaced before it is silently treated as the original evidence.

**Discriminating test:** For the same task set, compare retain-exact, retain-recipe and retain-summary-plus-pointer. Plant a changed recipe and a missing parent. Charge rebuilding and verification to the saving.

**Prediction:** For some reproducible artifacts, recipe storage should reduce residency while preserving required results; the detector should reject stale recipes. Approximate summaries need separate semantic checks.

**Evidence that would change the judgment:** The retained information is insufficient to reconstruct the object, or total cost at matched quality is worse than the simpler policy.

**Source passages:** `S22:123-138`, `S22:140-166`, `S24:130-152` in [discovery-excerpts.md](discovery-excerpts.md). **Map:** O01, O09, C07, C08, C13, C25, X01, X03, X09.

### N02 — Separate an idea’s storage state, truth status and permission to act

**Status: Unproven; confidence: medium. Novelty: Unproven.** Operational separation of existing ideas; not a new theory of memory.

**Connection:** Represent three independent attributes: residency (hot/cold/recipe/unavailable), evidential status (Supported/Disputed/Unproven with scope), and permitted use (explore/advice/action under an actual policy).

**What this synthesis adds:** AUDIT/BELIEF/HEAD and dormancy are already present. The connection makes their different state transitions explicit: eviction does not refute; popularity does not verify; support does not authorize.

**Why it could matter:** It protects speculative ideas from an execution gate and protects execution from speculative ideas. A cheap dormant hypothesis can remain available without entering active doctrine.

**Discriminating test:** Use a factorial fixture: supported-but-cold, unproven-but-hot, retracted-but-retrievable, expired-but-once-supported, and supported-but-unauthorized. Test retrieval and action decisions separately.

**Prediction:** The factored state should reduce category errors relative to one undifferentiated active/inactive flag.

**Evidence that would change the judgment:** Existing simpler fields already distinguish all cases reliably, or the additional state transitions produce more errors than they remove.

**Source passages:** `S05:1120-1145`, `S19:1952-1968`, `S18:1-24` in [discovery-excerpts.md](discovery-excerpts.md). **Map:** O02, O04, O10, C14, C24, C26, X04, X10, X11.

### N03 — Use game variants to generate bounded tests of agent authority and recovery

**Status: Unproven; confidence: medium. Novelty: Unproven.** More concrete joint test design for an existing connection.

**Connection:** Treat a ruleset as a generator of explicit states, legal moves, visibility boundaries and outcome checks. The same narrow fixture can test hidden information, revocation, duplicate submission, delayed observation and ordered replay.

**What this synthesis adds:** The earlier brief already names games as a testbed. The proposed bridge is a shared fixture with separate receiver, knowledge and passport measurements, rather than separate toy demonstrations.

**Why it could matter:** A disagreement about a move has a bounded answer under a chosen rule version, making some coordination and recovery failures observable without a general language-model judge.

**Discriminating test:** Freeze one small ruleset and separate its oracle from the worker. Inject reordered and duplicate moves, stale turns and hidden observations. Compare the same-model naive loop with the fleet at matched budget.

**Prediction:** Failures should localize to rule interpretation, information access or effect handling. A system that only narrates correct play will fail the receiver-based checks.

**Evidence that would change the judgment:** Oracle and worker share an error, selected games do not exercise the intended property, or success does not transfer to a held-out game. Passing never establishes general real-world competence.

**Source passages:** `S07:1-27`, `S07:470-475`, `S17:5-28`, `S11:1-65` in [discovery-excerpts.md](discovery-excerpts.md). **Map:** O05, O08, O11, C18, C21, C23, C29, C30, X05, X07, X08, X13.

### N04 — Choose additional agents by measured rescue value and information access

**Status: Unproven; confidence: medium. Novelty: Unproven.** Operational reformulation of existing complementarity ideas.

**Connection:** Combine behavioral passports with a table of paired failures and which observations each worker can obtain. Estimate the incremental value of a specialist conditional on the current worker failing, then test a selector on unseen tasks.

**What this synthesis adds:** This replaces the strong basis/rank analogy with a concrete selection target and separates model diversity from sensor or evidence diversity.

**Why it could matter:** It can identify a valuable cheap specialist or missing observation without assuming that a different persona, architecture or provider is independent.

**Discriminating test:** Compare another sample from the same model, a different model with the same evidence, and the same model with an additional relevant observation. Train selection only on earlier tasks.

**Prediction:** Some apparent model-diversity gains may be explained by additional evidence or retry budget; remaining held-out rescue value is the quantity to route on.

**Evidence that would change the judgment:** The selector cannot predict rescue opportunities, the apparent benefit leaks across train/test families, or ordinary retries match it at equal cost.

### N05 — Let the next decision guide both information retrieval and human escalation

**Status: Unproven; confidence: medium. Novelty: Unproven.** Cross-section synthesis; occurrence elsewhere and external novelty unassessed.

**Connection:** Use an explicit upcoming decision as the shared reference for what to retrieve, what to prefetch and what to put in the operator’s review queue. Keep uncertainty about that decision and a route for unexpected observations.

**What this synthesis adds:** The corpus already has decision-linked reports, query-aware rendering and cost-aware routing. Their joint budget is proposed here: compute time and operator attention both spent on information that could change a decision.

**Why it could matter:** It gives the broad rendering metaphor a concrete target while making the operator’s review cost visible.

**Discriminating test:** Compare recency-based retrieval and an ordinary inbox with decision-guided retrieval and grouping. Inject a relevant surprise not named in the current plan. Record task quality, reading time, late decisions and suppressed alarms.

**Prediction:** Routine traffic may decrease, but any gain must survive the surprise condition and include the cost of maintaining decision annotations.

**Evidence that would change the judgment:** The filter systematically hides unanticipated facts or annotation overhead exceeds the saved effort. Fewer alerts alone is not success.

### N06 — A retraction should invalidate dependent products, not merely edit a sentence

**Status: Unproven; confidence: medium. Novelty: Unproven.** Extension across existing subsystem boundaries.

**Connection:** Connect receipt dependencies to derived summaries, cached answers, passport scores and inherited lessons. When a premise changes, mark the affected products as requiring review or recomputation; preserve unrelated products and the historical record.

**What this synthesis adds:** The source already calls for dependency invalidation. The extension traces that obligation across memory, routing and next-generation prompts, with different handling for hard dependencies and merely suggestive citations.

**Why it could matter:** A corrected ledger can otherwise coexist with an old answer still circulating through the fleet. The target is measured correction propagation.

**Discriminating test:** Plant one false premise, create known descendants in several stores, then retract it. Include an unaffected control and a disputed but not disproven premise. Measure stale-use rate, recovery time and unnecessary invalidation.

**Prediction:** Explicit dependency lineage should shorten propagation and reduce recurrence, provided important dependencies are captured and retraction authority is constrained.

**Evidence that would change the judgment:** Dependencies are too incomplete, contested retractions cause excessive shutdown, or a simpler version reset achieves comparable outcomes with less burden.

**Source passages:** `S18:1-24`, `S19:1952-1968`, `S22:140-166`, `S11:1-65` in [discovery-excerpts.md](discovery-excerpts.md). **Map:** O01, O08, O10, C08, C19, C24, C25, C26, X04, X09, X10, X11.

### N07 — Historical game variants can test whether dissent survives compaction

**Status: Unproven; confidence: medium. Novelty: Unproven.** Candidate cross-domain test connection.

**Connection:** Carry two internally coherent rule reconstructions with distinct provenance through retrieval, salon synthesis and a context fold. Then ask a later model to run the variant selected by the user and explain which alternative remains unresolved.

**What this synthesis adds:** This connects the preservation ambition to an observable dissent-retention task. Historical truth is not decided by game outcomes; the test concerns faithful preservation of alternatives.

**Why it could matter:** Compaction can be evaluated for premature agreement rather than only average fact recall. A minority variant has a concrete downstream consequence.

**Discriminating test:** Begin with synthetic variants whose rule differences are known; later use a historically sourced case. Compare ordinary summary, branch-preserving summary and source-linked retrieval at equal budget.

**Prediction:** A branch-preserving representation should reduce accidental hybrid rules and loss of the requested variant.

**Evidence that would change the judgment:** Ordinary summaries perform equally well, branches create excessive retrieval confusion, or source labels silently bias the grader.

### N09 — Compare a source-first reading with a map-first reading before the next fold

**Status: Unproven; confidence: medium. Novelty: Unproven.** Concrete protocol sketch from existing anti-capture proposals.

**Connection:** Two isolated workers examine the same bounded question. One starts with a sealed source pack; the other with the current map plus that pack. Both commit candidate mechanisms, evidence and tests before seeing the other response. Then reconcile differences by source and executable consequence.

**What this synthesis adds:** Fresh-instance and contamination concerns are already explicit. This turns the dossier itself into an experimental input and makes editorial selection a measured variable.

**Why it could matter:** It can reveal what the map helps a reader find and what it makes harder to notice. Useful convergence and useful disagreement can both survive.

**Discriminating test:** Randomize presentation order across multiple matched tasks and fresh sessions; hold total evidence and budget constant. Blind a third-stage rubric to arm labels. With only two workers on one task, report a case comparison, not a causal effect estimate.
