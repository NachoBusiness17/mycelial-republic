## 3. Extracted Invariant Formulations

### Invariant 1: POSIWID (Purpose Over Stated Intent)
- **Statement:** `IF an agent's runtime behavior consistently diverges from its written prompt instructions THEN the agent's purpose is defined by its executed tool calls and output artifacts BECAUSE the purpose of a system is what it does.`
- **Mechanism:** Never judge an agent by its chain-of-thought aspirations or polite conversational prose. Audit strictly the bytes written, the network packets sent, and the file hashes changed.

- **Statement:** `IF a fleet of autonomous nodes is to survive without centralized failure THEN each node must contain within itself the complete recursive stack of operations, coordination, audit, external intelligence, and policy BECAUSE viable systems exist within viable systems.`
