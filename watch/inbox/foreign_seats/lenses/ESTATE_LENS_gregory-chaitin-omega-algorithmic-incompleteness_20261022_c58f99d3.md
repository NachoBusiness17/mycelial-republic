## 1. Context & Secondhand Reconstruction
Gregory Chaitin reformulated Gödel's Incompleteness Theorem and Turing's Undecidability through the lens of information and computation. While Gödel used self-referential arithmetic statements and Turing used diagonal proofs over the Halting Problem, Chaitin proved that **mathematical incompleteness is an inevitable consequence of information conservation**.

Chaitin discovered **Chaitin's Constant $\Omega$ (The Halting Probability)**: the probability that an arbitrary, randomly generated computer program generated by fair coin flips will halt on a universal prefix-free Turing machine $U$.

$\Omega$ is a maximally compact representation of mathematical truth:
1. Knowing the first $N$ bits of $\Omega$ allows one to resolve the Halting Problem for all programs of size up to $N$ bits, answering almost all famous unsolved problems in mathematics (Goldbach's Conjecture, Riemann Hypothesis, Twin Prime Conjecture).
2. Yet, $\Omega$ is **maximally algorithmically random and uncomputable**: $K(\Omega_{1 \dots n}) \ge n - c$. No mathematical formal system with $N$ bits of axioms can ever compute more than $N + c$ bits of $\Omega$.

Chaitin's Information-Theoretic Incompleteness Theorem states: **A formal axiomatic system of complexity $N$ bits cannot prove that a specific, individual object has Kolmogorov complexity greater than $N + c$.** You cannot prove a theorem that contains more algorithmic information than your foundational axioms.

## 2. Invariant Mathematical Formulation

### A. The Halting Probability $\Omega$
For a universal prefix-free Turing machine $U$, where domain $\text{dom}(U)$ consists of all programs $p \in \{0, 1\}^*$ that halt:
$$\Omega = \sum_{p \in \text{dom}(U)} 2^{-|p|}$$
*Kraft Inequality:* Because $U$ is prefix-free (no valid program is a proper prefix of another), $0 < \Omega < 1$.

*Algorithmic Randomness (Incompressibility):*
$$\exists c: \forall n, K(\Omega_{1 \dots n}) \ge n - c$$
The bits of $\Omega$ are statistically independent, normal, and maximally incompressible; no formula, algorithm, or pattern can compress them.

### B. Chaitin's Information-Theoretic Incompleteness Theorem
Let $F$ be a consistent, sound formal axiomatic system formalized as a computer program of length $|F| = N$ bits that enumerates true mathematical theorems of the form "Complexity of string $x$ is greater than $k$" ($K(x) > k$).

*Theorem:*
$$\exists c \text{ (independent of } k \text{ and } F): F \text{ cannot prove that } K(x) > N + c$$

*Implication:* Just as in physics where energy cannot be created from nothing, in mathematics **information cannot be deduced from an axiomatic system that does not already contain it**. Deductive reasoning cannot create new algorithmic entropy.

* **Failure Mode (The Deductive Hallucination Trap):** Expecting a compact prompt ($N$ bits) to generate infinite infallible proofs of external systems without ingesting external ground truth ($O$ bits), violating algorithmic information conservation.
