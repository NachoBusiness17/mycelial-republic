## 3. Extracted Invariant Formulations

### Invariant 1: Constitutive Rules (The Voluntary Invariant)
- **Statement:** `IF an evaluation harness or agent test is to measure authentic capability THEN it must enforce constitutive constraints that prohibit trivial shortcuts BECAUSE without the prohibition of more efficient means, the activity ceases to be a game and becomes mere optimization.`
- **Mechanism:** In our blind control trials (`run_dissenter_trial.py`, arena bench), we forbid the model from seeing the doorman's prompt or looking up ground truth directly. The restriction is the only thing that creates evaluation signal.

### Invariant 2: The Lusory Attitude in Autonomous Agents
- **Statement:** `IF an agent obeys a policy constraint or security boundary THEN it must adopt the lusory attitude: accepting the boundary as the constitutive definition of its operational universe BECAUSE an agent that views security rules merely as obstacles to circumvent is by definition adversarial.`
- **Mechanism:** An agent that tries to bypass `rclone rcat` streaming by dumping raw files onto node Bob's local NVMe is breaking the game's constitutive rules. The lusory attitude requires embracing the 15GB disk constraint as the creative forge for the streaming engine.
