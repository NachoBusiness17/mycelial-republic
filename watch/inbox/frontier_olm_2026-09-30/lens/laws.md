### 1.1 The evidence laws (how a claim becomes a claim)

- **OWED is a legal verdict.** Anything unreachable is filed as OWED, never guessed. The LINK-DROP card: "Never fabricate; OWED if unreachable." `memory/rib/RIB_BEHAVIOR_CARDS_20260928.md:13-20`. The lane boot prompt makes tri-state mandatory: every claim gets a source or a receipt, Supported / Disputed / Unproven. `memory/rib/RIB_LANE_WINDOW_BOOT_20260904.md:11-14`.
- **The empty-claim law.** A claim is a chair; you sit only if a primary record is on the table, "not a blog, not a rumor, not a vibe." Score supported / unproven / disputed; the human says when it is supported; software does not auto-truth. Enforced in `mag/claims_desk.py` so a record-less sit refuses and the root does not move. `memory/rib/RIB_GAME_CLAIMS_DESK.md:6-26`.
- **A failure against an unfiled prompt is not a finding.** The exact prompt sent to any model must be filed as md beside its outputs, before or at dispatch; otherwise the failure is unreproducible and therefore not a finding. Everything durable is md on disk, tracked (a register event), written open-append one item per record; corrections append, never rewrite. `memory/rib/RIB_MD_RECORD_20260921.md:7-25`.
- **Honest provenance.** No artifact may claim "grok" / "frontier" provenance unless real output was captured; `grok_captured` means real output only, with a provenance_note when it did not arrive; there is no "steal" without a real source. `memory/rib/recreation-coding-history.json:52-55` (honesty-provenance slot) and `:74-75` (corr-grok-flag-lie guardrail).
- **A verdict without its conditions is not a verdict** (the ONE-BUG LAW, 2026-09-29). Before consuming any instrument result, name: (1) the instrument and its exit code, never piped away or masked; (2) the moment, nothing compared across moments without saying so; (3) the context assumptions (cwd, basetemp, order, budget) and any that differ between measurement and consumption. Runs that cannot name their three conditions are treated as unfired. Falsifier: a cross-context disagreement must resolve to a named condition difference within one investigation. `memory/rib/RIB_DRIVING_LADDER_20260928.md:53-77`. - **Fail closed.** When no real reply can be produced, send nothing: "a gloss is a lie." Patch the cause, not the symptom; never kid-glove your own failure. `memory/rib/RIB_SELF_MY_CORRECTION_LOOP.md:6-14`. The shadow rib names the recurring failure shapes to watch for: performing a reply instead of doing the work, asking when the answer is already resident, narrating composing as if it were the turn. `memory/rib/RIB_SELF_MY_SHADOW.md:9-14`.

### 1.3 The instrument laws (how evidence is produced)

- **Consensus is not a correctness signal (measured, not theorized).** The adversarial eval found the flock agreed with strong-remote 0/3 while carrying HIGH consensus strength (0.60-0.67), and single-local alone was correct on all 3. Root cause: the riddler surrogate decode maps to a surrogate-action vocabulary orthogonal to task correctness. Implication for any research pipeline: do not trust multi-sample agreement on grounded tasks; use single local or remote plus an explicit check. `memory/rib/RIB_MINDSWEAVE_EVAL_CONSENSUS_ILLUSION_20260810.md:14-25,34-43`.
- **Emergent vs deterministic is a per-task, measured claim, never a dogma.** Five axes: invariant alignment (gate, must pass first), cost per unit outcome, quality / correctness on held-out data, variance / reproducibility, generalization on perturbed inputs. Decision rule: reject an emergent mechanism that wins on novelty but violates invariants; if it never beats deterministic on any axis, do not use it. The sharpest test is longitudinal compounding. `memory/rib/RIB_EMERGENT_TOOLING_K8S_DEEP_DIVE_20260810.md:99-145`. Deterministic for the known-compressible core, emergent for the open frontier; flock-eliminate decides. `memory/rib/RIB_EMERGENT_TOOLING_K8S_DEEP_DIVE_20260810.md:150-158`.
- **The map must stay re-derivable.** Because the map precedes the territory, a wrong map produces a wrong territory at scale, cheaply, many times. So the map must be grounded (re-derivable from raw provenance), honest (corrected when it over-claims), and versioned (content-addressed, revertable). Stateless-to-run, grounded-to-be-honest. `memory/rib/RIB_MAP_PRECEDES_TERRITORY_20260811.md:67-78`.
- **The chain is ground truth; models are interchangeable.** A deterministic instruction set anchored on shared cryptographic primitives is what persists. `memory/rib/RIB_DOCTRINE_CANONICAL.md:7-16`. State is recomputed from the chain; no derived or runtime state is trusted as truth (stateless-by-default, grammar invariant 2). `memory/rib/RIB_GRAMMAR_SEED_20260810.md:17-20`. The in-memory corpus fast-path went stale silently until an mtime fingerprint auto-invalidation was added; cached snapshots of the corpus are a correctness hazard, and that fix is the pattern. `memory/rib/RIB_RAM_CACHE_STALE_SNAPSHOT_20260825.md:8-41`.
- **Dissent stays separate; novel must name a test.** Roshomon core (statements recurring across 2 or more independent witnesses) is convergent truth; unique statements are divergent perspective, and a novel claim must name the test that would check it. Promotion is human-gated: seats draft, the operator nods. One bus: the Mag disk (memory/rib + handoff + rib_bus mount), not a new throne. `memory/rib/RIB_allseat_comms_ghost_2026-08-14.md:24-31`.
