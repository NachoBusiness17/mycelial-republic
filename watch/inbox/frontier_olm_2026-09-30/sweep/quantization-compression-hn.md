### RQ2. Do the 4 auto_quantize invariants survive the five-axis test (laws.md:34)?

Order per law: invariant alignment first, then cost, quality, variance, generalization. The four invariants are read from the live `memory/knowledge_graph.json` node `module:auto_quantize.py` this ask (the graph.md:24 line only names the module; the node carries the text).

1. **"SCHEMA: auto_quantize.v1" - survives, aligned.** The literature's own hygiene moved the same direction: bartowski's per-tensor layout maps restore strict meaning to GGUF tier names (_S = 90% of the named type, _M = 70%, _L allows up to 50% bumped) precisely because schema drift ("bpw collapse", Q3_K_XL beating Q5_K_M) made claims unverifiable. A versioned schema is the load-bearing part; v1 stays.
2. **"Anomalies are NEVER quantized. Keep raw forever." - survives, and 2026 practice converged on it independently.** GSQ-RCO allocates by per-tensor sensitivity under an exact size budget and keeps non-expert matrices at Q8_0. VeriLoop's IQ1_M is "a mixed-precision artifact (851 tensors, 5.36 BPW) with a protected high-precision spine", and exactly one tensor (blk.1.ffn_down.weight) is protected extra at the IQ1_M rung. Bartowski's degrade-one experiments: token embeddings dominate sensitivity 8-16x other tensors and tiny tensors are forced to F32. Three independent groups, same law.
3. **"Variance determines resolution. Low variance = high compression." - survives ONLY with a scope amendment.** The 2026 allocators use measured sensitivity (KLD-per-bit from degrade-one tests, per-tensor sensitivity search), not generic variance, and the Quesma thread quantified why: KL divergence "varies dramatically by dataset", benign on wikitext, up to 10x top-1 divergence on agentic/coding traces. A variance probe measured on telemetry-like data would understate divergence exactly where the estate consumes quantized output (task traces). Cost axis adds what a variance rule cannot see: quantized models overthink (see RQ3), so equal accuracy at lower bits can still cost more tokens. Generalization axis: bartowski's prior generalized to most families but FAILED on some (granite, MiniCPM5, DeepSeek-V2-Lite) until a per-class table was added, and his KLD-per-bit canary correctly rejected MiniCPM5-2B - i.e., even learned allocation needs a per-shape acceptance gate. Verdict: keep the law, amend "variance" to "variance measured on task-representative probes, gated by a canary".
4. **"The chain root is always recoverable from any quantization level." - FALSE as a naive claim; TRUE only as the chain-rooted reading the module actually implements.** Literature contact: 1-bit post-training quantization collapses (Quesma: 1-bit at random chance on GPQA; the thread's seamossfet: "Quantization on an existing pre-trained model will almost always collapse at 1-bit"); the estate's own verified splash file already flags Ternary Bonsai's 1.72-bit weights as UNVALIDATED for logprob calibration (memory/runs/gapwave/splash_bonsai_livetranslate_verified_20260920.md). What VeriLoop does instead is the correct form: every rung is quantized directly from the canonical BF16 GGUF (never re-quantized from a lower rung) and measured against a frozen BF16 logit reference, so recovery runs THROUGH the chain to the root, never from the quantized artifact alone. That is the same structure auto_quantize enforces (raw L0 kept; quantized L1 is a view). Verdict: survives under the chain reading; the wording "from any quantization level" should be tightened to "via the chain root" before any promotion. Funded-tier verification (an actual re-derivation test on our own analytics chain) is the named next step, not literature-only.

### RQ3. Quantization-induced divergence in multi-sample / consensus decoding (laws.md:33 extension)

- **arXiv 2606.00206 (NEW, strongest):** aggressive PTQ reduces accuracy while INCREASING chain-of-thought length; "In up to 52% of quantized model failures, the model actually reaches the correct answer mid-reasoning but fails to output it as the final answer"; token-level KL divergence vs FP is highest at high-entropy positions, where quantized models disproportionately sample overthinking markers ("wait", "but", "alternatively"). Scope: 5 models (1.5B-32B), 3 quant methods, 5 benchmarks; a training-free logit penalty on the markers cuts CoT length 12-23% and reduces quantization-induced overthinking failures up to 58%.
- **Estate extension:** the consensus-illusion rib (laws.md:33) says agreement is not correctness because the decode maps to a surrogate vocabulary. This paper adds a second, measured mechanism that hits consensus sampling exactly where it operates: quantization perturbs the distribution most at high-entropy (highest-disagreement) positions, so multi-sample agreement rates from a quantized decoder are not comparable to the FP decoder's, and agreement can be preserved while the emitted answer diverges (52% reach-but-not-emit). Thread corroboration: sharmajai's hypothesis that lower quants hold success rate by thinking longer (token spend hides quality loss), and ricardobeat's Wilson-CI objection (a model fluctuating 60/100/80 carries the same CI as a steady 80) - i.e., published quant evals under-report run-to-run variance, the same variance axis laws.md:34 demands be measured.
- **Direct multi-sample-consensus-under-quantization papers: none found in the window (OWED).** The extension above is inference from divergence measurements, not a published consensus-decoding result.

### RQ4. The quantize target in a deliberate ask so outputs stay byte-verifiable and re-derivable (laws.md:35)

VeriLoop is the working template, fetched and read this ask: (a) one canonical BF16 root GGUF, all rungs derived from it directly ("All tiers are quantized directly from the canonical BF16 GGUF (not re-quantized)"); (b) a FROZEN measurement protocol ("frozen quantization-retention protocol (WikiText-2 raw, ctx 2048, seed 42, F16 KV)") reporting PPL, KLD, same-top-p and RMS drift together; (c) honesty marking on the proxy ("these are quantization-retention measurements, not downstream benchmark-loss percentages"); (d) byte evidence at the rung: IQ1_M passed "llama.cpp runtime checks plus MTP speculative decoding (73.08% draft acceptance, identical output hashes)". So the deliberate-ask quantize target should name: the exact artifact (quant type, bpw, GGUF file, llama.cpp commit), the frozen root it derives from, fixed seed + sampling params, and an output contract of either byte-identical hashes (deterministic decode paths) or same-top-p fraction against frozen root logits plus an n-run variance report. The Quesma thread's variance critique is the reason the contract must demand repeated runs, not single-run CIs.
