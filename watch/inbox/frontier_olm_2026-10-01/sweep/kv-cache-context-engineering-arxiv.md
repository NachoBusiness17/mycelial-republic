## Pass 2: deep reads (fetched and read in this session)

NEW, full HTML text end to end:

1. Preserving Provenance in Shared KV Caches for LLM Serving (2609.38706, 2026-09-30). The shared KV-cache tier keys entries on token bytes plus coarse metadata while the engine locally distinguishes adapter, weight precision/version, KV representation, and tenant salt; at the connector boundary that provenance is discarded, so identical token prefixes under incompatible configs collide on one key. Measured incidents: cross-adapter LoRA collision drops sentiment accuracy 0.94 to 0.64 (32 harmful flips, p<0.001; IMDB 0.945 to 0.715 with 28.5% relabeled to the seeder's policy); in-place checkpoint swap keeps the key so SGLang served 960 of ~995 tokens from the superseded version; salt omission defeats the CVE-2025-46570-style isolation (perfect prompt identification at N=10, 93% at N=100 from timing). Two-phase seed-replay hit 83.5% cross-provenance; a 4-worker load-balanced fleet 10%; cold-start joining workers read stale state on 100% of requests (accuracy 0.73 to 0.92 when bound). Fix: a provenance contract over a dimension registry, canonical key = f(x, H(enc(id1..idn))) with length-prefixed injective encoding, worker-level digests (precision, weight version, KV format) resolved at startup and request-level digests (adapter, salt) carried in the request record; hooked into LMCache (22 base64 chars inside a 150-byte key budget), vLLM filesystem (md5) and Mooncake (blake2b) hash inputs, and SGLang HiCache's namespace seed; plus a differential omission test (vary one dimension, flag any key that does not change). Overhead: hit-path latency within noise (vLLM median TTFT -0.30 ms), request digest 12.7 microseconds, storage linear in provenance diversity (vLLM filesystem 214 to 856 MB across 4 classes). Key framing sentence, verbatim from the fetched page: "Equality of shared keys thus implies neither computational equivalence nor permission to reuse."
2. Identical Runs, Different Results (2609.33812, 2026-09-27). 584 runs across three studies (6 agents x 6 open-weight endpoints x3; then 3 pairings x 52; then x52 on the larger model), XGBoost airline-delay task scored by AUC. Within-pairing run-to-run SD (0.0107) exceeded the spread across all six pairing means (0.0095); three-run comparisons rank unreliably (weaker pairing wins 28-44% of draws); 39-113 runs per arm needed. The cache finding is the estate-relevant one: same job, same model (DeepSeek V4 Flash on Ollama Cloud), $0.08/run via one agent vs $1.86 via Claude Code, a ~23-fold gap; the endpoint served 92-98% of the cheap agent's input from its prompt cache but only 2-11% of Claude Code's, and the cache accounts for roughly ninefold of the gap. The failure was pairing-specific (Claude Code cached 96-97% on other models through the same endpoint) and the authors state: "We have not tested the mechanism." Compliance: 10 of 312 runs broke task rules and "The seven highest scores in the study are all among these ten."
3. Vosti: Specifying, Implementing, and Verifying Deterministic LLM Inference (2609.38981, 2026-09-30). Specifies bitwise system-level determinism: fixed model, deployment config, prompt, and initial sampler state imply bitwise-identical logits at every output position, across batching, chunked prefill, and KV-cache reuse/eviction/recomputation. Two-layer proof: Rust+Verus engine proven by induction to satisfy the central KV-cache invariant (every live or retained KV entry equals the cold-recompute value for its token prefix) plus write-isolation invariants; Triton kernels checked by a Z3-backed verifier proving bitwise-equal outputs across batch sizes, query lengths, and paged layouts; 5,488 bitwise comparisons pass on 7 Llama/Gemma models. Performance on H200: 1.36-3.19x vLLM batch-invariant decode throughput, 1.14-2.20x faster session completion on a decode-heavy agentic workload; prefill still slower than vLLM invariant FA3 and overall slower than default modes.
4. SuffixReplay: Prefix Caching via Suffix Replay for Hybrid LLMs (2609.33477, 2026-09-27). Hybrid linear-attention layers keep fixed-size recurrent states that cannot roll back, so prefix reuse only works at materialized checkpoints, and checkpoints are enormous (~1,500x a single token's KV entry, ~49 MiB in Qwen3.5-4B). Fix: store input hidden states (anchors) at sparse 64-token page boundaries (density 1/16), store NO recurrent-state checkpoints, and on a hit at position n replay only a recent suffix (k = min(0.05n, k_max)) through the linear recurrence; decay gates make distant contributions negligible; fail-closed to full prefill if anchors are missing. Every page boundary becomes a valid reuse point. Measured on OLMo-Hybrid-7B, Qwen3.5-4B, Qwen3.6-27B-FP8 vs SGLang v0.5.18 on H800: quality 91.4-100% of full prefill (Qwen >99% at k=128); median TTFT -15-20% (ShareGPT) to -55-70% (ToolMind >16K); branch-between-checkpoints case 369 ms to 72-94 ms (3.9-5.1x); throughput 2.3-4.3x SGLang when the working set exceeds HBM (SGLang hit rate collapses 0.86 to 0.05 while SuffixReplay holds 0.85). Anchor storage 3.3-9.4 KiB/token, 0.36-0.51x SGLang's amortized checkpoint cost.
5. PAIR: Adapting Context Compression for Long-Horizon Agents with Counterfactual Continuations (2609.36526, 2026-09-29). Diagnostic: context compression erodes cross-run reliability (Pass3 falls before solvability does) and inflates step counts before it kills tasks. Mechanism: at each compression boundary, restore the same environment state and roll out matched continuations from pre-compression vs post-compression context; estimate outcome hazard H and interaction burden B; screen boundaries by successive halving; an optimizer LLM revises only section guidance inside a fixed prompt template; select among 5 candidate prompts by end-to-end validation. Numbers: AppWorld history-only PAIR 84.7% Acc / 79.8% Pass3 vs 84.1% / 78.6% with NO compression, i.e. repaired compression slightly beats uncompressed at roughly half the input tokens; best ACON baseline 81.2% / 70.8%. Harm is sparse and localized: 151 of 197 AppWorld boundaries add steps but only 12 add >5; only 11 boundaries cut continuation success by >0.5; 27 harmful boundaries occurred inside ultimately successful trajectories; hazard and burden are nearly uncorrelated (Spearman 0.004-0.102) so both signals are needed.

6. Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression (2609.36322, 2026-09-28). Chunked KV-cache compression introduces a "phase" coordinate: a token's position relative to compression-window boundaries. Pretraining transformers from scratch under multiple compression designs plus causal interventions shows retrieval accuracy varies periodically across phases, up to 40 percentage points in large open-weight models, with attention components specializing per phase. The evaluation law: averaging over phases hides systematic positional failures; measurement must sweep phases.
7. When Does Selection Replace Extraction? (2609.34227, 2026-09-28). Pre-registered non-inferiority test (one-sided 95% bound -3.0 vs -5 margin) on LoCoMo: raw turns selected by one typed-decision-model call match LLM-extracted-fact memory at tight budget; raw turns cost 3,061x less to write; reranking gains shrink as budget grows (+17.4 points at 3-of-30, +1.5 at generous budgets, where extraction wins accuracy); reranking lowered correct abstention.

## Answers to the four research questions

RQ1 (prefix/prompt caching behaviors exposed by inference servers and APIs; how asks must be shaped byte-stable; extending the ZCode playbook's byte-identical law). Three new laws this window, all read end to end. (1) Byte-identical is necessary but NOT sufficient: Provenance shows shared caches collide identical token bytes across adapter, weight-version, precision, and salt dimensions, and the damage is not hypothetical (0.94 to 0.64 cross-adapter, 93% prompt identification from timing under salt omission, stale weight-version serves). The ZCode playbook's byte-identical law (corpus/steal/ZCODE_OPERATING_PLAYBOOK_20260925.md) should grow a provenance clause: when a fleet crosses connectors (Hermes front door to provider gateways, multiple models on one endpoint), pin adapter id, weight version, quantization config, and salt alongside the bytes, and run the paper's differential omission test (vary one dimension, require the key to change). (2) The premise that same bytes give same completions is an engine property, not a law of nature: Vosti proves bitwise-identical logits are achievable WITH full KV-cache reuse invariants, and Identical Runs shows that without such properties, identical runs vary more than the things being compared. Byte-stable asks buy cache hits and reproducibility only up to the serving stack's determinism contract. (3) The economics are measured in the wild: 92-98% vs 2-11% cache share on the same model and endpoint produced a ~23x cost gap between two agents. The estate's byte-stable asks are the controllable half of the agent-gateway-provider path; the playbook should log cache share per lane the way it logs tokens. HONEST GAP: no in-window paper documents llama.cpp or Ollama server cache flags (slot save/restore, session caching); that is product-docs land, not arXiv, and this lane did not fetch those docs. SuffixReplay shows where engine-side prefix caching is heading: page-boundary-granular reuse with no checkpoint placement question, 2.3-4.3x throughput when the working set exceeds HBM, which matters to the janitor fleet the day a hybrid-attention model lands in Ollama.

RQ2 (structure-fed vs prose-fed context; memweave doctrine numbers). Two new measured results. (1) PAIR gives the metric law: compression (summaries replacing raw history) degrades RELIABILITY before solvability, Pass3 falls before Pass@1, so memweave's structure-feeding claims must be graded on pass-k variance, not single-run success; and repaired structured section-guidance beat the uncompressed baseline (84.7% vs 84.1% AppWorld Acc at about half the tokens), the first in-window number where structure-feeding strictly dominates raw history on both axes. Harm is sparse (11 of 197 boundaries carry the damage), which matches the memlance model: one bad fold, not gradual rot. (2) Selection vs Extraction gives the budget law: at tight budgets, selected raw turns (pointers to records) are non-inferior to LLM-extracted prose facts at 3,061x less write cost; at generous budgets, extraction wins accuracy and selection's rerank edge collapses (+17.4 to +1.5 points). Memweave doctrine thus gets a crossover: pointers-to-raw below the budget line, distilled structures only above it. Out-of-window pointer, not banked: 2606.14875 (June) already showed symbolic re-expression beating summaries at matched budget; the 09-28 sweep's ContextEvo and ACG rows carry the structure-over-prose training-side numbers.

RQ3 (KV-cache eviction and quantization strategies for long agent sessions; quality cost at 2026 lengths). Eviction is settled law from the prior sweeps and this window adds no counter-evidence: LRU plus selective one-hit demotion is the production answer (When Fancy Eviction Fails, 14 policies, two traces, re-read this session), RR-Evict owns the agent-loop shape (already banked), and repair-style reuse (CacheRepair/RelaxKV, banked 09-30) is where the quality-adjusted wins live. Quantization quality cost: this window's specific new instrument is Periodic Weak Spots (abs-only): any CHUNKED KV compression scheme imports a phase coordinate, and retrieval accuracy can differ by up to 40 percentage points across phases in large open-weight models, so a compression config that averages well can still have systematic dead zones; the estate's acceptance bar for any KV compression on janitor seats must include a phase sweep, not a benchmark average. Standing pointer from the 09-28 sweep, still the best quantization quality-cost number: Faithfulness Is Not Free (2608.30996): INT8 KV near-lossless, INT4 silently breaks grounding.

RQ4 (long-context degradation at 2026 window sizes; budgeting mag.cmd context-pack and carrier echoes). The window's evidence says budget by STEPS and by PHASE, not by tokens alone. Agents Rot (banked 09-30, abs re-read this session): success follows a geometric law in per-step reliability; bounding the context window steepens decay rather than easing it (logit slope -0.69 vs -0.44), so shrinking the pack is not a free quality lever. Periodic Weak Spots adds the placement law: under chunked compression, position within chunk predicts retrieval up to 40 points, so carrier echoes and pack anchors should not straddle chunk boundaries, and any pack-layout eval must sweep phase. PAIR adds the failure shape: budget pressure first costs cross-run reliability and inflates interaction steps (151 of 197 boundaries added steps, only 12 added >5), which is exactly the turn-2 no-echo / interaction-burden defect class the carrier healed in window 1; the instrument for context-pack sizing is pass-k over repeated runs plus step counts, not a single trajectory. The 2B-janitor-specific collapse study remains OWED (the 09-30 sweep said it too; nothing in this window measured 2B-class context collapse).
