### 1. Routing LLM traffic across inference providers with TCP-style congestion control (getunblocked.com, 2026-09-29; HN 49897322) - READ FULL TEXT
Fetched: https://getunblocked.com/blog/adaptive-routing-inference-providers/ (banked as _ihn_page_49897322_tcp_routing.txt).
The RQ1 schema answer and the RQ3/RQ4 measured design. Production GLM 5.2/5.3 router across Baseten/Fireworks/CoreWeave. Tank accounting: "We record every call in a ledger with the provider, token counts, duration, time to first token and task ID, and then add the calls up by task." A five-minute job summarizes the ledger per provider and task type into Redis; tasks that touched more than one provider are excluded from attribution. Ranking is cost-weighted (score = 0.7 x cheapest-ratio + 0.3 x fastest-ratio, so a faster provider only leads if it costs under 1.75x cheapest), with a 3x latency guard, 5% hysteresis, a 5-minute conversation pin (cache), and a permanent 5% exploration floor. Reliability is a GATE not a score: a shared per-provider permitted rate updated AIMD-style - "A 429 means the provider is asking for less traffic, so we halve the rate, as TCP does when it detects congestion." (other failures x0.8, success +0.25 rps capped by success rate; decrease at most once per 5s and only when recent error rate exceeds 10%). Off switch (one Postgres row, 5s propagation) built BEFORE enabling, plus a one-week shadow run. Measured outcomes, honestly priced: leaving round-robin for fixed order took search cost/task from $0.070 to $0.060; the adaptive layer's further saving was approximately zero ("Cost per task stayed 14% below what round-robin had been costing us, and it stayed there without a single deploy"), while median task time fell 55% whenever a faster provider existed; CoreWeave's 45%-cheaper list price never reached the bill because it buckled under load. Two audit findings the estate should steal whole: the leader looked cheaper because its cache was warm (fix: price cached tokens at uncached rate for ranking, measure TTFT only on cache misses), and nearly every recorded provider failure in a 3-day audit was actually the client exhausting its own output budget (fix: stop counting that against the provider).
