Quote: "External cache transfers can succeed while a hybrid language model resumes from an inconsistent state." Why: it is the estate's exact animal (GLM-5.3-Flash is the session model) on the estate's exact shelf (vLLM + LMCache, 2,331-row source in corpus/library/lmcache-src per lens/corpus.md:20) with the NVFP4-quantized checkpoint - the Q1 unwired-feature map (strict-prefix lookup, shared-computation corrections, matched checkpoint scheduling, fixed per-rank kernel configs cure a complete-hit recovery mismatch that credited one fewer token) and the Q5 quant-rung evidence in one paper. Measured: agreement 34/36 to 36/36 after alignment; CPU reload cut TTFT 46-64 pct and total request time 1.9-7.0 pct vs modified cold recomputation. Scope caveat the authors state: one model revision, controlled config, no concurrent-serving or capacity claims. Overlap: 0 catalog rows, 0 register rows, only a raw-census mention in the 10-03 lane's `sweep/_raw/q1_candidates.json`; never banked. Confidence 0.95.
2. **Shared KV Caching for Replicated 27B Inference: Correctness Failures and Performance Boundaries** (2609.15021, 2026-09-14, Frank Li, cs.DC). Quote: "Median cross-replica time to first content token falls from 31.715 to 0.605 seconds at 128k input". Why: the 52x TTFT number and 0.790s at 256k input are the payoff of a shared 256 GiB LMCache pool across two vLLM replicas; the same paper isolates a raw-pointer fallback bug that omitted a CUDA-stream dependency (byte tests fail under imposed delay, pass when restored) and names the mixed allocator as the safe deployment path. That is the correctness contract the estate needs before wiring the shelf into any multi-seat serving shape (Q1 + Q3). Overlap: 0 catalog, 0 register, 0 prior sweeps - fully new. Confidence 0.9.
3. **Adapting Context Compression for Long-Horizon Agents with Counterfactual Continuations** (2609.36526, 2026-09-29, cs.LG, 41pp/10fig/9tab). Overlap: only raw-census mentions (10-03 `_raw2/q5_compress.xml`; 09-30 set-aside list); never banked. Confidence 0.9.

**Q3 (seven unwired inference-budget carriers; KV/context-shaped; free wiring).** The carriers (stealth_driver, duel_harness, tesuji_fire, lane_runner, lite_scale, wave_fire, ds_workhorse; lens/laws.md:75 citing memory/rib/RIB_INFERENCE_BUDGET_20261001.md:100-114) are all KV/context-shaped in one specific sense: they hand-roll dispatch params over long frozen prefixes (estate-law blocks, rib chains), so their cache validity and their EMPTY_REASONING class-kill both live in the ask bytes. **Q4 (packing-density floor for context-pack).** Composed floor, all read this sitting: (a) compression degrades reliability before solvability (36526) - the trigger metric; (b) episodic selection beats recency and raw accumulation, and the failure axis is query-evidence distance (2610.00562); (c) chunked KV compression has phase-periodic 40-point retrieval swings (36322, banked 10-03); (d) the mechanism is positional: RoPE models retrieve positionally, so where evidence sits in the window matters as much as whether it survives (38530). Direction for context-pack: below the reliability floor, retrieve (episodic selection by query-evidence distance) rather than compress; a density threshold derived from solvability alone will be set too low.

**Q5 (KV quantization x the reasoning-quant ladder, burns percolator row 7).** 2609.15030 is the direct evidence on the estate's own model family: an NVFP4-quantized checkpoint plus external LMCache recovery needed strict-prefix lookup, shared-computation corrections and per-rank kernel pinning before generations agreed 36/36; quantized weights make external-KV-state assumptions STRICTER, not looser. Combined-configuration safety rule the estate can adopt now: never combine a quantized checkpoint with an unaligned external-cache restore; validate every KV-quant rung with a recovery-agreement test of the 36/36 shape; and treat reasoning chains as the sensitive load (divergence under eviction is silent, per the banked Divergence Timing; 2-bit KV only with data-adaptive transforms per the banked WUSH-KV). This hands the percolator row 7 probe two concrete rungs and a falsifier.
