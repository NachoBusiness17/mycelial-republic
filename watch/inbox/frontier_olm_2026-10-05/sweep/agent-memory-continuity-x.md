## The four research questions, answered from what was read

1. Entity identity grounding (the 29-of-31 phantom already_inside welds): three independent 2026 sources converge on the same fix shape: identity is a write-time bookkeeping policy, not a retrieval property. StateMemBench (arXiv:2608.19652) shows current-state accuracy at 0.127-0.205 for named memory systems and lifts it with explicit supersession tracking; the length- and cost-matched control (+15 to +32 points from structure, not context) kills the "just retrieve better" excuse. mem0 Dream ships it in production (lifecycle_state column + replacement_memory_id pointer + latest_only filter). The infer post documents the failure mode from the vendor's own side: an inferred record can come back with no agent_id field at all even when the caller passed one, and their working fix is encoding the policy into the id string itself (`customer_marcus::smart_summary` vs `::verbatim_log`) - free-text-derived ids dangling is exactly the knowledge_graph.py:236-239 disease, published by the vendor that most builds on inferred ids. Zep's two-clock edges (when true in the world vs when learned) are the strongest published answer: welds should carry both timestamps so a stale weld is visible instead of absent.
2. Narrative memory welded to code: no full published design found in-window; closest is ibl.ai's CoALA framing (procedural memory = "implicit knowledge in the model weights plus explicit knowledge in agent code") plus mem0's placement test showing rules held in CLAUDE.md tie retrieval at small scale - the estate's ribs-already-are-code pattern. OWED: a design that links session records to the module that implemented them was not found; the DolphinBench oracle-context certification method is the nearest usable instrument.
3. Recall/continuity evals for a 258,840 + 65,934-row biography shelf: DolphinBench (already banked) for action-based grading at 500k-token histories; StateMemBench's closed-pool current/superseded/neither grading is directly portable - score the biography shelf on whether a weld reflects the current canonical id, a superseded one, or neither; the compaction-cliff placement test gives the clean-7 quiz pattern (rules tested by action without naming them, deterministic regex graders, no LLM judge). LongMemEval's five-ability framing (knowledge updates, temporal reasoning) is the substrate all three in-window sources cite.
4. Memory-tier architectures vs the zknot recap + rib stack: the frontier consensus taxonomy (CoALA via ibl.ai: working/episodic/semantic/procedural) is explicitly criticized by the akshay full article as not-a-retrieval-path: "Not one of those five [LongMemEval abilities] is semantic, episodic, or procedural." The zknot recap is a user-summary-shaped tier (present before any query, works on turn one - Zep's type 6); ribs are procedural runbooks; what the estate lacks is the typed fact layer with intervals (Zep type 1) and supersession lifecycle (Dream). mem0's placement result ("A rule that lives only in the conversation is only as safe as the next compaction") and the Passau 53%-after-one-round measurement both say the zknot-recap-only boot path sits on the cliff; the rib vault's verbatim-pinning is already the Knowledge Triage answer.
