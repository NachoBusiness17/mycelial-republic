## The mechanism (stated as a port)

1. Every durable record carries a supersession key plus source_units (the sources it was derived from).
2. Retire = stamp the record falsified/superseded, then transitively quarantine every record and derived artifact whose source_units list it: summaries, plans, caches, compiled packs.
3. Recompiling a fresh pack or rebuilding an index is NOT a rollback; descendants are swept by key, not by regeneration.
4. Retraction latency (retirement stamp to zero descendants still influencing decisions) becomes a measured gauge: the propagation clock (state/NIGHT_LOOP_20261005.md:253-262) read from the retirement end.
