## Steal 1: ArcticSwarm, search isolation before review (topology beats width)

Source: https://x.com/rohanpaul_ai/status/2097089066579988968 (mirror-fetched twice;
no paper link in the post, primary OWED by name search).

plausible answer, peers read it and search around it, so the swarm converges on the
first plausible frame rather than the answer. The cure is a topology change, not a
width change: block selected agents from reading peers WHILE they search, pool
findings after, then run a review phase that challenges the leading answers before
