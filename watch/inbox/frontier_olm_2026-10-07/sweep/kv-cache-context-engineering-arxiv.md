## Banked items (8, strongest first; all NEW to the estate, all fetched and read this session)

### 1. ReFold: Training-Free Reversible Inter-Turn Context Folding for Long-Horizon Agents (2610.07863, 2026-10-06, Su et al.)
Full HTML read. A rendering layer that compresses only the model's rendered context while preserving the underlying history: already-displayed content becomes a stub (keeping class/function signatures), agent-reported-finished turns fold into one-line notes, and the cached prefix is rewritten once every k=3 steps so between advances the context stays strictly append-only and the prefix cache survives (hit rate 87% vs 23% for mask-style eviction). "Every removal is strictly reversible, a wrong removal costs one restore from the history rather than permanent content loss." Numbers: token consumption down up to 2.5x, KV-cache memory halved, up to 92% of forced compactions avoided under capped budgets, queuing delay down up to 100%, inference cost down up to 3.4x, across SWE-bench Verified/Pro, Multi-SWE-bench, Terminal-Bench 1.0/2.1 on Qwen3.6-27B and Qwen3.6-35B-A3B; beats LLMLingua-2, SWE-Pruner, AgentDiet. Estate fit: this is the cure class for both live defects the ask names. The d01 shed finding (lens/burns.md:160-161, the tour guide that can drop pages) is answered by the restore operator; the CONTEXT-PACK propagation gap (lens/burns.md:151-153) is answered by chunked rewriting that keeps the prefix byte-stable between advances, the same law our byte-identical-ask cache-hit contract enforces (corpus/steal/ZCODE_OPERATING_PLAYBOOK_20260925.md). mag/context_compression.py (degree-7 hub, lens/graph.md:22) should grow a reversible-stub operator before any lossy summarizer.

### 2. Beyond the Context Window: EDAR, an Adaptive Entropy-Based Routing Framework for Hybrid Retrieval and Long-Context LMs (2609.35831, 2026-09-23, Olufadewa et al.)
Full HTML read. Routes per query: generate the RAG answer's first m=30 tokens, accept if mean entropy <= tau (tuned 1.2), else escalate to full long-context. "97.4% of the accuracy of the pure long-context baseline while reducing total token expenditure by 70.7%" (escalating 18.2%). LongBench v2: naive RAG 41.2%, pure LC 58.4%, EDAR 56.9% (gap to LC not significant); entropy-hallucination Pearson r=0.85. Mechanistic gold for the FTS organ: LC dropped 14 points on Retrieve.KV when the key sat mid-500k context, and EDAR resolved 82% of those because retrieval "effectively repositioned the relevant evidence to the beginning"; conversely 67% of high-entropy RAG failures were hard negatives. Caveat for our lane: evaluated on Llama 4 Scout/Maverick + Gemini 2.5 Pro via API, not local 7B; needs token logprobs (local runtimes give them, some APIs do not). Estate fit: the 1,195,926-row FTS5 organ (lens/corpus.md:8) plus a local 7B can implement this router tomorrow; the entropy check is one pass over already-generated logits.

### 3. Machine-Interpretable Information (MII): Compiling Documents into Searchable and Readable Protocol States (2609.23371, 2026-09-20, Wang et al.)
Full HTML read. A 0.2B Mamba Writer compiles each document into a fixed 56-token canonical state (16 Global learned-query + 24 Event + 16 Cover tokens); a lightweight Translator projects it into a frozen reader's embedding space as a soft prefix, with the state centroid stored in the .mii header for O(1) dense retrieval. The GPT-2-vocab Writer against >128K-vocab readers forces "genuine semantic translation rather than token-level memorization." On HotpotQA dev (7,405 queries) with LOCAL-CLASS readers (Llama-3-8B-Instruct, Qwen-2.5-7B, Mistral-v0.3-7B): FullContext(7K) EM 0.4639, BM25 0.4177, Dense BGE 0.4390, text Summary-512 0.4400, pure MII 0.2986 at 0.4% of FC FLOPs, Residual-MII (state + top-3 sparse chunks, ~480 tokens) 0.4668 EM at 7.0% of FC FLOPs, i.e. beats full context. This is the measured answer to research question 5: guide-style abstraction loses on verbatim entity detail (pure state fails rare-entity reconstruction without a sparse text cache; 8-bit quantization collapses QA) but state-plus-sparse-residual beats the full-context baseline. Estate fit: the catalog is already 1.19M documents; compiled per-doc states + FTS residual is a concrete index-side architecture, and the failure modes (fixed 56-token bandwidth over-compresses dense docs) are the design warnings.

### 4. Similarity Is Not Validity: Defending LLM Semantic Caches Against Poisoning (2609.35908, 2026-09-28, Zhang et al.)
Full HTML read. Threat: "an attacker can cache a malicious response under a query with high cosine similarity to benign requests." The information-bottleneck argument (data-processing inequality) proves any embedding-only matcher is bounded by the information the embedding retained, so no cosine threshold separates valid from invalid hits. Defense reads the raw cache-key text: adversarial keys have a rewrite-residual structure; Deletion Gain searches shortened variants for similarity gains, an Answer Check (key-answer cosine drop + word echo) suppresses benign-wrapper false positives. Blocks 82.0-98.2% of poisoned entries at 5% FPR, end-to-end ASR 30.0->0.6 / 80.2->2.6 / 91.6->1.4 percent across three attack classes, 0.021-0.115 ms per hit, zero serving-time model calls. Scope limit they state: if a deployment keys on only part of the input, the residual can hide in excluded text. Estate fit: the harness holds a byte-identical-ask cache-hit law precisely because similarity is not identity; this paper is the formal version of that law for every semantic-cache shortcut the estate might be tempted to add on top.

### 5. Monte Carlo Estimation for KV Cache Eviction (LORE-KV, 2610.07643, 2026-10-06, Bilal et al.)
Full HTML read. Training-free eviction reframed as future-use prediction: sample M=4 short continuations (T=8 tokens) from the frozen model, score each cached token by a closed-form leave-one-out deletion effect (attention weight times value-minus-output gap through W^O), aggregate prompt-window and future scores with entropy/disagreement reliability weights. On LongBench/RULER/NIAH with Mistral-7B, Llama-3.1-8B, Qwen2.5-14B, Ministral-3-8B plus hybrid Qwen3.5-9B and Gemma-4-12B: beats H2O, StreamingLLM, SnapKV, PyramidKV, Ada-KV, CriticalKV, AnDPro, LAQ++(8) at B=128-1024; RULER gain over AnDPro grows 3.55 points at 4K to 5.85 at 16K. Retained-token framing (the BreadthKV question): matching LORE-KV/E accuracy requires baselines to retain ~208 tokens, a 38.5% cache saving; "a single response-side continuation recovers about 89% of the gain." Honest costs: 1.46-2.77x AnDPro's per-sample wall-clock, gains shrink at larger budgets, decisions are irreversible.

### 6. Lachesis: Lifetime-Aware KV Cache Placement for Agent Serving across HBM and High-Bandwidth Flash (2610.08378, 2026-10-06, Yang et al.)
Full HTML read. Between harness and engine, places KV pages by predicted lifetime: deterministic path uses harness-reported boundaries ("the harness knows whether a segment is discarded at the boundary or retained past it. A short-lived context segment has priority for HBM."), predictive path ranks worker-segment lifetimes with ridge regression (Kendall's tau 0.53). Agentic-session measurements that answer research question 1's setting: agent peak contexts are 29x chatbot workloads; reasoning segments hold 66-83% of a turn's KV yet live one turn; lead-agent segments outlive workers 4.0-6.1x and are unread 71-88% of their lifetime (so read-to-write ratio, the prior-work criterion, is a poor proxy). Flash lifetime extension 1.19-3.13x over HBM-first; tight-SLO configs outlast the five-year warranty. Caveats: trace-driven simulation only (tau3-bench, BFCLv4, AppWorld, SWE-bench Verified, TerminalBench, WebArena traces; Llama-4-Maverick and Qwen3-235B-A22B), no end-to-end latency on real hardware.

### 7. UNREAL: Unifying Retrieval and Long-Context with a Single Model (2610.08463, 2026-10-06, Kinderman et al.)
Full HTML read. Retrieval queries derived from the frozen LLM itself: 64 learned retrieval tokens appended after the query + BM25 context, residual-stream states mixed by learned weights, ColBERT-style MaxSim over 7 mean-pooled vectors per chunk from one intermediate layer. "It adds fewer than 500K trainable parameters and leaves the backbone unchanged." Index: ~21M Wikipedia chunks (~3B tokens). Recall@10: HotpotQA 49.1->73.2, 2WikiMultiHopQA 31.7->60.1, MuSiQue 8.8->14.4 (all four backbones beat BM25/BGE/Qwen3-Embedding/Jina/late-interaction/hybrid-RRF pipelines); NoLiMa 1.0->24.83 at 128K. For research question 4: theoretical FLOPs break-even at 4K-17K tokens depending on backbone, measured TTFT savings "roughly 32K tokens onward." Caveats: backbones are Qwen3.5-4B, two 30B models, and two linear/Mamba hybrids, not our local 7B set; Wikipedia-only training; multi-vector index is heavier than single-vector dense.

### 8. The Attribution-Compression Frontier in Retrieval-Augmented Generation (2609.14245, 2026-09-13, Mody; GroundLM 2026 Workshop at EMNLP)
Abs page read (html timed out twice, fallback succeeded). Measures citation attribution, not just answer quality, across reranking, extractive selection, abstractive summarization, token pruning, and extract-cluster-rewrite on ASQA and QASPER at a nominal 0.25 budget: a RECOMP-style compressor's citations score "0.86 precision against its summaries but 0.12 against source spans", and claim verification finds an unsupported rate of 0.88 versus 0.17 when checking summaries, with a 200-question TRUE T5-XXL audit confirming emitted-vs-grounded gaps. Estate fit: this is the citation-lint law's external validation; any compaction layer we add in front of prose records must be measured against source spans, not against its own summaries, or the estate's citation gates go blind exactly where compression touched the text.

## Per-question synthesis

Q1 (KV compression under agentic sessions, retained-token-count frontier): the late-2026 frontier splits into (a) decode-time byte allocation, where our banked BreadthKV already sits, and this sweep adds LORE-KV (future-aware scoring, 38.5% fewer retained tokens at matched accuracy, but 1.46-2.77x overhead and irreversible); and (b) session-structure exploitation, the genuinely new axis: Lachesis shows 66-83% of a turn's KV is reasoning that dies at turn end, and ReFold shows inter-turn redundancy (re-displayed content, finished turns) is removable reversibly with the prefix cache intact. For a harness like ours the (b) axis is free; it needs no model-side changes.

Q2 (prompt-cache correctness semantics): three hard findings. Rolling agents break exact-prefix caching structurally: evicting the oldest document shifts every retained document's position, so "the longest shared prefix is therefore little more than the fixed instruction" (Request Order Matters, 2610.05833, already banked 10-06); its cure is contiguity, not importance (document-aligned recomputation cut cross-order answer variation 69.0->26.1 percent while capturing less deviation mass). Shared KV tiers keyed only on tokens + model metadata collide across adapters/precisions/versions (KV Provenance, 2609.38706, banked 10-01; accuracy 0.94->0.64 cross-adapter, reasoning to zero on KV-representation mismatch, 93% prompt identification from timing when salt is omitted). And semantic caches are attackable by construction (item 4 above). Net for us: the byte-identical-ask law is not bureaucracy, it is the only setting of these dials with no measured failure mode; anything looser must import a provenance contract or a Deletion-Gain-style validity check.

Q3 (compaction preserving continuity): the measured record now says reversibility beats summarization. ReFold avoids up to 92% of forced compactions and makes every removal undoable from history; KV-streams (banked) carries retained KV across the compaction boundary and RL alone teaches the model to read evicted information back out of the streamed cache; PAIR (banked) shows compression degrades cross-run reliability before solvability and repairs templates via counterfactual rollouts. The CONTEXT-PACK propagation gap (lens/burns.md:151-153) sits exactly where these three papers point: pack-layer changes must be propagated the way KV-streams propagates state, and must be reversible the way ReFold's restore is.

Q4 (long-context vs retrieval at local scale): no paper this window tested literal local 7B end to end, so treat as adjacent evidence: EDAR's router (97.4% of LC accuracy at 29.3% of the tokens) is architecture-agnostic but was run on API models; MII's readers are our exact class (Llama-3-8B, Qwen-2.5-7B, Mistral-7B) and its result is sharp: a 56-token state alone loses to BM25+full reading, state+3-sparse-chunks beats full context at 7% FLOPs; UNREAL puts the long-context-vs-retrieval FLOPs crossover at 4K-17K tokens theoretical, ~32K measured, i.e. below that, retrieval wins on compute in their setting. For the 1.19M-row FTS5 organ the actionable reading: retrieval-first with an entropy-gated escalation path, and compiled per-doc states as a future index layer, not full-context ingestion.

Q5 (information loss in guide-style abstraction vs full context): measured by MII (state-only EM 0.2986 vs full 0.4639; residual hybrid 0.4668; rare-entity verbatim loss; 8-bit quantization collapse), by MORSE (banked 09-30/10-05: context ordering alone decides which evidence survives compression, information preemption), and by the Attribution-Compression Frontier (summaries self-consistent at 0.86 but source-faithful at only 0.12). The d01 tour guide metaphor is now a measured curve: abstraction loses exactly the verbatim-span and provenance layers first, which is why our citation lint runs against sources and why the pack layer should prefer reversible stubs over prose summaries.
