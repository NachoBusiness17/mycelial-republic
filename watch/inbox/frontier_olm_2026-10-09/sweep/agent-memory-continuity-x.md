## Answers to the five research questions

### Q1 correction and supersession (estate: 6 superseded_by edges of 1,256)

Three 2026-10 papers converge on the same shape: supersession is a decision layer with hysteresis, not an edge type.
- MINDSET (2610.08586, submitted 2026-10-06): "Each incoming episode may reinforce, supersede, split or create a schema. The transition decision balances representation distortion, contradiction, historical damage, fragmentation and internal inconsistency, while hysteresis prevents isolated contradictions from prematurely rewriting stable memory." Beats LightMem on LoCoMo F1 (p<0.01, Holm-corrected) over a reproducible 850-question sample. Estate translation: our 6 superseded_by edges are hand-registered corrections (all six verified live this session by key `rel`, endpoints superseded:row-N -> superseder:row-N); the frontier pattern is to make supersession a scored state transition with a hysteresis gate so one contradicting receipt cannot flip a stable law. That maps directly onto the estate's drift-patrol/errata flow (row-2's own text cites 48h_synth/ERRATA.md).
- Stale, Misattributed, or Late (2610.10265, submitted 2026-10-07): the pre-generation failure taxonomy (stale value / wrong principal / too late). Headline datum: "without update resolution, 70.3% of prompts expose a superseded value", and serving only the active value of each correctly keyed slot eliminated observed stale exposure. Also names the merge asymmetry: "Missed merges leave stale values active, whereas false merges silently remove current values" - the exact risk profile of auto-wiring superseded_by edges at scale.
- When Evidence Changes (2610.03902, submitted 2026-10-02): the economics inversion. Under revocation/replacement of source docs, "local repair uses 5-10x fewer revision tokens than rebuilding, yet every memory pipeline costs at least twice full re-reading in held-out conditions" and "source-filtered re-reading remained cheapest". Estate translation: for a harness whose sources (ribs, receipts, git) never disappear, the cheapest correction path after evidence revision is often NOT maintaining derived memory (graph edges) but re-reading the source-filtered evidence. This directly challenges "wire more superseded_by edges" as the first move; the first move is cheap source re-reads, and the edges only earn their keep where sources are cold or gone.

### Q2 knot-as-CRD vs the single-controller law

- Persistent Memory in Multi-Agent LLM Inference (2610.07782, submitted 2026-10-06): on one three-tier architecture, decomposition bounds the per-call KV working set (14.3 MiB vs 35.5 MiB single-pass), but the persistent shared tier produced "no detectable accuracy change (+0.015, 95% CI [-0.011, +0.046])" at +0.368 MiB peak cache cost, and the authors argue the null is structural on single-question benchmarks. Also a correction-culture datum: "Reaching it took four measurement corrections - three inflating the apparent benefit." Estate translation: cross-agent shared memory buys nothing measurable in their setting; what bought the win was decomposition itself (bounding per-call context), which the estate already does via context packs. The single-controller architecture law is consistent with the frontier null: without genuinely concurrent writers, CRDT convergence is not the binding problem, so knot-as-CRD is moot as an intra-host design and only becomes live for the unix mesh nodes / shared-inbox multi-host surface (where two controllers can actually race).
- Beyond Corrected Memory (2610.08101, submitted 2026-10-06): even with correct shared records, "identical retained records can correspond to compliant and violating executions under the same task rule"; removing evidence like receipt/action-dependence leaves 82.4% of opposite-label pairs indistinguishable, restoration separates 97.9%. Estate translation: wire the receipt, not just the fact - which the estate's corr_id/effect-broker split already half-does.
- Background (out-of-window, read anyway): marcobambini substack "Block-Level LWW" (2026-04-13): row-level LWW CRDT works for atomic values but "memory is not atomic"; block-level LWW merges long memory entries paragraph-wise without locks. AgentRoom (arXiv 2608.23740, August): CRDT-merged shared filesystem for concurrent coding agents. If the mesh ever needs coordination-free knot merge, the block-level LWW shape is the starting point; today it answers a problem the single-controller law prevents.

### Q3 L0d context-pack shedding and runaway-recall ceiling (beyond the ported hermes fix)

- Right Memory Wrong Context (2610.07309, submitted 2026-10-05): recall and accuracy metrics do not see admissibility; a filter on off-namespace memory (namespace = the trust boundary of the query) raised top-20 anchor recall from 0.432 to 0.533 on frozen rankings from RHELM and MemOps (3,767 queries) with no score changes inside the namespace. Estate translation: the runaway-recall fix family the estate ported (ceiling + prefetch spilling) is one lever; admissibility filtering by namespace is a second, orthogonal lever that reduces what the pack carries without touching the retriever. For the estate the namespace analogue is lane/seat scope: a builder lane's pack should not admit elder-lane memories at all, not merely rank them lower.
- When to Remember, When to Abstain (2610.07100, submitted 2026-10-05): "only 77.9% of value and belief assertions are supported by their source, versus 96.2% for all other categories"; a global confidence bar cannot separate these, a category-conditioned bar resolves it. Estate translation: the recall ceiling is partly a retention-policy artifact - bank less per category. Maps to the estate's kind-tagged nodes (law/doctrine/steal/knot) as the conditioning axis the percolator currently treats with one threshold.
- QGMem (2610.11920, submitted 2026-10-08): query-time graph construction over event-indexed atomic units ("dynamic memory traces") instead of a persistent always-on graph - working memory is built per query, so the pack only ever carries query-relevant subgraphs. Directly relevant to pack shedding: stop maintaining a dense pack; assemble it per ask.
- The 39%-arrangement datum from the akshay_pachaar X article (2026-09-29, read via fxtwitter): across 15 models and 200,000+ simulated conversations, splitting identical content across turns cost an average of 39% accuracy versus combining it into one turn. Selection AND arrangement both decide; the estate's pack order is currently unpriced.

The ids are truncated free text that can end mid-word with a trailing space (e.g. `invariant:law `, `invariant:schema budget refactor v1 deterministic `, `doctrine:shadow accepted knot ties back into the `).
- Verdict on the ask's hypothesis: the trailing-space bug is A join blocker but not THE join blocker - normalizing 139 ids unblocks 143 edges of the 1,256, which does not re-wire the 1,066 orphans. The frontier patterns on offer: MINDSET's versioned-schema transitions (schemas evolve by reinforce/supersede/split/create moves, so orphans would be absorbed as episodes into schemas rather than linked one-by-one), and QGMem's event-indexed units with query-time graph construction (orphans stay units until a query needs them linked - no bulk re-wiring at all). Both argue against a one-shot bulk relink: the frontier either absorbs orphans lazily (QGMem) or via gated transitions (MINDSET). Cheapest estate-first sequence: (1) normalize the 139 whitespace ids (mechanical, unblocks 143 joins), (2) adopt the lazy pattern - link orphans at read time via the corpus FTS index instead of materializing edges.
