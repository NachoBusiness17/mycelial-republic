## Answers to the four research questions

RQ1 (prefix-cache economics at fan-out vs byte-identical-ask): the frontier confirms the playbook law and extends it. Byte-identity must cover the tools block and JSON key order, not just ask text (item 2, doug.sh key-shuffle bug); at 50 children the regime is capacity-bound, so identity alone is not enough: 88k-token working sets per child blow the pool regardless of identity (item 1); OpenAI now prices shared-prefix reuse at up to 90% off inside a 30-minute window and calls fork-from-shared-prefix economically viable (item 4). Grep receipt: `corpus/steal/ZCODE_OPERATING_PLAYBOOK_20260925.md:10`.

RQ2 (KV management vs L0d shedding + Hermes prefetch spilling, commit f676ee787): three bear directly. LRU repo: under capacity pressure the fix set is compression/tiering/admission control, not liveness prediction (item 1). doug.sh offload table: a spill tier that copies 40 GB to serve 1.5% is theater; the port must instrument restore-hit share (item 2). DeepSeek CED bounded replay: restore only the tail window that still carries signal (item 6). The Hermes memory runaway-recall ceiling fix in f676ee787 (per its commit message, read in AGENTS.md boot context) is the same shape: cap recall, spill opt-in, measure restores.

RQ3 (LLMLingua-class vs LENS-2 laws): HN's in-window LLMLingua-class surface is the token-compression CLI family (zero hits for the academic names). The one shipping example measures savings with usage counters only and has no success-rate instrument; the first commenter demands exactly the estate's bar (item 5). Byte-local reproducible benchmarks exist, but for cache mechanics rather than compression quality: `make setup data repro` (item 1) and `make kv-cache-demo` with offline hash-bound verify (item 3). Estate already holds the LLMLingua PDFs and the eval bar at `memory/research_polished/kv_cache_compaction.md:13`.

RQ4 (one-time context tax vs per-ask re-packing): the frontier analogue exists and is now a vendor feature: OpenAI prewarming, "before the user asks their first question" (item 4), which is deliberate-ask frozen-RIB in product form. doug.sh supplies the cost side: compaction is a re-pack tax ("A summary changes the prompt, so the turn after compaction reads all of it again"), so compact as rarely as allowed = freeze the prefix, pay once. Item 1 adds the boundary condition: the one-time tax only stays paid if the frozen shared prefix actually fits capacity for N concurrent children.
