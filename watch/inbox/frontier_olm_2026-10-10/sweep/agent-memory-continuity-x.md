## Answers to the five research questions (each claim cites what I read or ran)

### RQ1: the day-9 read-path contract, and do the 6 placeholder supersession rows get a real chain model

The three day-9 finds specify a four-part read-path contract, confirmed by my own re-fetch of each abs page this session: (1) serve only the active value of each keyed slot; without update resolution 70.3 percent of prompts expose a superseded value, and missed merges leave stale values active while false merges silently remove current values (2610.10265 abstract, fetched this session); (2) supersession is a scored state transition with hysteresis, not an edge flip: episodes are immutable, schemas versioned, each episode may reinforce, supersede, split or create a schema (2610.08586); (3) the baseline read-path is source-filtered re-reading of current evidence, and every memory pipeline must be costed against it across ingest, revision and use (2610.03902); (4) retrieval has admissibility statuses, not just relevance rank (2610.07309, banked yesterday, re-read today: admissible / inadmissible / unresolved, where lifecycle state can make relevant memory unservable). Does this replace the 6 placeholder superseded_by rows (superseded:row-N -> superseder:row-N, verified as the graph's only supersession edges by the graph lens at watch/inbox/frontier_olm_2026-10-10/lens/graph.md:35)? Yes, structurally: the placeholder rows encode none of the four parts. The chain model the contract implies needs: a keyed slot per claim (the merge asymmetry is the risk), transition typing (reinforce/supersede/split/create), hysteresis parameters, and a per-edge note of whether a source-filtered re-read is cheaper than maintaining the edge (03902's own answer for hot sources like ribs and git: often yes, re-read). The shipping implementation read today (rohitg00/agentmemory README, fetched from raw.githubusercontent.com) confirms the read-path half in production: "Superseded memory versions are excluded from every recall path; the version chain keeps their history."

### RQ2: architectures that automate the already_inside link (18 edges / 140 steals, graph lens line 33)

Nothing read this session links a new steal to estate prior art fully automatically; what exists is two half-machines that compose into one. Write side: SAGE (2609.36043, fetched this session) gates what enters an evolving memory by per-item paired comparison of current versus edited behavior, committing an edit only when wins are statistically reliable against losses, with asymmetric penalty for regressions; it is closed-form statistics, no LLM judge, and it cut regression rates in 19 of 20 settings. Read side: TIDE (2609.37544) runs responsibility credit assignment, distributing outcome signals to the specific memories referenced during generation, over a capacity-constrained population that reinforce, crossover, mutate or evict. Estate translation: already_inside is responsibility credit with the reference set fixed to estate modules; SAGE's paired test is the acceptance gate a fill-ball should pass before minting a steal node, and TIDE's credit machinery is the weighting scheme for the 18 existing edges. Yesterday's sweep already banked the third half-machine (QGMem's lazy query-time linking); today's adds the gate and the credit. Also noted: our catalog ALREADY mirrors whole repos nobody linked (getzep 881 rows, agentmemory 783 rows, single-pass grep this session) - the linking failure is not a data failure.

### RQ3: does the route-map 25x boot cut generalize to warm_state.json + zknot, and when does it not

Warm boot today (memory/warm_state.json read in full this session, 989 bytes, schema hermes_warm_state.v1): chain tip, verkle root, deployment URLs, a brief pointer. That IS a route map - pointers, not content. The generalization holds only under conditions the day-9 economics paper prices precisely (2610.03902, re-fetched): memory amortizes over uses, crossing full re-reading's cost only after 2-14 uses of the same material, and source-filtered re-reading stays cheapest below that. A session that consults the boot pack once and then diverges is below the crossover; the 25x cut claim should be falsified exactly there. The structural-null paper (2610.07782, banked yesterday, re-read today) adds the second non-generalization condition: a persistent tier buys nothing measurable when each query carries its own evidence and correctness requires resetting traces between conditions - i.e. a route map pays only when later asks actually reuse earlier evidence across sessions. Third condition from MemFit (2610.00872, fetched this session): the write side must be near-free - "stores each turn verbatim in an append-only store with near-instantaneous, LLM-free insertion" - or the amortization ledger goes negative at ingest. Estate falsifier, stated as a test not a claim: instrument warm boots with a use counter per pack field; if median uses-per-session of a field is under the 03902 crossover band, replace that field with a source-filtered re-read (zknot/state paths are hot sources; 03902 says re-read wins there).

### RQ4: what knowledge_graph schema v3 must carry so novelty checks see the 122 orphan steals

Four columns, each grounded in a paper read this session: (1) transition typing on supersession edges - reinforce / supersede / split / create with hysteresis metadata (2610.08586); the 6 placeholder rows carry none of it. (2) A weight with credit semantics - TIDE's population operations (reinforce, crossover, mutate, evict) over a capacity-constrained pool are exactly edge-weight maintenance under budget; the graph lens (line 6) records that no weight field exists today. (3) Admissibility status per memory-query pair - admissible / inadmissible / unresolved, with lifecycle state as a first-class field so a superseded steal can be excluded from recall while kept in history (2610.07309 + agentmemory's production semantics). (4) A store-versus-reconstruct flag - MemoWM's allocation rule stores only what exceeds the world model's predictive prior, cutting experience-specific storage 53.9 percent versus MIRIX while beating the strongest baseline by 2.62 points (2610.10778, fetched this session); the graph analogue is not storing derivable joins. The day-9 file's own finding stands as step zero: normalize the 139 whitespace node ids to unblock 143 edges before any of this.

### RQ5: what the world-rib contract needs that compiler-without-territory cannot express

Two mechanisms read today fill the exact gap the laws lens names (watch/inbox/frontier_olm_2026-10-10/lens/laws.md:51: "a RIB schema that lowers to 2D field, 3D, world, code, plus the re-derivable-territory guard"). MemoWM (2610.10778) supplies the allocation calculus: what the territory model can predict need not be stored in the rib; the rib stores only residuals with downstream value beyond the predictive prior, and the trade-off is an explicit rule balancing expected reconstruction error against storage cost, with optimal shared-model capacity growing as more interactions are retained. Action-conditioned bisimulation (2609.38778, fetched this session) supplies the re-derivation guard verbatim: "Two states merge only when their shared actions lead to agreeing outcomes and successor blocks under an affordance label" - observation similarity never enters the rule and nothing is trained; the frozen agent fills an empirical predictive state graph as it acts. For the world rib that means: territory identity is action-outcome equivalence, not appearance; a rib may re-derive any state whose affordance-labeled action outcomes agree; and the rib's memory budget is set by reconstruction-error tolerance, not by capture volume. Together they are the missing target type's first two laws.
