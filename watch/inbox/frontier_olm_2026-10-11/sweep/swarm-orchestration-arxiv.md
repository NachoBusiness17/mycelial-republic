Quote (16 words, from the html body): "These external judgments are used only for evaluation

1. One base model holds all three roles each cycle g: L_agent = L_eval = L_opt = L^(g).
2. Algorithm 2 (workflow optimization): the optimizer proposes an orchestrator-subagent
   workflow (roles, instructions, output contracts, call order), the agent executes it, the
   evaluator compares output to the best-so-far workspace y*, and an elite of size 1 is

   Bradley-Terry scores; the top K-1 trajectories form an SFT set with the workflow prompt

4. Two cycles on Qwen3.6-27B (L0 -> L1 -> L2). Evolutionary search runs on 12 synthetic
   research-programming tasks (9 train / 3 held-out; finance, pharmacy, robotics). Public
   benchmarks are evaluation-only.
5. Grading: the model grades itself in-loop ("Current model's comparisons determine
   Bradley-Terry ranks" - html body). The external panel (OpenAI GPT-5.5 and Claude Opus 4.8

   quote above. There is NO null control on the grader: no random-workflow arm, no
   shuffled-label arm (verified by direct question against the full text; the closest things
   are a mutual-information permutation adjustment in Appendix F and a generic-directive

### 2.4 Attention Tax, Handoff Tax (2610.06069)

Fetched: https://arxiv.org/abs/2610.06069 and https://arxiv.org/html/2610.06069v1 (full body).
Meta: Akshit Anchan and Nayonika Sen, 2026-10-05, cs.MA.
Quote (19 words, from the abs page abstract): "Decomposition reduces the burden of long
contexts but incurs a handoff tax when information is compressed or transferred between
agents."

one model, two tasks; crossover not directly observed; handoff tax is one scalar.
