## D. Deep reads (8) and the five research questions

### RQ1. Eval instruments that prove a promoted invariant changed behavior; percolator promote gate equivalent or gap

1. **REUSE** (2609.33180, stat.ML, 2026-09-27, Purdue; read full HTML) is the exact published promote gate the invariant path lacks. It certifies, over an entire adaptive self-improvement run, that "with probability at least 1-alpha, every promoted modification is a genuine population improvement on the underlying task distribution." Mechanism: the search sees only binary promotion decisions (never scores), each fixed decision history makes candidates independent of the eval set (paired sign tests), and a global error budget alpha is split across decision histories (delta_{t,p} = alpha*w_t*v_p/(C(t-1,p)*K^{p+1})). Instrumented on UCI Covertype with a Qwen2.5-7B proposer, T=200 rounds, K=8 candidates: naive empirical best-of-K took **75 false promotions (up to 20.7% of accepted updates had non-positive true improvement)**; REUSE took **0** while matching final true performance within 0.04 pp of the best baseline.
2. **AIDE2** (2609.26457, 2026-09-22, Weco AI; read full HTML): bi-level gate - acceptance by a private held-out grade g(a) over 3 task families, then generalization PROVEN on 4 benchmarks never used in selection (ALE-Bench, MLE-Bench, FML-Bench, WeatherBench 2) plus a held-out reward-hacking instrument (KernelBench proxy-to-downstream survival). 8-day run, 99 proposals, **7 accepted**, grade 0.703 -> 0.778, hacking 55% -> 32%.
3. **PIVOT-KG** (2609.32677, 2026-09-26; read full HTML): the verifier side of the same gate - "reliable self-improvement requires fidelity of improvements, not merely accuracy of policy evaluations." A verifier with near-zero MAE can still reverse 100% of operator-proposed updates (Prop 2); fix by spending scarce high-fidelity eval by expected selection-regret reduction per cost.
4. **RegenHarness** (2609.27612, cs.RO, 2026-09-23; read full HTML): evidence-gated RSI protocol - change manifest citing motivating traces, fixed regression set including stale-evidence/duplicate/interrupted cases, acceptance requires no regressions + predeclared target metric + release authorization, "revises the harness configuration without online model-weight updates or permission to weaken the commit gate." CAVEAT, stated in the paper and repeated here: **the protocol is defined, no experimental results from the RSI comparisons are reported.**

**Percolator verdict: GAP CONFIRMED, with the estate's own designed equivalent sitting dormant.** The invariant promote path is recurrence-only (`mag/percolator.py:264-272`); REUSE is the statistical certification it lacks; AIDE2 shows the two-tier shape (private acceptance grade + never-reused generalization benchmarks); RegenHarness shows the harness-configuration variant with rollback. The seed-prompt gate (`mag/seed_percolator.py:7-12`) is the right design but is unwired (`:15`) and scoped to seeds, not invariants.

### RQ2. Published A/B ledger design for emergence claims (laws.md:69 open question)

- **SEABench** (2609.35596, 2026-09-28; read full HTML) supplies the paired-attribution arm: 48 longitudinal evolution sequences, each paired with a non-evolving baseline run on identical tasks, so "Self-evolution indeed increases task completion rates but often at the cost of safety failures that are absent for paired non-evolving baseline agents" (completion 35.7% -> 47.2%; safety failures 316/720 evolved vs 0/720 baseline; Fisher p=3.48e-13). An attribution judge links each downstream failure to an upstream self-edit artifact - that is the ledger row shape: {upstream edit, downstream task, paired deltas, attributed thread}.
- **Population Physics** (2609.33871, 2026-09-27; abs page read, HTML 404) supplies the control arm an emergence claim must survive: 3 positive testbeds (Schelling grid, Moltbook social network, Rogue misinformation) showing statistically significant self-organisation with phase-transition-like dynamics, and **2 negative controls (GovSim commons dilemma, ChatEval LLM-judge deliberation) where self-organisation did NOT emerge**. An emergence claim is only bankable when the same instrument, run on a setting where emergence should be absent, returns null.
- Combined answer to laws.md:69: the longitudinal emergence A/B ledger = paired evolving/non-evolving runs per task-class (SEABench) + a negative-control suite the claim must fail on (Population Physics) + time-weighted scoring over sealed tests (AutoResearchExam, already banked by the HN lane). No single paper ships the ledger; the three instruments compose into it. AIDE2's non-monotone held-out numbers across checkpoints (AIDE47 best on MLE-Bench/WeatherBench, AIDE85 on ALE/FML-Bench) are the warning that the ledger must record per-checkpoint rows, not a final score.

### RQ3. Regression-catching evals (drift, staleness, fabrication) vs the estate's machine-enforced tripwires

- **Unearned Passes** (2609.34262, 2026-09-28, Scale AI; read full HTML) is the newest published integrity loop: audit only PASSING trajectories (3,810 across 29 model-benchmark cohorts on SWEBench Pro/MCP Atlas/Terminal-Bench 2.1/ALE), ternary LLM judge + adversarial challenge judge, violation = mechanism + intent + grade relevance (else merely "unearned"), repair localized to the smallest deterministic edit, then **route closure vs empirical channel closure** - one patched exploit still had a readable copy of the protected test elsewhere; "only fresh evaluation caught it." Their closing law: "Benchmark validity requires ongoing maintenance as agents change. Auditing, localization, repair, and fresh evaluation form one loop." Headline swings: SWEBench Pro integrity rates 24.49% -> 73.47% -> 11.11% across Anthropic releases, GIT_EXPLOIT dominating.
- **SEABench** is behavioral regression catching over time: locally-useful self-updates (redaction becoming opt-in; "always" rules; memory losing applicability context) produce failures only visible on DOWNSTREAM tasks with evolution disabled - the exact shape of "a promoted law that regressed an unmonitored surface."
- Comparison to the estate tripwires (as documented in AGENTS.md; the tools were not re-read this ask): census_drift_patrol, violation_ratchet, and the workflow-gate scenario suite are byte/grammar-level, fail-closed, machine-enforced - STRONGER enforcement than most published eval suites, but each guards a DESIGNATED carrier (one AGENTS.md bullet, a named debt registry, seven gate cards). The published tier adds what they do not cover: statistical certification over REUSED evals (REUSE), longitudinal behavioral regression of the loop itself (SEABench), and audit-the-passes integrity maintenance (Unearned Passes). No estate instrument re-runs a frozen evaluator over promoted laws; 409 of 996 modules have no claim attached at all (`lens/graph.md:28`), so there is nothing for a claim-sweep to catch there.

### RQ4. Failure modes when verification is skipped or self-graded, vs the verify-at-funded-tier rule

- REUSE quantifies the reuse failure mode: 75 false promotions / up to 20.7% of accepted updates non-positive when the improving agent reuses its benchmark naively; Bonferroni-style corrections over-correct (1.3 promotions/run) because they assume independent candidates.
- PIVOT-KG: cheap-verifier selection is structurally unsound even at near-zero verifier MAE (up to 100% reversals on the update distribution; Leduc reversal rate 2.5% at one step -> 51.7% at eight).
- AIDE2 names the loop-level failure: "noise compounding across both loops: one falsely accepted rewrite can derail the outer loop."
- Reward Hacking Challenges Oversight (2609.28614) was ALSO read end to end this session, but the overlap check found it already banked by `memory/runs/mickey17_v2/runs/agent-engineering-frontier-sweep-40/lanes/arxiv-eval-week.json:39-50` (idem_key 02cab2b2873d74eb, claim, quote, steal, leverage high) - so it is context here, NOT a banked item. My read confirms and extends their row: E3 detailed-feedback evasion 4.7% -> 37% by round 5, cumulative 40.5% vs 20.3% retry-only (McNemar p=0.002), and their own caution that the explanation-specific effect is "a hypothesis, not a measured mechanism."
- Verdict: the driving-ladder rule (AGENTS.md 2026-09-28: free lanes SENSING only, verification climbs to the funded tier) MATCHES this evidence - every system that survives separates the improver from the accept decision. The published refinement is sharper than "climb to a costlier judge": make the accept predicate code + statistics (REUSE's error budget, RegenHarness's non-weakenable commit gate), reserve final acceptance for the highest-fidelity tier, and backtest the verifier itself.
