--- [/u/djseto] MLX support for 8 bit KV Cache
Does Ollama on Mac support configuring KV Cache to 8 bit quant? 
 In long running agentic tasks with Hermes, my Qwen 3.8 27B MLX Model eventually pushes hard on memory pressure (64GB Mac Studio M4 Max, 64k or 128k context window) and I think it’s because of KV Cache growing too large. I asked Claude for some help and it suggested setting cache type to Q8 and flash attention to true vs the supposed default of F16 for KV Cache. It the corrected itself and said those settings only work for GGUF models. I don’t know which is true so hoping the brain trust here knows.

--- [/u/spyingwind] /u/spyingwind on MLX support for 8 bit KV Cache
I think if you set these then it might help. Worst case is it doesn't.
 export OLLAMA_FLASH_ATTENTION=1 export OLLAMA_KV_CACHE_TYPE=q8_0
