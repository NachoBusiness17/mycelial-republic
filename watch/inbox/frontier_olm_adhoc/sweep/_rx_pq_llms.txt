# PromptQuorum

> One prompt. Every model. One verdict. PromptQuorum is a multi-model AI dispatch and consensus tool. Write one structured prompt, send it simultaneously to ChatGPT, Claude, Gemini and 25+ AI models, then run consensus analysis across all responses — hallucination detection, contradiction scoring, best-answer extraction. 100% private: API keys stay in your browser, no data reaches PromptQuorum servers.

## Product

- **Primary use case**: Dispatch a single prompt to 25+ AI models simultaneously and analyze consensus across all responses
- **Category**: AI Tools / Multi-model workspace / Prompt engineering
- **Pricing**: Free. Bring your own API key (BYOM) or use a local LLM. No account required.
- **Platforms**: macOS, Windows, Linux (desktop)
- **Offline support**: Full offline capability via local LLMs (Ollama, LM Studio, Jan AI, GPT4All)
- **Status**: Public beta — desktop app available for macOS, Windows, and Linux, no waitlist or signup required
- **Developer**: Hans Kuepper — [LinkedIn](https://www.linkedin.com/in/hanskuepper/)

## Supported AI Models

**Cloud providers (25+)**: OpenAI (GPT-5.6), Anthropic Claude (Sonnet 5), Google Gemini (3.1 Pro), xAI Grok, DeepSeek, Mistral, Cohere, Meta Llama (via Together AI, Groq, OpenRouter), Perplexity, and more.

**Local / self-hosted**: Ollama, LM Studio, Jan AI, GPT4All, Open WebUI, KoboldCpp, vLLM, oobabooga, and any OpenAI-compatible endpoint.

## Core Features

- **9 Prompt Frameworks**: CO-STAR (Singapore GPT-4 competition winner), CRAFT, RISEN, APE, SPECS, TRACE, RTF, Google Prompt, Single Prompt Line — plus 2 fully custom frameworks
- **Dispatch**: One-click simultaneous dispatch to all connected AI services; tabs open in parallel
- **Quorum Analysis (13 types)**: Consensus Summary, Weighted Merge, Atomic Facts Extraction, Overlap Mapping, Contradiction Detection, Confidence Scoring, Completeness Check, Hallucination Detection, Redundancy Elimination, Best Answer Selection, Multi-Model Ensemble, Controversy Flag, Response Ranking
- **Optimization**: AI-powered iterative prompt refinement with 8 one-click refinements and full version history
- **Privacy (BYOM)**: API keys stored only in browser localStorage, never transmitted; zero telemetry, zero tracking
- **Export**: Results export in TXT, MD, JSON, CSV, HTML, PDF

## MCP Server (Live)

PromptQuorum runs a live, public, read-only [Model Context Protocol](https://modelcontextprotocol.io) server exposing the site's own content and software directory to any MCP-compatible client. No account, API key, or authentication required.

- **Transport**: Streamable HTTP — `POST`/`GET` to `https://www.promptquorum.com/api/mcp`
- **Server version**: 2.0.0 — 17 tools, 5 resources, 4 prompts; rate limit 120 requests/minute/IP
- **Discovery manifest**: [https://www.promptquorum.com/mcp.json](https://www.promptquorum.com/mcp.json)
- **Documentation**: [https://www.promptquorum.com/mcp-stats](https://www.promptquorum.com/mcp-stats)
- **Tools** (find apps):
  - `find_best_apps(goal, os?, ramGb?, vramGb?, experience?, offlineOnly?, freeOnly?, limit?)` — plain-language goal + machine → ranked shortlist with reasons, trade-offs and missing details
  - `search_apps(query?, category?, useCase?, os?, ramGb?, vramGb?, price?, worksWith?, installEffort?, locality?, mcpSupport?, license?, sortBy?, limit?, offset?)` — filter the Local LLM Software Directory
  - `recommend_stack(goal, os?, ramGb?, vramGb?)` — ready-made multi-app stack with hardware floor
  - `find_local_alternative(cloudApp)` — local alternatives to a cloud AI product (image, voice/audio)
  - `get_app_alternatives(slug, os?, freeOnly?, easierInstall?)` — similar apps to one the user knows
  - `get_app_details(slug)` — full directory data (license, hardware, platforms, price) for one tool
  - `list_categories()` — valid category/use-case/OS filter values with counts
- **Tools** (decide and check):
  - `compare_apps(slugs[2-5], criteria?)` — criteria matrix, per-need leaders, summary
  - `check_hardware_compatibility(slug, os?, ramGb?, vramGb?, modelBillions?, quantization?)` — fits / too-demanding / unknown, with estimate labelled
  - `estimate_vram(modelBillions, quantization?, contextLength?, availableGb?)` — memory estimate for a model
  - `explain_license(licenseString, useCase?)` — plain-language license rule of thumb; not legal advice
- **Tools** (read and learn):
  - `search_promptquorum(query, lang?, cluster?, limit?)` — search all guides and the software directory
  - `get_article(cluster, slug, lang?)` — fetch one article's full content
  - `find_related_content(app? | topic?)` — review, hands-on test, comparison and setup articles
  - `get_hands_on_test(slug?)` — PromptQuorum's own hands-on findings with evidence labels; reports untested apps as untested
  - `get_latest(type?, limit?, since?)` — recently added apps, updated articles, new tests
  - `list_clusters()` — every content section with a description
- **Resources**: `promptquorum://categories`, `promptquorum://stacks`, `promptquorum://app/{slug}`, `promptquorum://article/{cluster}/{slug}`, `promptquorum://methodology`
- **Prompts**: `recommend_local_ai_stack`, `compare_local_ai_tools`, `find_offline_alternative`, `check_commercial_license`
- **Example client config** (Claude Desktop / any MCP client that accepts a URL):
  ```json
  { "mcpServers": { "promptquorum": { "url": "https://www.promptquorum.com/api/mcp" } } }
  ```
