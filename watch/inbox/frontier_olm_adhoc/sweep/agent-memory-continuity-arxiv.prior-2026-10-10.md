## BANKED ITEMS (strongest first; the JSON result carries these 8)

### 1. Use and Disuse: Intent-Structured Experience Consolidation for Memory and Learning in LLM Agents (Hippocam) - arXiv:2610.12124 - 2026-10-08 - cs.AI
Zeng, Liu, Wang, Jin, Li, Liu. Full-text read.
The single closest blueprint to our standing-wave law. Intent stack (nested LIFO of purpose + exit-condition + message index) partitions the live context; consolidation replaces closed spans with self-contained first-person summaries that KEEP "state changes, conclusions, evidence with provenance" and prune discovery process; replaced messages become children in an archive message-tree (context = layer 1); recall tool descends the tree progressively. Unused experience is never scored or deleted: it recurses deeper and becomes "progressively more abstract" through repeated folds; used knowledge is reconsolidated with new work. No importance scores, no time decay.
Numbers (DeepSeek-V4.1-Flash, single runs): ALFWorld 97.8%, ScienceWorld 81.9%, StreamBench 81.7% / 85.8% at 300 tasks, cross-domain ALFWorld to ScienceWorld 78.9% (+16.2pp over ACE), GoodAI LTM 88.7% interleaved vs 85.1% isolated (no degradation from interleaving), LoCoMo 77.6% (+10.1pp over A-Mem), MemoryAgentBench conflict 97.0/77.0/41.0% at 6k/32k/64k. Honest limits: single runs; 64k still hard (41.0%); consolidation is 26.8-34.0% of StreamBench cost; cache-discount savings hold only while a cache hit costs under ~15% of a miss.
WHY IT MATTERS HERE: this is the published twin of "deletes mass but keeps recipes" - the archive tree gives knowledge_graph.json a provenance-carrying evidence layer (every summary carries evidence-with-provenance + informative failures), and the use-and-disuse dynamic replaces hand-tuned decay with reconsolidation-on-use. Overlap: mirrored name-only at catalog L1003577.

### 2. Real Long-Term Memory for AI: A 50-Million-Token Window That Is Faster and Cheaper Than Recompute (galahad-kv) - arXiv:2610.10845 - 2026-10-07 - cs.CL/DC
Sietse Schelpe (single author). Full-text read. GENUINELY NEW.
The direct published rival/verifier for the night-cools route-map boot claim. Persists per-block KV state (~16k tokens/block) to encrypted local NVMe (AES-256-GCM, one key per org) via a vLLM 0.31.0 KV-transfer connector; restore grafts KV back so the forward pass resumes without recompute. 100/100 zero-recompute restores across 0-50M depth (Gemma 4 12B + 31B, single H100).
Conditions that bound any boot-cut multiple: restore is 2.8x faster (12B bf16: 0.266s vs 0.760s) and 4.25x (31B FP8: 0.347s vs 1.475s), 8.8-12.3x less GPU energy; restore latency is depth-independent; larger models gain MORE. Planted-fact recall 82/100 (12B) and 98/100 (31B), zero hallucinations, 0/20 fabrications on negative controls, with an anti-cheat protocol (nonce mutation, blind ingestion, decoys, on-disk audits). Costs: 36.4 KiB/token (12B sliding-window) = 1.86 TB per 50M tokens; 134 KiB/token (31B) = 6.25 TB; deposit 20,839 tok/s (12B).
WHY IT MATTERS HERE: the honest published envelope for KV-state warm-boot is 2.8-4.3x latency (up to ~12x on energy), NOT 25x - so the route-map 25x claim holds only if it measures a different denominator (full cold re-derivation of routes vs byte-restore). One block resident at a time ("Processed is not held-in-VRAM is not restored") and mandatory local NVMe are the load-bearing caveats. Overlap: zero hits.

### 3. Event-Centric Memory with Query-Aware Graph Augmentation for Long-Term Conversational Agents (QGMem) - arXiv:2610.11920 - 2026-10-08 - cs.CL
Liu, Yuan, Liu, Li, Lin, Li, Chen, Hu. Full-text read.
The concrete data model for filling a 99.7%-empty evidence layer WITHOUT adding name-only nodes. Atomic memory unit m = (context-independent summary, source dialogue span d_m = traceable provenance, entity set, location set, factual-time + utterance-time dual timestamps, structured triple (subject, predicate, object)), extracted over sliding windows (6 turns, overlap 2, step 4); every unit carries start_turn/end_turn evidence bounds. Units do NOT link to each other directly: they link via shared membership in dynamic memory traces r_h = (relation, ordered state trajectory, latest supported state), built by similarity clustering (tau=0.80) plus LLM consolidation that orders chronologically, merges repeats, treats later incompatible values as updates. Query time: hybrid retrieval (BM25 + dense + attribute) fused by RRF (pool 100) plus reranker to k=10; a local graph (entities + values, predicate-labeled edges, bounded k edges / 2k nodes) is induced ONLY from activated facts, encoded as a graph token ahead of text for a frozen LLM.
Numbers: LoCoMo 82.77% (+8.30 over LiCoMemory), LongMemEval-S 62.14%, multi-hop conflict 12.50% (nearly doubles best baseline but absolutely weak), BEAM-500K 38.91% (+5.41 over Mem0), >35% at 1M tokens / 29.81% at 10M. Ablation: w/o atomic units -7.43, w/o reranker -5.23, w/o graph token -3.95. Cost: 5.94 s/QA vs RAG 3.84 s.
WHY IT MATTERS HERE: the (provenance span, dual time, triple, trace) schema IS the why-link the knowledge graph lacks; edges-as-predicates derived only from activated facts avoid name-only node sprawl. Overlap: mirrored name-only at catalog L1003519.

### 4. Rehearse Everything, Remember Nothing: Attic-KV Rehearses What Will Be Read - arXiv:2610.12133 - 2026-10-08 - cs.CL/LG
Zhiyun Shi. Full-text read.
The sharpest published conditions table for compaction that preserves retrieval of evicted facts. Under tight KV budgets, whole-context rehearsal (model rereads its context, keeps what it attends to) retains answer entries near chance (3.5-5.0% at 3% keep): "rehearse everything, remember nothing." Attic-KV instead has the model quiz itself with QA pairs whose answers quote the exact context words (<=256 tokens), plus content-adaptive anchor rehearsal (rehearsal size = tokens of sentences containing anchors; Spearman 0.59 with fact count); scores combine by entry-wise max.
Dose-response (RULER-4K, Qwen3-8B): advantage over full reread is 41.9 points at 3% keep, 23.5 at 5%, 1.1 at 10%, all methods converge ~96.5 at 20-30% - the gain exists ONLY under scarcity. Best training-free method in all 8 settings; +17.1 on KVgrad, +28.1 on RestoreKV+. Limits: dense multi-key tasks stay unsolved at tight budgets (14.0/1.9 at 3%, chance level); restore tokens exist only for Qwen3-8B / Llama-3.1-8B; a coherence trade-off drops passage retrieval 77 to 40.
WHY IT MATTERS HERE: for the 7-day standing-wave law, the transferable principle is "rehearse what will be read" - retention decisions keyed to anticipated queries, not uniform rereads; and the dose-response curve says compaction research only pays where the budget is genuinely tight. Overlap: mirrored name-only at catalog L1003581.

### 5. Agentic-TTT: Training test-time policy for test-time training - arXiv:2610.12002 - 2026-10-08 - cs.LG/AI/CL
Jiahao Lu, Mohan Kankanhalli. Full-text read.
The strongest 2026 answer to the living-weights context-vs-weight tier question. TTT (5 methods: PoT, TTT-FS, TTRL, SEAL, TLM) becomes callable tools; a learned policy (Assign/Adapt/Load/Generate, max 6 turns) decides per query whether to adapt weights, reuse an existing LoRA skill, or answer directly; accumulated skills + pools form an "evolving capability environment." Trained by SFT then Dr. GRPO on base-relative utility minus compute cost.
Numbers (Qwen2.5-7B-Instruct; 8 domains): utility 0.256 direct to 0.510 SFT+RL (~2x), 0.375 SFT-only; ~20:1 help-to-harm; 100 reuse decisions: 61 helpful / 1 harmful. Compute knob: raising lambda_comp 0 to 0.4 cuts compute ~35.5%; moderate penalties IMPROVE utility because unconstrained policies overuse TTT. Always-SEAL degrades Math (-0.368) and Code (-0.236): weight updates HURT domain-mismatched inputs. Limits they state: benefit-enriched benchmark (~65% TTT-positive vs 7% of full MATH-500), no frontier models, stream-level credit assignment only weakly addressed.
WHY IT MATTERS HERE: the rib's open question gets a published shape - weight updates are a tool to be gated by a cheaper policy, with utility-minus-compute as the training signal; reuse of an existing adapter beats re-adaptation. Overlap: mirrored name-only at catalog L1003539.

### 6. The Right Memory in the Wrong Context: Verifying Retrieval Admissibility in Long-Term Agent Memory - arXiv:2610.07309 - 2026-10-05 - cs.AI/IR/MA
Zi Wang, Xingqiao Wang, Emmanuel Addai, Devika Ambekar, Xiaowei Xu. Abs read. GENUINELY NEW.
Retrieved-but-topically-relevant memory can still be inadmissible: it belongs to another principal, violates policy, or reflects an incompatible lifecycle state (stale state = exactly our superseded-fact problem). Framework: label each memory-query pair admissible / inadmissible / unresolved; compare retrieval routes at equal required-evidence recall; trace memory IDs through prompts linking exposure to disclosure. Evidence: reanalysis of frozen RHELM+MemOps rankings (3,767 queries) lifts anchor recall 0.432 to 0.533 and 80%-recall feasibility 0.237 to 0.311 while cutting exact similarity evaluations 98.3%; 16 controlled exposure scenarios show relevant-inadmissible literal disclosure +0.156 (CI [0.031, 0.312]).
WHY IT MATTERS HERE: gives the knowledge graph an admissibility edge class (principal / policy / lifecycle-state) so why-links carry WHEN a fact may be used, not just WHERE it came from - directly serves conflict-aware reuse after eviction. Overlap: zero hits.

### 7. When to Remember, When to Abstain: Category-Conditioned Retention for Reliable Agent Memory - arXiv:2610.07100 - 2026-10-05 - cs.AI/MA
Olukunle Owolabi, Pulkit Gupta, Fei Wang. Abs read. GENUINELY NEW.
Selective prediction AT THE WRITE BOUNDARY: retention confidence thresholds conditioned on the semantic category of an assertion instead of one global threshold. Motivating asymmetry across 4,715 candidate assertions (100 synthetic personas, deployed cold-start pipeline): only 77.9% of value/belief assertions were supported by their sources vs 96.2% for all other categories. Category-conditioned thresholds cut unsupported retentions 6.2% to 4.0% (~36% relative) while preserving ~13pp more coverage (95% CI 9.8-16.0) than a global threshold.
WHY IT MATTERS HERE: the standing-wave's delete-mass-keep-recipes law needs exactly this - a per-category write bar (recipes/procedures get the liberal bar, values/beliefs/judgments get the strict bar) instead of uniform retention scoring. Overlap: zero hits.

### 8. MemTrial: Learning When to Trust Memory in LLM Portfolio Agents - arXiv:2610.11732 - 2026-10-08 - cs.AI
Guanghao Wu, Zhuo Cai, Shoujin Wang. Abs read. GENUINELY NEW.
Memory credit assignment done by counterfactual drafts: with-and-without-experience decision drafts cancel the shared market factor; each retrieved experience gets a Banzhaf value over a fractional-factorial design of 8 draft combinations; credits pooled across dates and similar experiences with a hierarchical Bayesian model; the agent acts on credits only after they demonstrate predictive power on unseen dates, else defaults to a conservative reference (1/N). Numbers: best of 15 on a semi-synthetic benchmark with known experience quality; losses capped 2.2% below 1/N vs 15-38% for the best experience-learning agent; +21.2% avg utility over the best experience-learning agent; beats every LLM baseline on InvestorBench across 8 LLMs.
WHY IT MATTERS HERE: the estate's self-steal meter and improve/promote gate are memory-credit problems; MemTrial is the published pattern for verifying a memory EARNS its keep before it influences decisions - with a fallback when verification fails. Overlap: zero hits.

## ANSWER SKETCHES PER RESEARCH QUESTION

Q1 (evidence linking vs name-only nodes): cognee/letta/mem0 docs are already in-corpus (catalog hits above); the NEW steal is QGMem's schema - every memory unit carries provenance span + dual timestamps + triple, and links ONLY via shared trace membership (state trajectories), with graph edges induced only from query-activated facts. Hippocam adds: summaries must retain "evidence with provenance" and informative failures. Admissibility edges (2610.07309) add when-usable. None of these add unearned nodes.
Q2 (25x boot cut): the published warm-reload envelope is 2.8-4.3x latency (galahad-kv, grows with model size, depth-independent, local-NVMe-bound, terabyte store) and up to 12.3x on energy; sleep-time compute reports ~5x on test-time compute. A 25x claim therefore needs its denominator stated (cold re-derivation vs byte-restore vs recompute-per-token) or it overclaims vs published conditions.
Q3 (in-context vs weights): 2026 evidence says gate weight updates behind a cheap policy (Agentic-TTT: always-adapting hurts, 20:1 help-to-harm when gated, compute-penalty term improves utility); Hippocam shows pure in-context + structured consolidation matching or beating on agent suites; DPPM shows parametric memory winning decisively over Full Context on personalization (+21pp) at 2B-7B scale with a 62.7x latency win. The tier answer: context-first with consolidation; weights only where a verified reusable skill or stable preference exists, gated by measured utility.
Q4 (compaction preserving evicted facts): rehearse-what-will-be-read (Attic-KV, dose-response: gains only under scarcity), residual tokens after summaries (REMORY), write-boundary category-conditioned retention (2610.07100), no-deletion recursive abstraction (Hippocam), trace-membership linking (QGMem), admissibility-aware exposure (2610.07309). All compatible with delete-mass-keep-recipes IF recipes are stored as executable, replay-verifiable artifacts (Memento 3).
