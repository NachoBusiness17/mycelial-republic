## 1. What the MUD remembers per visitor

**Identity:** first visit mints `visitor_id = "mv-" + sha256(world_salt ‖ client_nonce)[:12]`, stored in a first-party cookie. No account, no email, no IP ever enters the id. The id is the only join key.

**Raw visit row — F1 canonical string**, one JSONL line per visit, schema deliberately parallel to `memory/biography/knot_timeline.jsonl:1`:

```json
{"store":"mud.visit.v1","visitor_id":"mv-3fa9c201b7e4","visit_id":"mv-3fa9c201b7e4:20260923T0344","start_minute":"2026-09-23T03:44:00Z","end_minute":"2026-09-23T04:12:00Z","start_unix_minute":1790135040,"end_unix_minute":1790135320,"duration_minutes":28.0,"visits_total":3,"rooms_walked":["tavern_front","stacks_midnight","widows_overlook"],"room_dwell_sec":{"tavern_front":310,"stacks_midnight":900,"widows_overlook":470},"choices":["door:rsvp_left","valve:water_open","take:ledger","give:vesper:receipt"],"deaths":0,"puzzles_solved":["rsvp_door"],"theme_vector":[0.0,0.25,0.0,0.5,0.0,0.0,0.25,0.0],"commit":"<sha256>","amended":false}
```

**Canonicalization rules (the F1 contract):**
- Keys sorted; UTF-8; LF-terminated; no trailing whitespace; floats rounded to 6dp (matches `knot_timeline.jsonl:5`, `0.325305`).
- Time floored to the **unix minute** — never store sub-minute timestamps (`start_unix_minute` pattern, `knot_timeline.jsonl:1`).
- `rooms_walked`: stable engine room IDs (`tavern_front`), lowercase snake, deduped, walk order preserved in the array; dwell in a separate sorted map.
- `choices`: `verb:object` canonical tokens from the engine's validated action enum only (`door:rsvp_left`). Parser prose, free text, and LLM output never enter this array — the engine emits the token at the moment it accepts the action (engine-owns-truth, `index_events.jsonl:2192`).
- `theme_vector`: exactly 8 floats summing ≤1 — the 8-slot allocation copied from `knot_timeline.jsonl:1` so world and visitor rows fold through the same tooling.
- `commit` = sha256 over the canonical JSON of the row **minus** `commit` itself; `amended:false` at seal; amendments never rewrite — they append a successor row with `amended:true` (the `knot_timeline.jsonl:1` flag, used the same way).
