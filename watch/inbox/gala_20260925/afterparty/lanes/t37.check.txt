BINDING CONTRACT (receipt format: source-fetched: YYYY-MM-DD sha256:<64 hex>):
  - binding + --source + file exists -> gate recomputes sha256 over the file bytes; match exits 0, mismatch exits 2 naming both digests
  - binding + --source + file missing -> exit 2 (fail-closed, same class as a missing receipt)
  - --source given, receipt binds nothing -> exit 2 (nothing to verify is not a pass)
  - binding stamped, no --source -> date rules only, reason says 'stamped but unverified (pass --source to enforce)', exit 0 if the date is fresh
  - newest stamp drops a binding an older stamp carried -> exit 2 're-stamp smell' even without --source (a bare fresh stamp cannot launder a bound claim)
  - stamp line says sha256 but the binding is malformed (63/65 chars, non-hex) -> the whole line is not a stamp, exit 2 'no freshness stamp' (never a truncated-hash guess)
  - hex compared case-insensitively; most recent stamp is the evidence; on a date tie a bound stamp beats a bare one
