t64 check: Portal_ pad suffix vs ZoneGate ZONE_REGION key audit (verify by read; no code change, zero mismatches found)

ITEM RECALL
t59's client tint binds pads by ^Portal_(.+)$ then keys Gate_<sanitized suffix>;
ZoneGate stamps Gate_<sanitized zone> only for ZONE_REGION keys. Any pad whose
sanitized suffix is not a ZONE_REGION key would silently never tint. Build the
suffix-vs-key table and classify each pad.

3) THE LATENT SEAM (for t46/t59 authors or a future wave author)
The join lives in two hand-authored lists: WAVE[].name (init.server.luau) and
ZONE_REGION (ZoneGate.luau). They are identical today by discipline, not by
construction: a future wave zone added to WAVE without a ZONE_REGION row
would silently never tint AND silently never gate (portalGate :99-101 returns
true). If either list grows, the diff command in this file is the check.
No code change filed: the item authorizes a one-line key alignment only for
genuine mismatches, and there are zero.
