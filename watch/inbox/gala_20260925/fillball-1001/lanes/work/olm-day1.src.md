## The steal (mechanism, not links)

The month's four papers converge on one mechanism: quantization damage is STRATIFIED and AGREEMENT-COUNTERFEITING, so any single-scalar gate certifies the wrong thing. Perplexity can hold while a capability class dies; answer accuracy can hold while the evidence under the answer dies; cross-sample agreement can rise because the model collapsed, not because it is right; and the fix for the storage side is density measurement before layout adoption, not a universal format. The estate port is a two-part promote gate for the janitor fleet and the deliberate-ask quantize-target ladder (`AGENTS.md:28`), plus two intake rules:

- **Capability-classed batteries, not scalar loss.** Induction (repeat-a-string-from-context) and retrieval (recall-a-fact-from-context) probes score each quant arm separately, because a 1.2-1.5x perplexity rise can hide induction at 0.959 retention while retrieval has already fallen to 0.554 (Find 1, sweep:22). The estate already holds the invariant this re-derives from the weight side: `mag/auto_quantize.py:22`, "Anomalies are NEVER quantized. Keep raw forever." The sweep flags the sibling law at `mag/auto_quantize.py:23` (variance determines resolution) as half-stale because 2026 mixed precision allocates by sensitivity, not variance (sweep:35-36); the battery is the sensitivity instrument that restatement needs.
- **Concentration scoring, not agreement counting.** A consensus or quorum verdict built from same-family same-quant lanes is modal collapse, not independent verification (`mag/_consensus_witness.py:5` assumes independent bodies converge; quantized same-family lanes are not independent). Witness rosters must span model families and quant levels, and agreement scores as collision probability (Find 2, sweep:47).
- **Evidence field in every promote gate.** Verdict accuracy surviving a quant is compatible with the rationale's support dying (Find 4), so percolator intake routes a verdict-passes-support-drops row to the EXPLORE queue (`mag/percolator.py:16`) instead of compiling it as a repeatable invariant (`mag/percolator.py:14`); this lands the sweep's contract-on-content rule (sweep:61) inside intake.
- **Density-first compression discipline.** Before adopting a compressed layout, measure the zero fraction the layout exploits; a sub-2-bit ternary rung is now measured economics (Find 3) and must carry a task-shaped eval from Find 1, never a perplexity delta alone.
