# THE RACTOR-ESSAY PATTERN — REPEATABILITY + IMPROVEMENTS (2026-09-29)

Operator asked two questions after watching the Q-operation pipeline run end to end: "how can we make this a repeatable pattern?" and "how can we improve upon it?" This receipt is the answer; the artifact is `.agents/skills/ractor-essay/SKILL.md` (invocable as a house skill from every future seat).

## What makes it repeatable (the four artifacts)

1. **A name.** The pattern is now `ractor-essay`. Named things are invocable; unnamed things are anecdotes.
2. **A card.** The SKILL.md encodes the seven phases + the socratic frame: self-steal -> digest (measured numbers, path-cited) -> N grounded lens essays -> adversarial grade -> dated corrections -> strongest-parts synthesis -> the interpreted piece -> receipt. Each phase has inputs, outputs, and exit criteria. Any seat, any window, same pipeline.
3. **Laws inside the asks.** The binding rules ride in the dispatch text itself, not in the operator's vigilance: no fabrications (traceable to digest or cited file), em-dash 0, tri-state claims, blind divergence between lenses, receipt-before-speech, verdict-not-vocabulary on sensitive subjects, width 3 for lens fan-out.
4. **The self-feed.** Each run's DIGEST lands in the corpus in a stable schema. The pipeline's Phase 1 is a corpus sweep, so every run becomes raw material for the next. The Q run proved the payoff: its self-steal found the estate had already held the entire research project (6,242 Q posts, Cooper's 1.62M characters, the lineage ledgers) — the lenses argued from measured numbers because a prior seat had filed them.

## What would improve it (v1 ledger, seeded)

1. **Phase 0 exists now.** The Q run inherited fixed lenses (East / West / game theory). v1 adds the socratic frame: the ask gets teased out first, and the lenses are derived from the ask. A subject about economics should not automatically get a Daoist lens just because the last one did.
2. **Digest quota, grader-enforced.** The self-steal paid hardest, so it becomes structural: every lens must cite at least five measured numbers from the digest, and the grader checks. Vibes fail the gate.
3. **The grader gets graded.** The Q run's receipt honestly flagged that its grader was an LLM pass, not the human-blind A/B. v1 offers Phase 3.5: the operator reads two anonymized lenses cold and ranks them; their ranking is a scored row against the LLM grader's. Over runs, this builds the grader's own Brier table.
4. **Tension map = synthesis skeleton, one-to-one.** The Q run did this implicitly. Now it is the law: every cross-lens tension the grader maps becomes a section the synthesis must resolve or name unresolvable. No tension left behind.
5. **The 1301 law in the final piece.** Sensitive subjects: the final piece states verdicts, not vocabulary. The lens essays and receipts carry the clinical detail. A window that dies mid-pipeline loses nothing because every phase files before speaking.
6. **Cost line in every receipt.** One run = lens fan-out (free/cheap lanes, width 3) + two funded-tier judgment moments (grader, synthesis). The receipt states the token/width cost so the pattern's price is a measured fact, like everything else here.
7. **Length budget stated in Phase 6.** The Q run's final piece landed at 2,019 words and had room to earn more; the voice brief now carries the target length so the last phase is aimed, not open-ended.

## The first dogfood is already framed

The pending subject is the game-platform moonshot (WoW clone + GWAP backend + the sovereign platform). Its Phase 0 was drafted this session before the pattern existed — five socratic questions, each of which reorders the ladder:

1. When you say "wow clone," do you want a world to WALK (you and Adam in a shared persistent world soon) or an engine to OWN (sovereign server infrastructure)? Walk-first sequences B2 ahead of the bots port; own-first puts the port on the critical path.
2. When you say "gwap as a backend for people making games," who is customer zero — an external developer, or the estate's own verification needs? The reCAPTCHA lesson says embed in friction that already exists; the estate's existing friction is verifying its own work.
3. When you say "roblox but not child predators," which predation do you refuse FIRST — the scrip squeeze, the safety failure, or the attention mining? Each refusal is a design constraint with a different price, and the platform cannot pay all three before B4.
4. What is the moonshot's falsifier? What observed fact ends it? (Unregistered falsifiers are vibes, not moonshots.)
5. Is the AI-populated world (playerbots + estate seats as souls) the actual product nobody else has — and if so, why is it currently on the critical path only as a build blocker instead of as the product spec? (UF-01's "bot innkeepers that remember you" already has a falsifier written.)
