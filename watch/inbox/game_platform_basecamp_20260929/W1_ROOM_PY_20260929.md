## Files (this lane's ownership, nothing else touched)

- `server/room.py` (new, ~200 lines): `Room` + `Member`. Per-client bounded
  asyncio.Queue drained by a per-member writer task; `publish()` is fully
  synchronous and hands the SAME bytes object to every queue (encode-once
  fan-out); `QueueFull` drops that laggard inside publish (reason "slow",
  transport closed, loop never blocked); presence via `touch()` +
  `presence()` + `sweep()` (expire, default 6s, mud_relay parity); drop
  reasons slow/expired/left/error/closed; `on_drop` observer; `wait_idle()`
  test primitive.
- `server/ws_door.py` (new, ~280 lines): minimal RFC6455 server-side
  handshake (SHA1+GUID accept, byte-exact 101) + frame reader/writer.
  Byte logic stolen from `dashboard/mud_relay.py` (FW-37 spike) and ported
  from blocking sockets to asyncio; credit in the module docstring and at
  both stolen functions. `WsDoor.publish(line)` frames the encoded tick
  ONCE and fans the same frame bytes through the room. Ping/pong, close
  echo, 1 MiB frame cap, text frames update presence meta (id/name).
  Standalone demo: `python -m server.ws_door` (default 8801; NEVER 8766,
  which is mud_relay's port and the cast_server collision from the ledger).
- `tests/test_room.py` (new, 5 tests): 3-fake-client fan-out (asserts the
  same bytes OBJECT reaches every queue), slow-client drop (stalled sender,
  full queue, disconnect, fast member carries on), presence touch/sweep
  expiry, byte-level handshake against a crafted client hello (accept
  computed independently in the test; non-upgrade GET gets 400 + close),
  full frame roundtrip over real sockets (publish both length forms,
  masked presence frame, ping/pong, close echo, no expiry ghost after
  socket close).

## The integration contract (server owner adds; this lane did not edit server/server.py)

```python
self.ws_door = WsDoor()               # 1. WorldServer.__init__
await self.ws_door.start(self.host)   # 2. WorldServer.start (own listener, ephemeral port)
self.ws_door.publish(line)            # 3. WorldServer.pump_once, right after line = encode(payload)
# optional 4th: await self.ws_door.stop() in WorldServer.stop()
```

`publish` is sync by contract: the 800ms tick loop never awaits it. The
room owns every transport law; the door owns only RFC6455 bytes.
