# DEEP READ DELIVERED: the omaras0 paper (arXiv:2610.07782, NeurIPS ML4Sys 2026)

"Persistent Memory in Multi-Agent LLM Inference: What It Costs, What It Buys, and
When You Can Tell" - Son, Han, Koh, Dai, Xu, Cheng (UCLA/Wisconsin/HCLTech).

## What it finds

- Decomposition HOLDS: agent-split inference bounds active KV cache per call
  (14.3 MiB peak vs 35.5 single-pass / 35.3 RAG). The systems value is real.
- The persistent-memory tier is a STRUCTURAL NULL: across eight controlled
  dataset pairs, n=100/arm, it costs +0.388 MiB and produces no detectable
  accuracy change (+0.015, 95% CI [-0.011, +0.046]). Not "we failed to find the
  gain" - the gain is UNTESTABLE on single-question benchmarks: each condition
  gets its own evidence and traces are reset between conditions, so recall has
  nothing informative to retrieve.

  apparent benefit. The founding-fixture disease, peer-reviewed.

measurement discipline (four corrections, preregistered ablation conditions,

the falsifier-first rule, peer-reviewed.

memory tier. Every battery run is a single-question benchmark with traces reset
