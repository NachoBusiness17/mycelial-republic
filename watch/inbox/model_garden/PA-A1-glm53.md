## 2. VERIFIER DESIGN

**Binding point: read path, always.** Verification happens at the moment a consumer reads a directive or health row, not when it is written. Write-side signing is permitted but never trusted alone; an unsigned message is rejected at read time after the migration window.

**Key material: one secret.** `state/steer_secret` (hex, 32 bytes, file mode 600). Holder: the operator's device and the estate root. The operator's workflow stays single-word: the secret lives on his phone in a clipboard macro; the signed envelope is generated by one tap of a shortcut that computes the HMAC over a template. He types `steer <nudge>` as today; the signing layer wraps it. Zero added ceremony: he never sees a hex digest. On the estate side, `steer_seal.verify()` loads the secret lazily and fails closed if absent.

**Canonical envelope.**

```
STEER1|<channel_id>|<ts_unix>|<nonce16hex>|<body_sha256>\n<body>
```

- `channel_id`: `file-steer` | `discord` | `phone-door` | `grok-gate`
- `ts_unix`: seconds UTC
- `nonce16hex`: 16 hex chars, client-random, tracked in a replay ring
- `body_sha256`: SHA-256 of `<body>` (UTF-8), hex
- Signature: `HMAC-SHA256(secret, canonical_bytes_of_envelope_through_body_sha)`, appended as `|<hmac_hex>` on the same first line.

**Replay window.** Accept only if: (a) `|now - ts_unix| <= 120` seconds, and (b) `(ts_unix, nonce16hex)` not in the replay ring. Ring: persistent JSONL at `state/steer_nonces.jsonl`, in-memory set at load, prune entries older than 300s on each verify. Clock-skew tolerance of 120s covers phone-to-estate drift without NTP ceremony.

**Backward compatibility (migration).** `verify(msg)` returns `(ok, reason)`; during the migration window (flag `STEER_SEAL_ENFORCE=0`), unsigned messages pass with reason `unsigned-legacy` and are logged; enforcement flips to reject at a named cutover date recorded in `state/steer_seal_state.json`. Signed messages always verify regardless of flag.

## 3. THE PATCH SPEC (apply as-is)

**File: `mag/steer_seal.py` (NEW).**

```python
"""steer_seal v1 - read-path anti-forgery + replay rejection for steering channels."""
import hashlib, hmac, json, os, time
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
SECRET = ROOT / "state" / "steer_secret"
RING = ROOT / "state" / "steer_nonces.jsonl"
STATE = ROOT / "state" / "steer_seal_state.json"
WINDOW = 120

def _secret() -> bytes:
    if not SECRET.is_file():
        raise SystemExit("steer_seal: state/steer_secret missing - fail closed")
    return bytes.fromhex(SECRET.read_text(encoding="utf-8").strip())

def _enforced() -> bool:
    if os.environ.get("STEER_SEAL_ENFORCE") == "1":
        return True
    try:
        return json.loads(STATE.read_text()).get("enforce", False)
    except Exception:
        return False

def sign(channel_id: str, body: str, ts: int | None = None,
         nonce: str | None = None) -> str:
    ts = ts or int(time.time())
    nonce = nonce or os.urandom(8).hex()
    body_sha = hashlib.sha256(body.encode("utf-8")).hexdigest()
    canonical = f"STEER1|{channel_id}|{ts}|{nonce}|{body_sha}".encode("utf-8")
    mac = hmac.new(_secret(), canonical, hashlib.sha256).hexdigest()
    return f"STEER1|{channel_id}|{ts}|{nonce}|{body_sha}|{mac}\n{body}"

def verify(raw: str) -> tuple[bool, str]:
    lines = raw.split("\n", 1)
    parts = lines[0].split("|")
    if parts[0] != "STEER1":
        return (not _enforced(), "unsigned-legacy" if not _enforced() else "reject:no-envelope")
    if len(parts) != 6 or len(lines) != 2:
        return False, "reject:malformed-envelope"
    _, channel_id, ts_s, nonce, body_sha, mac = parts
    body = lines[1]
    if abs(int(time.time()) - int(ts_s)) > WINDOW:
        return False, "reject:stale-ts"
    if hashlib.sha256(body.encode("utf-8")).hexdigest() != body_sha:
        return False, "reject:body-hash-mismatch"
    canonical = f"STEER1|{channel_id}|{ts_s}|{nonce}|{body_sha}".encode("utf-8")
    if not hmac.compare_digest(
            hmac.new(_secret(), canonical, hashlib.sha256).hexdigest(), mac):
        return False, "reject:bad-mac"
    if _replay(nonce, int(ts_s)):
        return False, "reject:replay"
    return True, "ok"

def _replay(nonce: str, ts: int) -> bool:
    seen = set()
    if RING.is_file():
        for ln in RING.read_text().splitlines():
            try:
                r = json.loads(ln)
            except Exception:
                continue
            if time.time() - r["ts"] <= 300:
                seen.add((r["ts"], r["nonce"]))
    if (ts, nonce) in seen:
        return True
    RING.parent.mkdir(parents=True, exist_ok=True)
    with RING.open("a") as f:
        f.write(json.dumps({"ts": ts, "nonce": nonce}) + "\n")
    return False
```

## 4. TEST PLAN

Positive cases - MUST BE REJECTED (forgeries):

1. Raw nudge with no envelope, enforcement on -> `reject:no-envelope`.
2. Envelope with `bad-mac` (any single hex char flipped) -> `reject:bad-mac`.
3. Valid envelope, body modified after signing -> `reject:body-hash-mismatch`.
4. Replayed authentic envelope (same ts+nonce, 5s later) -> `reject:replay`.
5. Authentic envelope with `ts` offset -121s / +121s -> `reject:stale-ts`.
6. Envelope signed under a test secret, verified under the estate secret -> `reject:bad-mac` (secret-swap forgery).
7. Forged `phone_door_log.jsonl` row with `seal` copied from a prior row -> `reject:replay` in `status()`.
8. Truncated envelope (5 fields, no mac) -> `reject:malformed-envelope`.

Negative cases - MUST STILL PASS UNCHANGED (operator friction = zero):

1. Operator types `steer "stop, check the quota first"` with the phone shortcut wrapping it -> `ok`.
2. Nudge body containing `|` characters, newlines, unicode, and the literal string `STEER1|fake` inside the body -> `ok` (body is hash-bound, never parsed).
3. Nudge matching every `_PATCH_PATTERNS` entry in `02__grok_steer.py:36-48` (e.g. "remove that gate") once sealed -> reaches `decide_steer` normally; the seal rejects forgeries, never operator sentiment.
4. Phone-door health rows from the real `ensure()` (latency strings like `"in 23.1ms"`) -> `ok`.
5. Migration window: legacy unsealed message with `enforce=false` -> passes, logged `unsigned-legacy`.
6. The interrupt law itself: `verify()` adds exactly one secret load and two hashes to the operator's path; measured over 1000 verifies, added latency < 5ms (assert in test).

Test file: `tests/test_steer_seal.py`, cases 1-8 as `test_reject_*`, negative 1-6 as `test_accept_*`. Estimated 14 tests, pytest, deterministic (inject `time.time` via monkeypatch for stale/replay cases).

## 5. FALSIFIER

This design is wrong if either observation holds:

- **F1 (forge-side):** a party with write access to the repo but NOT to `state/steer_secret` produces a message that `verify()` accepts as `ok`. One accepted forgery kills the whole layer, since it means the secret or the comparison is leakable from read-path context.
- **F2 (operator-side):** the operator's single-word workflow is measurably slowed - any observed case where a legitimate steer fails to verify on first attempt for a reason other than a genuine replay or >120s clock drift (e.g. shortcut mis-signs, unicode body hash mismatch). One friction event violates the interrupt law and the design must be re-cut, because a verifier the operator routes around is worse than none.

Also falsifying: the Discord reader file, when produced, cannot bind `verify()` at its read path without new infrastructure beyond the one secret - that would prove the envelope shape does not cover the estate's actual channels.
