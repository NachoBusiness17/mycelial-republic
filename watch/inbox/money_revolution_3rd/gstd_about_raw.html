О проекте GSTD

GSTD — открытый протокол для децентрализованного ИИ-инференса. Любой может запустить программное обеспечение ноды на своём оборудовании, зарегистрироваться в сети и зарабатывать GSTD за выполненную работу — 85% каждой комиссии, расчёт на блокчейне.

Ключевые особенности

Открытая сеть нод

Любой может запустить ПО ноды на своём оборудовании для обработки ИИ-запросов — зарабатывая GSTD за каждое выполненное задание.

Утилити-токен — не инвестиция

GSTD — платёжный токен для ИИ-вычислений. Заработок идёт от реального использования — без стейкинга, без обещаний доходности.

Мультичейн в разработке: TON уже работает, мост — в разработке

GSTD сегодня работает на TON. Кросс-чейн мост к Solana и XRPL — на ранней стадии, без аудита и ни разу не переводил средства в продакшене — считайте его неработающим.

Открытый исходный код

Все компоненты платформы имеют открытый код. Разворачивайте из GitHub, верифицируйте на блокчейне.

Что мы строим

1

Сеть нод: любой может запустить ПО ноды для обработки ИИ-запросов, генерируя комиссии протокола

2

Распределение комиссий: операторы нод зарабатывают 85% каждой комиссии за инференс, расчёт на блокчейне через контракт SettlementMaster

3

Казна: 10% комиссий идут в казну, ещё 5% — на байбэк и сжигание GSTD

4

Открытый доступ: любое устройство (ноутбук, Pi, сервер) может присоединиться и начать зарабатывать

Наша миссия

Создать открытую сеть ИИ-вычислений, где любой может запустить ноду и зарабатывать GSTD, обслуживая ИИ-запросы. Без посредников, без единого провайдера — только открытый рынок вычислений.

Открытая сеть ИИ-вычислений на TON. Платите GSTD за инференс. Запустите ноду, зарабатывайте 85% комиссий на блокчейне.
