# PACKAGING — how to zip and share this packet

One job: get these files to another human without losing the honesty. Numbered, so a
stranger can execute it.

## Before zipping

1. Read every file once, as a stranger would. If a sentence only makes sense because
   you already know the machine, fix the sentence, not the reader.
2. Check that no file names a private path, a username, a hostname, or a key. Tokens
   only. The legend in BUILD.md is the mapping; each reader maps tokens to their own
   machine.
3. Check the evidence names. The packet cites receipt files by name; those receipts
   live in the authoring archive, not in the zip. Leave the names — they are pointers
   and pedigree, not attachments. If you want the receipts to travel, copy them into a
   `receipts/` subfolder inside the zip, unchanged. Do not summarize them into the zip;
   a summary of a receipt is prose, and readers get bytes (BUILD 3g).
4. Blanks stay blank. Missing fields stay —. Never invent a file name, a number, a
   date, or a result to make the pack look fuller.

## The zip

5. Zip the folder as `adventurelearn_packet.zip`. Nothing else goes in: no local keys
   file, no config with tokens, no cached model outputs with personal data, no git
   metadata.
6. Name the packet honestly in the covering message: what it is (build instructions for
   a small epistemics machine), what it is not (not a product, not a service, no
   support), and that it is incomplete in named places.

## Sending

7. Any plain channel. The packet is text; it does not need a platform, an account, or a
   service. If a channel mangles Markdown, attach the zip instead of pasting.
8. If the recipient answers, their reply is an outside reader's verdict (BUILD 3g).
   File it: keep / kill / amend, and which catches you accept. The packet improves the
   same way the machine does — by amendment, not by rebirth.

## The standing OPSEC of this share

- Public knowledge only. Every source in BIBLIOGRAPHY.md is free and legal; nothing
  paywalled was fetched, and every blocker is recorded as a blocker.
- No secrets in the pack. No keys in the zip. Key material lives in the VAULT, outside
  every shared surface, forever.
- Software never mints Supported. If this packet's claims are ever copied into a
  claims table, they enter as unproven until a human signs.
- Say incomplete when incomplete. This packet is incomplete in named places, and the
  covering message repeats it.
- Add back one rule, not a desk. If the recipient adopts one piece, one rule is the
  right-sized first win. The machine grew by single rules that each carried a failure
  story; it never grew by a committee.
