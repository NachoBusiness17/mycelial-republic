## The honest frame

Real VRAM is billions of bits at nanoseconds. Mycelium will be BITS at MINUTES. So the prize
is not replacing VRAM — it is owning a **living memory hierarchy** end to end: registers to
archive, every layer grown, every layer instrumented. And mycelium already HAS the layers;
what does not exist is the controller and the bus. That is what we build.

## The baby steps, dogfooded like the fleet itself

Law: every step must be CONSUMED by the fleet (a dashboard tile, a trail row, a MUD room) —
instrumentation is the product, observation alone is theater.

- **Step 0 — build the ear.** C17 as filed ($31): noise floor, then fading-memory capacity
  (PRBS light drive, readout predicts delayed input). Fleet-consumed as: nightly MC number
  on the dashboard next to the drift patrol — the cube gets a heartbeat tile.
- **Step 1 — the read test.** "What did the network just hear?" — the capacity meter IS the
  read. Pass = MC measurably above shuffled-surrogate. Fleet-consumed as: the MC curve in
  the trails, per night.
- **Step 2 — the first write.** Condition the network (repeated pulse pattern), measure the
  response BEFORE vs AFTER: did anything persist past the electrical trace? This is
  "save to disk." Fleet-consumed as: a before/after receipt pair, VOID-able rows.
- **Step 3 — addressing.** Two sites, one rig: write at electrode A (stimulate), read at B.
  Measure how much of the write arrives at B vs distance — that decay curve is the embryonic
  address decoder. Fleet-consumed as: the routing table tile.
- **Step 4 — the filesystem.** Map trained patterns to symbols in a lookup table; capacity
  counted in HONEST BITS. One bit held an hour would be a world-class hobbyist result at
  this table. Fleet-consumed as: myco-bit-0 mounted as a literal file the fleet reads.
- **Step 5 — the mount.** The cube's state becomes a fleet surface: MUD room reads the
  myco-bit; estate walk shows the cube's lantern; the estate catalog indexes its ledger.
  The living computer substrate becomes part of the living computer.
