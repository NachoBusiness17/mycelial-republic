## F1. The landed harness already runs the thesis inverted at the reward line, and the fix is a deletion

The selfimp imp002 orchestrator routes the reward channel through a paid remote LLM rater (`flash_call`, mag/selfplay_orchestrator.py:166) that costs 2966.9 ms per move on average (memory/runs/selfplay/evidence_latest.json:8, vs actor 3472.6 ms, so the rater is 46 percent of wall time) and, when the API is down or its text is junk, banks a NEUTRAL 0.5 half-credit (mag/selfplay_orchestrator.py:249-251 fallback `return "0.5"`, :254-268 parse default). The deterministic keyed oracle is present one line away but demoted: `self.elo.update(reward if correct else 0.0)` (mag/selfplay_orchestrator.py:179) uses the LLM float as the score and the oracle only as a boolean veto. My probe ran it: `_parse_reward('')` returns 0.5, `_parse_reward('the model rambled')` returns 0.5. The founding thesis says Stockfish is in charge; in the one loop that exists, Stockfish may only say yes/no while a flash model grades degree, and when the flash model is silent the loop pays its winners half credit. Note the honest refinement: in the banked 8-bout run, reward equaled the oracle verdict on every row (evidence_latest.json rows m001-m008), so the gate held; the defect is cost (3 s/move for what a dict lookup gives in 0 ms), the failure default, and the principle. This is the effect-broker law (model text proposes, only the broker authorizes, mag/effect_broker.py:317 schema effect_broker.v1) applied to reward: model text proposes a move, only the keyed oracle banks the point. Falsifier: a batch where LLM-rater partial credit on oracle-correct answers predicts downstream fold value better than binary keyed outcomes; nobody has such a batch, and the burden is on the rater to earn its 3 seconds. Move (20 min): delete the scorer leg, score Elo from the keyed oracle alone, rerun one session offline, bank the wall-time delta as the receipt.

## F3. Token cues are the opening book, and the opening book is free

In chess the opening book is a lookup of strong start sequences per position class. The token-cues receipt is exactly that organ in decode space: "fixing particular starting token cues makes a base model's performance competitive with that of its RL-trained counterparts," with the cue '.\n\nOkay' lifting Olmo-3-7B MATH-500 pass@1 from 42 to 78 (watch/inbox/TOKEN_CUES_2610.06851_20261006.md:10), and cue-induced hidden states correlating with different training-doc types (:14), which is the per-position-class structure of a real opening book. In the league encoding, a cue is a move class: choose repertoire for this position class. The league discovers which cue wins on which problem class by self-play bouts and banks it as a $0 decode-time layer, portable to every seat with zero training, and measurable on the garden's 17 animals tonight (instruments exist per the receipt's S1 row, :26). CONVERGENT with the receipt's own S1/S2 rows (:26-27) and with the D6 monoculture probe framing (:21): cue-varied same-model arms may beat temperature-varied arms as the cheap mesh's diversity axis. This is the piece frontier labs have no reason to build and a cheap fleet cannot afford to skip. Falsifier: the 3-arm cue battery on gemma:2b-class animals shows no arm separation; then cues are a paper-local artifact on Olmo/Qwen and the opening-book layer is cut before it contaminates the league. Move (45 min): run the one-animal, ~50-item, 3-arm battery (no cue / '.\n\nOkay' / 'Alright,'), bank pass@1 per arm, no spend.
