## Standing law this pass mints for the next lens

A census over memory/training/events.jsonl (or any mixed-content jsonl that may carry
binary bytes) in default grep mode silently truncates at the first binary byte and
reports a prefix as a total. The fix is one flag: grep -a. Symptom signature: the sorted
uniq output contains a "Binary file ... matches" line; any census whose sum is far below
wc -l was truncated. This is the third instrument of the same class in two sittings
(findstr /s on this host, literal-pipe grep patterns, default-mode grep on binary-detected
files): the pattern is that the lens RUNS the check but transcribes the command without
the flag that made it work. Receipt law: the command in the receipt must be the command
that produced the number, flags included.
