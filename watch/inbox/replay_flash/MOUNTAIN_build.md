## Part 2. THE PRIMER v0 (the tangible-books moonshot leg)

A book that reads the walker: a physical page, webcam-captured by the operator, maps to a CathedralPlate region and unlocks the matching zone content for the session.

- Capture flow: the operator lays the open page flat and runs `tools/primer_capture.py` on the host. First run picks the page quadrilateral once and caches it; every run then grabs one frame, crops the cached region, normalizes, computes the page digest, matches it against the mapping table, and delivers the page id to the world through the estate's one HTTP nerve, the NpcGateway pair (`src/server/NpcGateway.luau` + `tools/roblox_npc_gateway.py`). v0 target is the Studio localhost gateway; a live published server needs the gateway on the fleet's public box per README step 6. UNVERIFIED: that public-box deployment; no receipt exists for it in the evidence.
- Page identity, lighting-tolerant: raw pixel hashing is rejected by design because lighting and camera pose move every byte. The digest is a 256-bit perceptual vector: crop, grayscale, downscale to a 16x16 grid of per-cell mean luminance, subtract the image mean, divide by image standard deviation, threshold at zero. Identity is minimum Hamming distance against the table; a page matches when distance is at most T. Tolerance mechanism stated: illumination is removed by the per-image mean/std normalization, residual pose noise is absorbed by the distance threshold T. Initial T = 24 (under 10 percent of bits). UNVERIFIED: T is uncalibrated until the v0 calibration run records hamming distributions for same-page and different-page captures under the operator's real lighting; the calibration run is part of v0 and its receipt names the final T.
- Mapping table format: `roblox/primer_pages.json`, one object: `{"version": 1, "tolerance_hamming": 24, "pages": [{"id", "title", "digest_hex", "eigen": [x, y], "zone", "unlock"}]}`. `eigen` is a CathedralPlate coordinate so lookup rides the same recompute the eigenmap smokes already diff against the scan JSON. `zone` is a strict-required `KSpace.all()` key, the ZoneGate t67 shape: a page cannot exist without a zone join, and a join without its page cannot be written, because the table is derived from the pages array, not a second list.
- What appears in-world when page N is shown: the gateway delivers the page id; the server resolves the PrimerPages row; the CathedralMap HUD pulses the matching region label (color pulse on the existing billboard label instance, no new HUD surface); a one-way portal spawns at the walker landing at the region's derived entry point, the `entry()` convention; ShadowLedger files a "PAGE N SHOWN" row with the live eigen position, dist and bearing. The unlock is session-scoped like `disposition()`: the matching zone's gate treats the page as a key for this session only, and the durable record is the ledger row, not a store flag.
