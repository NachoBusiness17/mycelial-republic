# selfimp imp001 receipt — 2026-09-29 (queue-closes 63→11 + idempotency)

## Root cause

`tests/test_corpus_acquire.py` existed but was broken: `_make_todo(63)` created
only 63 short lines, while the WO-12 flip sweep keys every flip on line number
AND content snippet, expecting UNCHECKED rows at the exact `_FLIPS` line numbers
(up to 277). The sweep hit "flip lines not unchecked at recount" on every test.

Two further bugs:
- `res["flips"] == 56` — `_FLIPS` has 54 entries; the 2 merge flips (lines 235/237)
  are already inside those 54, not extra
- `len(flipped) == 56` — only flipped rows get the CLOSE marker; the 2 inserts
  are UNCHECKED and carry no CLOSE marker, so the count is 54
- Idempotency test expected dry-run on 11-row file to return ok=True, but the
  sweep's pre_count==63 drift check fires before the dry_run branch
- Drift-abort test targeted "Stone 5" which doesn't match line 5's actual
  content ("Cerebras lane"), so the replace never flipped anything

## Fix

- Rewrote `_make_todo` to build a 277-line file with UNCHECKED rows at every
  `_FLIPS` key (54 rows) plus 9 untouched rows = 63 total, each flip line
  carrying the expected snippet from `_FLIPS`
- Added `_FLIPS` to imports
- `flips` assertion 56→54, `flipped` assertion 56→54
- Idempotency test: second sweep AND dry-run on 11-row file both hit drift law
  (pre_count=11 != 63) → ok=False
- Drift-abort test: flip any UNCHECKED row (`replace("- [ ]", "- [x]", 1)`),
  which triggers pre_count!=63 abort
