## 4. Estate verdict (the ask's question, answered per class)

1. Does it run local at 7B-14B? YES, five ways, all open: Granite 4.0 H-Tiny (7B total/1B active, Ollama/llama.cpp/vLLM listed by IBM), Nemotron-Nano-9B-v2 (9B, HF), Qwen3.5-4B (4B dense, Apache-2.0), RWKV-7 G1 7.2B (GGUF/Ollama, const VRAM), Falcon-H1 7B / Falcon-Mamba 7B (HF, up to 256K ctx). The estate's janitor tier (gemma:2b/gemma4 via Ollama) now has linear-family siblings it could serve from the same runtime.
2. Does the new wave dissolve the KV constraint class at our scale? In the MEMORY dimension, yes measurably: 75% of layers KV-free (Qwen3.5/Qwen3-Next 3:1), 90% (Granite 9:1), 4-of-32+ layers (Nemotron Nano), zero KV at all (RWKV G1, Falcon-Mamba). IBM claims >70% RAM cut, Kimi claims 75% KV cut and 6x decode at 1M. In the RECALL dimension, no new paper this pass overturns sw-09's wall (Zoology 82% gap, Repeat-After-Me copying limit, BASED dial): the hybrids buy memory back by keeping 1-in-4 or 1-in-10 attention layers, which is exactly sw-09's "attention share as a recall budget" line, now with five shipping instances to pick the budget from. For agent transcripts (verbatim tool-call IDs, receipt hashes), sw-09's synthesis stands: the external store does the recall, the linear backbone pays constant per-token cost.
3. What is genuinely NEW doctrine since sw-09: (a) the delta-rule family went production at the frontier tier (Qwen3-Next -> Qwen3.5 shipped GDN to a 4B Apache dense; Kimi's KDA is Gated DeltaNet with finer-grained gating); (b) Mamba-3 halves the state size at equal perplexity (state-size dial, not just attention-share dial); (c) pure-RNN reasoning models (RWKV G1) now ship agentic prompt guides and quantizations, i.e. the no-KV class is being tuned FOR agents, not just benchmarked at them.
