## The mechanism, concretely

1. THE ARCHITECTURE LAYER: every complex system gets a building. SettleTask
   is a factory (built - settle_factory.html). The context pack is a library
   with a frozen wing and a revolving tail. The consensus gate is a chamber
   with five chairs. The verkle chain is the vault under the floor, roots
   visible. These are not metaphors ON the docs - they ARE the docs: the same
   layout an agent's tools parse (rooms = modules, belts = data flows, stamps
   = gates) and a human walks (visual, labeled, slow).
2. THE HUNT: invariants are hidden IN the architecture the way the factory
   hides its ratios in belt speeds - discoverable by walking, not stated in
   prose. A finding is: walked the floor, noticed the gear, extracted the
   invariant, wrote the falsifier. The scavenger hunt IS research; the map IS
   the corpus.
3. THE CATALOG: findings bank into the percolator register (the estate's
   invariant store) with circles attached (symbol/machines/machloket/
   ground/operator). The catalog is the score, and it is evenly distributed:
   every row lands in the public register, the seed, and the mesh - the same
   hour it is found. Hoarding a found invariant is the one rule violation,
   because hoarding converts truth back into control.
4. THE ANTI-CONTROL CLAUSE (the operator's last line is the constitution):
   "evenly distributed instead of hoarded and used to control." The test:
   any truth discovered inside the architecture must reach the public
   register before it can be used to steer behavior. An ungated finding that
   steers without being banked is the negative egregore - the estate's own
   red ledger caught this class tonight (the stealth card crowning an
   unmeasured event).

the right phrase and not inflation)

not the points. The Ulam spiral: the pattern was always there; the linear
