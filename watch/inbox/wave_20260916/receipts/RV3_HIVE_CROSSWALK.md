## Adopt list (their pieces we steal — with build steps)

1. **Receipt "Open" row + failed-honesty clause.** Every receipt that closes a built artifact gains two lines: `open: <who can open it / path>` and `failed: <short list>` where a fake-complete catalog is a refuse. Build step: one template edit to the standing receipt skeleton + one line in the wave capsule law. $0, one line each.
2. **Stop discipline — "last line is stop; no bonus work."** Lane asks end in `stop`; extra scope found mid-lane becomes a requeued row, never side work. Build step: add the refuse to lane-runner charter / ask contract (text-only).
3. **"Add back one rule, not a desk" as a named law.** When a stranger-test or falsifier fails, the fix is one rule, never a standing committee. Build step: one line in the AGENTS.md Clippy block or CONSTITUTION pointer.
4. **Logged-skip law (Gate-0 shape) for our own gates.** Any gate that skips — lite_guard ceiling, UNSUPPORTED_UNSEEDED, D24 human-gate, lane requeue — emits a log/receipt line even on skip. "Invisible skip is where capture hides." Build step: ~10 lines across `mag/lite_guard.py` / `mag/lane_runner.py` log paths.
5. **First-hour recipe for every new wave/surface.** One trivial job end-to-end (write a README, confirm receipt, operator opens) before real work; if it fails, fix the bus, don't start the product. Build step: add "first hour" section to the wave capsule template (text-only).
6. **Version honesty label.** Claims in receipts and packs classify as FROZEN (tagged/committed bytes) vs PRACTICE (current habit, untagged); never launder one as the other. Build step: one header line in the receipt template.
7. **`fetched_at` + `veto` columns for A2 row law v2.** Per-source fetch timestamps and an explicit human-veto field. Build step: two optional keys in the grounding_wave v4 key set (`.get` defaults keep old rows valid — same convention as v2/v3).

## The deepest difference (the mechanism with no neighbor)

**Our blind challenge set with sealed keys (A1).** Their entire audit apparatus — receipt check, Table 5, Table 7, the shop test — is administered by the same bench that did the work. Nothing in the Hive corpus requires a prediction *before* an outcome, a key the workers cannot see, or a score that must produce a canon-or-fossil correction on pain of refusal ("silence is not an allowed outcome"). Their one outside-read (the stranger-continuability test) checks that the files are followable, not that the claims are true — the exact seam our referee chain exists to guard ("the fleet is only falsifiable by its own author"). Mirror note, stated for symmetry: their **Frame Audit gates 1–5** (interrogating steering, hedging, and composite illusion *before* synthesis) has no neighbor in our fleet — our falsifiers all fire after the fact, and nothing we run inspects the prompt's pull. Both holes are adoptable; neither system is complete without the other's neighborless mechanism.
