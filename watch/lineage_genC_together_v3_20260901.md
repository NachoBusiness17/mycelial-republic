2. **Availability (A)**: Every request receives a (non-error) response, without the guarantee that it contains the most recent write. The system is always up and able to respond.
3. **Partition Tolerance (P)**: The system continues to operate despite an arbitrary number of messages being dropped (or delayed) by the network between nodes.
