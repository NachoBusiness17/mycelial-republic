CONTEXT — the tab train (relay through the operator's free web surfaces)

The operator's manual relay today: deepseek web chat -> claude -> gpt -> grok -> z.ai ->
meta -> gemini -> file. All free logged-in web surfaces on two Chrome profiles
(fostertron, nachobuisness). He wants dumb bounded agents with our prompts in tabs
transferring data down the pipe FREE — "the shape of the ideas matters more than the
engine running them."

What exists:
- The cage runs openclaw@2026.8.2, which ships a built-in Browser Relay tool (agent
  drives real tabs: navigate, click, read, fill). Currently NOT enabled in our config
  (tools profile minimal; skills all disabled).
- awesome-openclaw-skills (community) ships a skill for exactly this: accessing external
  AI services (ChatGPT, Claude, HF...) via browser automation.
- The shape train already does the same job via API lanes at ~$0 (free tiers + pennies);
  the tab train's edge is the operator's existing free web sessions (no API keys at all).
- Host internet is FLAPPING today (DNS failures observed) — reliability matters.
- ToS honesty: automating free web UIs violates some providers' terms; mitigations =
  operator's own logged-in sessions, human-pace cadence, low volume, no scraping-farm
  behavior. Aggregator surfaces (Genspark etc.) are the ToS-clean alternative.
- Economist pacing discipline exists (per-surface caps, gaps between sends, burn guard).
- An "android surface" proposal exists in the estate (phone as driver) — optional third leg.

Rightsize questions:
- Smallest v1: which ONE surface, what ONE task proves the pipe? (e.g., deepseek web chat
  receives a digest, returns a research brief, transcript lands in the salon inbox.)
- What pacing is defensible (messages/hour, session length, hours/day)?
- What breaks first: login walls, captchas, UI changes, the flapping internet — and what
  is the fail-honest behavior for each?
- Does Browser Relay need config surgery + restart, or skill-only enablement?
- Kill criteria: what observed signal stops the tab train permanently vs pauses it?
- Is the API-lane train (already live) good enough that the tab train is a nice-to-have?
